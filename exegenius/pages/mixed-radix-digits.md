Mixed-radix digits are the place-value digits of an integer in a positional system where each place has its own length, so the digit at each place ranges over that length rather than over one common base. The [Chinese-remainder map](chinese-remainder-map.md) reads these digits to give each coefficient one coordinate per axis, which requires that each index have exactly one digit tuple. The paper states this fact: <cite data-source="paper">Every ordinary coefficient index has a unique mixed-radix expression</cite>.

Fix a positive integer $\beta$, the number of places, and positive integers $\lambda_1, \dots, \lambda_\beta$. The place index $j$ runs from $1$ to $\beta$ and names a place. Here $\lambda_j$ is the length of place $j$, the number of values the digit at place $j$ can take. The letters $j$ and $\lambda$ have other meanings on earlier pages; here each has only the meaning given in its definition.

Let $\Lambda = \lambda_1\lambda_2\cdots\lambda_\beta$ be the product of the lengths, the number of distinct digit strings the system can write. The place value of place $j$ is $w_j = \lambda_1\lambda_2\cdots\lambda_{j-1}$, the product of the lengths of the places below it, with $w_1 = 1$. The same formula defines $w_{\beta+1} = \lambda_1\cdots\lambda_\beta = \Lambda$, one place past the last, so $w_j$ is defined for $1 \le j \le \beta+1$. The place value is the amount that one unit of the digit at a place adds to the integer.

Let $\nu$ be an integer with $0 \le \nu < \Lambda$, the integer being written. The digit $v_j$ at place $j$ is an integer with $0 \le v_j < \lambda_j$. A mixed-radix expansion of $\nu$ is a tuple (an ordered list) $(v_1, \dots, v_\beta)$ of digits, one per place, such that

$$\nu = \sum_{j=1}^{\beta} v_j\, w_j.$$

For example, take $\beta = 2$, $\lambda_1 = 3$ and $\lambda_2 = 4$. Then $\Lambda = 12$, $w_1 = 1$ and $w_2 = 3$. For $\nu = 7$ the digits are $v_1 = 1$ and $v_2 = 2$, since $1\cdot 1 + 2\cdot 3 = 7$. For $\nu = 11$ they are $v_1 = 2$ and $v_2 = 3$, since $2 + 3\cdot 3 = 11$. If every length is $2$, the place values are powers of $2$ and the expansion is the binary expansion. If every length equals a common value $\rho$, the number of digit values $0,\dots,\rho-1$, the expansion is the base-$\rho$ expansion.

Uniqueness of the expansion is based on the [Telescoping identity](telescoping-identity.md). Here $i$ is a place index that runs over the places below $j$, so the letter changes meaning from its use on the convolution page. For every place $j$, $\sum_{i<j}(\lambda_i-1)w_i = w_j - 1$, because $(\lambda_i-1)w_i = w_{i+1}-w_i$ and the sum telescopes from $w_1 = 1$.

Every such $\nu$ has exactly one mixed-radix expansion. Suppose two expansions $(v_1,\dots,v_\beta)$ and $(v'_1,\dots,v'_\beta)$ of the same $\nu$ differ, and let $j$ be the largest place where their digits differ. Here $v'_i$ is the digit at place $i$ of the second expansion. Each digit at place $i$ lies in $[0,\lambda_i)$, so $|v_i-v'_i| \le \lambda_i-1$. The digits agree above $j$, so the difference of the two values is $\sum_{i\le j}(v_i-v'_i)w_i$. Since $v_j \ne v'_j$ are integers, the term at $j$ has absolute value at least $w_j$, while the places below $j$ contribute at most $\sum_{i<j}(\lambda_i-1)w_i = w_j-1$ in absolute value. The difference is therefore at least $1$ in absolute value, which contradicts both expansions giving $\nu$. Distinct digit tuples give distinct values.

The largest value a tuple gives comes from $v_j = \lambda_j-1$ at every place. Since $(\lambda_j-1)w_j = w_{j+1}-w_j$, the telescoping identity gives $\sum_j(\lambda_j-1)w_j = w_{\beta+1}-w_1 = \Lambda-1$. Every tuple therefore gives a value in $\{0,\dots,\Lambda-1\}$. The $\Lambda$ digit tuples give $\Lambda$ distinct values in that set of $\Lambda$ integers, so every $\nu$ in the range is reached by exactly one tuple.
