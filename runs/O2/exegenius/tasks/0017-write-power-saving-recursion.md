## This page

Concept: Volume-normalized recursion
Gloss: Splitting rows cyclically among W roles makes each of s child calls act on volume V/W, so cost per bit obeys F_k ≤ (s/W)F_{k−1} + O(1), and s/W < m^τ yields a power saving e^τ in the parameter.
Also called: recursive saving

## This page in the argument

The step: For widths $e=m^k$ with a row field of length divisible by $W^k$, chunk interchange costs $O(Ve^\tau)$, because time per bit obeys $F_k\le(s/W)F_{k-1}+O(1)$.
How: split rows cyclically into $W$ role streams of volume $V/W$, apply each edge shear by recursive smaller interchanges, merge, and complete the interchange with two linear updates; then solve the geometric recurrence
Why: Dividing by volume, multiplying the width by $m$ multiplies the recursive cost by $s/W<m$, so the per-bit cost grows like a power $e^\tau$ with $\tau<1$. (the sources say so: "After dividing cost by volume, multiplying the parameter by $m$
increases the recursive contribution by $s/W<m$." (paper))

Its sub-steps, in order:

- Running the bit network with frames $\Phi_{M_v}$ on the role streams and merging rows back yields $H\gets H+D$ on every original row, including scratch rows.
- The updates $D\gets D-H$, $H\gets H+D$, $D\gets H-D$ send $(H,D)$ to $(D,H)$.
- Since $s/W<m^\tau$, the recurrence gives $F_k=O(e^\tau)$.

It serves these steps, from the main result down:

- One deterministic fixed-tape Turing machine computes the exact $2n$-bit product of two $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.; how: build two linear-network tape procedures, fast address interchange and simultaneous butterfly layers, from fixed networks with a strict rank saving; use them in synthetic transforms; place these in the Harvey–van der Hoeven reduction through radix digits, a CRT map, Gaussian resampling with retained permutations, Bluestein chirps and a phase twist; and bound every cost term (on [Integer multiplication in O(n (lg n)^(1−κ)) time](main-theorem.md))
- Two disjoint $u$-bit address fields of a stored array of volume $V$ can be interchanged in $O(Vu^\tau)$ time with $\tau=1-2^{-50}$.; how: factor each edge shear into rank-many smaller interchanges plus linear triangular updates, run the bit network on row-split role streams so its endpoint is the shear $H\gets H+D$, recurse on the field width, and remove the width and row restrictions by padding (on [Fast address-chunk interchange in O(V u^τ)](fast-interchange.md))

**S3.3.1**: Running the bit network with frames $\Phi_{M_v}$ on the role streams and merging rows back yields $H\gets H+D$ on every original row, including scratch rows.
Source: "The result
is $H\leftarrow H+D$ on every original row, including rows assigned
to scratch roles, whose initial values were arbitrary." (paper)
> The row split supplies the common address set used in the frame identity~\eqref{eq:common-frame-identity}. Here the frame at a vertex with matrix $M$ is the address permutation $\Phi_M$, and every edge changes it by $\Phi_{M'-M}$. The same invariant proof applies because a common address permutation commutes with every pointwise bit gate. For the physical input arrays $f_w$, the logical arrays are $g_w=\Phi_{-M_{\mathrm{in}(w)}}f_w$; this only specifies their interpretation, with no initial tape operation. The logical circuit routes $g_w$ to role $\rho(w)$. Thus its physical output satisfies \[ f'_{\rho(w)} =\Phi_{M_{\mathrm{out}(\rho(w))}} \Phi_{-M_{\mathrm{in}(w)}}f_w =\Phi_{I_m}f_w, \] by~\eqref{eq:finite-shear-contract}. Merge by returning row $g$ of output role $\rho(w)$ to the original row $Wg+(w-1)$ within the same preceding prefix. This undoes $\rho$ and restores row order. The result is $H\leftarrow H+D$ on every original row, including rows assigned to scratch roles, whose initial values were arbitrary.

**S3.3.2**: The updates $D\gets D-H$, $H\gets H+D$, $D\gets H-D$ send $(H,D)$ to $(D,H)$.
Source: "The transformation
sends $(H,D)$ to $(D,H)$." (paper)
> To interchange the two full chunks, perform \[ D\leftarrow D-H,\qquad H\leftarrow H+D,\qquad D\leftarrow H-D, \] componentwise. Only the middle shear uses the circuit. The other two updates target the later group and have linear cost. The transformation sends $(H,D)$ to $(D,H)$.

**S3.3.3**: Since $s/W<m^\tau$, the recurrence gives $F_k=O(e^\tau)$.
Source: "Hence $F_k=O(e^\tau)$." (paper)
> The number of recursive calls is the sum of the edge ranks, exactly $s$. Each acts on one role stream of volume $V/W$, retaining all other fields as spectators. Splitting, merging, gates, and triangular operations have total cost $O(V)$ because their number is fixed. Below we verify that scheduling the recursive calls on fixed tapes also costs $O(V)$ at this node. Thus if $F_k$ is a uniform upper bound for time divided by logical volume, then \begin{equation} \label{eq:swap-recurrence} F_0=O(1),\qquad F_k\le(s/W)F_{k-1}+O(1). \end{equation} For $a=s/W<m^\tau$ the geometric sum $\sum_{j=0}^k a^j$ is $O(m^{k\tau})$. If $a\le1$, the sum is at most $k+1=O(m^{k\tau})$; if $a>1$, it is $O(a^k)$. Hence $F_k=O(e^\tau)$.
