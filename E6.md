# E6: confirming the key-step instruction on fresh extractions, paired

Records of experiment E6, run in the development session of lmmx/exegenius (plan:
`calibration/plans/E6.md` at f07da93; analysis: `docs/journal/2026-10-14-e6-key-step-confirm.md`).

- `runs/E6F1`–`E6F8`: eight fresh planning projects with E1's configuration (`runs/G1/exegenius.toml`
  byte for byte) and `template/sources/paper.tex` (copies omitted; byte-identical), stopped when
  the background task was accepted. Extract and background ran with exegenius master af36d6d;
  each prompt as `exegenius next` printed it went word for word to a fresh `general-purpose`
  subagent with `model: "sonnet"`, `effort: "high"`.
- `runs/E6FkB`, `runs/E6FkV`: copies of `E6Fk` taken after its background task was accepted; the
  argument task rendered by the baseline binary (B) or the key-step variant (V, exegenius
  branch `131026-exp-key-step`, 0c29556), answered the same way. In each pair the task files
  differ only in the key-step paragraph and the project path (checked by diff). Every run was
  stopped when `next` handed out write tasks.
- `results/transcripts/e6/subagents/`: the transcript and `.meta.json` of every subagent whose
  answer was accepted (description `RUN TASK`, the run named without its `E6` prefix). All 32 ran
  on `claude-sonnet-5-5` at `high` on every turn.
- `results/e6-killed-attempts/`: ten first argument attempts (F1V, F2V, F3V, F4V, F5B, F5V, F7B,
  F7V, F8B, F8V) killed by the account's usage limit (HTTP 429) before submitting, and in
  `drafts/` the scratch files three of them had written (F1V, F2V, F4V). Before each retry the
  task's scratch directory and answer file were moved here, so no retry saw a killed draft.
