An address field is a contiguous block of address bits, and the choice of fields fixes how an array is laid out on a tape. Transform levels rearrange these fields, so the layout sets what each level costs.

Write $m$ for an item's position in tape order. An array is stored in tape order: the item at position $m$ sits in the $m$-th cell, and its address is $m$ written in binary. Write $u$ for the number of bits in one address field. Splitting the address bits into contiguous blocks of $u$ bits gives the address fields. An address is then a tuple of field values, and the set of all addresses is the Cartesian product of the fields' value sets.

Example. A 4-item array has two one-bit fields, the high bit and the low bit. Interchanging them sends the item at address $01$ to address $10$, the item at $10$ to $01$, and leaves the items at $00$ and $11$ in place. The items are unchanged; only their cells move.

Why levels rearrange fields. The transform is the discrete Fourier transform, which evaluates a coefficient list at roots of unity. It is computed in levels, each a layer of two-point butterflies that replace a pair of entries by their sum and difference, up to a scale factor. A level pairs entries whose addresses differ in one bit, and successive levels pair different bits. A fixed-tape machine combines two entries only when both are scanned together, so a level may first need an interchange of two disjoint address fields that brings its pair into the scanned position.

Rearranging is not free. A layout's cost is counted in the [Fixed-tape machine model and stream operations](fixed-tape-model.md), where each step touches one cell per tape, so moving data is the cost to minimize. Write $V$ for the stored bit volume, the total number of bits the array holds. Each entry is a fixed-width coefficient of $\Theta(\log n)$ bits, and the padded array holds $\Theta(n/\log n)$ entries, so $V=\Theta(n)$ <cite data-source="paper">a full padded array has $\Theta(V)$ stored bits</cite>. Scanning all $\Theta(n)$ stored bits at each of the $\Theta(\log n)$ levels costs $\Theta(n\log n)$ <cite data-source="paper">$\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$</cite>.
