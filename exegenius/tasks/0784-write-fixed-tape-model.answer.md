A fixed-tape machine model is a Turing machine whose alphabet and number of tapes are fixed in advance, so they do not grow with the input; only the contents of the tapes grow. It is the setting of the main result, [Integer multiplication below n log n](main-theorem.md), which gives a machine whose running time is below $n\log n$.

A fixed-tape machine has three restrictions. Its alphabet, the finite set of symbols a cell may hold, is fixed. Its number of tapes is fixed. Its tapes are one-dimensional, meaning each is a row of cells. The paper puts it as <cite data-source="paper">A machine has one fixed finite alphabet and one fixed finite number of one-dimensional tapes.</cite> Each step is local: a step <cite data-source="paper">reads and writes at most one cell on each tape and moves each head by at most one cell.</cite> For example, if a tape holds 1011 with its head on the first cell, one step can overwrite that 1 with 0 and move to the second cell, but cannot reach the fourth. Reaching a cell three cells away therefore takes at least three steps.

Let $n$ be the number of bits in each input integer, and let $T_A(n)$ be the worst-case running time of machine $A$ on inputs of $n$ bits. This model measures its costs against [Schönhage–Strassen multiplication](schonhage-strassen.md). Their result is that <cite data-source="paper">two n-bit integers can be multiplied in O(n log n log log n)</cite> time on a multitape Turing machine, and its authors <cite data-source="paper">conjectured n log n as the optimal order of multiplication cost</cite>. This model restricts [The n log n optimality conjecture](n-log-n-conjecture.md) to one fixed machine at a time.

This model states its lower bounds with [Big-Omega notation](big-omega-notation.md). <cite data-source="paper">In the present fixed-tape model, an eventual lower bound for every multiplication machine means</cite> that for each fixed machine $A$ there are constants $c_A>0$ and $N_A$ with $T_A(n)\ge c_A\,n\lg n$ for all $n\ge N_A$. In $\Omega$ notation, this says $T_A(n)=\Omega(n\lg n)$.

This model decides the lower-bound question by the [limit inferior](limit-inferior.md) of the ratio $T_A(n)/(n\lg n)$. If $T_A(n)\ge c_A\,n\lg n$ for all $n\ge N_A$, the ratio is at least $c_A$ from $N_A$ on, so its limit inferior is at least $c_A>0$. A machine whose ratio has limit inferior zero therefore satisfies no such bound, for any $c_A>0$ and $N_A$.

The paper's Theorem 1 supplies such a machine. <cite data-source="paper">There is one deterministic Turing machine A, with a fixed finite alphabet and a fixed</cite> finite number of one-dimensional tapes. <cite data-source="paper">Its worst-case running time satisfies</cite> $T_A(n)=O(n(\lg n)^{1-\kappa})$, where $\kappa=2^{-182}$. The paper states that <cite data-source="paper">The theorem refutes an eventual Ω(n log n) lower bound</cite> in this model, so not every fixed multiplication machine has the eventual lower bound.

The $O$ gives a constant $C$ with $T_A(n)\le C\,n(\lg n)^{1-\kappa}$ for all large $n$. Dividing by $n\lg n$ gives $T_A(n)/(n\lg n)\le C(\lg n)^{-\kappa}$. The ratio is nonnegative, and the right side tends to zero because $\kappa>0$ and $\lg n$ grows without bound. So the ratio's limit inferior is zero, and $A$ satisfies no bound $T_A(n)\ge c_A\,n\lg n$ for $n\ge N_A$ with any $c_A>0$.
