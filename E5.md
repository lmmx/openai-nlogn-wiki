# E5: Opus at medium effort for planning, against E1's Sonnet-high general-purpose arm

Records of experiment E5, run in the development session of lmmx/exegenius (plan:
`calibration/plans/E5.md` at b03e7a3; analysis: `docs/journal/2026-10-14-e5-opus.md`). This
branch starts from `131026-exp-e1-config`, whose G1–G5 runs are the comparison arm.

- `runs/N1`–`N5`: five fresh planning-only runs with E1's configuration (`runs/G1/exegenius.toml`,
  byte for byte) and `template/sources/paper.tex` (the copies in the run directories are
  omitted; they were byte-identical). Binary: exegenius master af36d6d (cc70355 plus a status
  message fix). Each task's prompt as `exegenius next` printed it went word for word to a fresh
  `general-purpose` subagent with `model: "opus"`, `effort: "medium"`; every run was stopped
  when `next` handed out write tasks. `status.txt` is `exegenius status` at that point.
- `results/transcripts/e5/subagents/`: the fifteen planning subagents' transcripts with their
  `.meta.json` (description `RUN TASK`). Every assistant message is `claude-opus-5-5` at effort
  `medium`. No restarts.

The orchestrator was the development session (Opus, high effort), with that session's
permissions rather than this branch's `.claude/settings.json`; it only passed prompts and ran
`exegenius next` and `status`.
