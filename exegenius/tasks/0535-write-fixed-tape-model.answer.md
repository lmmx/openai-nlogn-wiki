A fixed-tape machine model is a Turing machine whose alphabet and number of tapes are fixed in advance, so they do not grow with the input; only the contents of the tapes grow. The main result, [Integer multiplication below n log n](main-theorem.md), is stated in this model.

A fixed-tape machine is constrained in three ways: its alphabet is fixed, its number of tapes is fixed, and its tapes are one-dimensional. As the paper puts it, <cite data-source="paper">A machine has one fixed finite alphabet and one fixed finite number of one-dimensional tapes.</cite> A one-dimensional tape is a row of cells. Each step is local: a step <cite data-source="paper">reads and writes at most one cell on each tape and moves each head by at most one cell.</cite> For example, if a tape holds 1011 with its head on the first cell, one step can overwrite that 1 with 0 and move to the second cell, but cannot reach the fourth. Reaching a cell $k$ cells away therefore takes at least $k$ steps.

Let $n$ be the number of bits in each input integer, and for a machine $A$ let $T_A(n)$ be its running time on inputs of $n$ bits. Write $\log$ for $\log_2$ in $n\log n$, and $\lg n$ for $\log_2 n$ rounded up to an integer and never below $1$. They differ by at most a factor of $2$ for $n \geq 2$.

Costs in this model are measured against [Schönhage–Strassen multiplication](schonhage-strassen.md). That method shows that <cite data-source="paper">two n-bit integers can be multiplied in O(n log n log log n)</cite> time on a multitape machine. Its authors <cite data-source="paper">conjectured n log n as the optimal order of multiplication cost</cite>. This model restricts [the n log n optimality conjecture](n-log-n-conjecture.md) to one machine at a time.

In this model, lower bounds are stated with [Big-Omega notation](big-omega-notation.md). Here $\Omega(g)$ denotes the functions that are at least a positive constant times $g$ for all large inputs. <cite data-source="paper">In the present fixed-tape model, an eventual lower bound for every multiplication machine means</cite> that for each fixed machine $A$ there are a constant $\sigma>0$ and a threshold input length $n_0$, depending on $A$, with $T_A(n) \geq \sigma\, n\log n$ for all $n \geq n_0$. In the $\Omega$ notation, this says $T_A(n)=\Omega(n\log n)$.

In this model the lower-bound question is decided by the [limit inferior](limit-inferior.md) of the ratio $T_A(n)/(n\log n)$. If $T_A(n) \geq \sigma\, n\log n$ for all $n \geq n_0$, then this ratio is at least $\sigma$ from $n_0$ on, so its limit inferior is at least $\sigma>0$. A machine whose ratio has limit inferior zero therefore satisfies no such bound with any $\sigma>0$, and it refutes the claim that every machine has one.

The paper's Theorem 1 supplies such a machine: <cite data-source="paper">There is one deterministic Turing machine A, with a fixed finite alphabet and a fixed</cite> finite number of one-dimensional tapes, and its worst-case running time satisfies $T_A(n)=O(n(\lg n)^{1-\kappa})$, where $\kappa=2^{-182}$. The method behind this bound <cite data-source="paper">uses linear combinations of intermediate data to reduce the</cite> <cite data-source="paper">cost of both address rearrangement and Fourier-transform layers.</cite>

The $O$ gives a constant $C$ with $T_A(n) \leq C\, n(\lg n)^{1-\kappa}$ for all large $n$. Dividing by $n\lg n$ gives $T_A(n)/(n\log n) \leq C(\lg n)^{-\kappa}$. The ratio is nonnegative, and the right side tends to zero because $\kappa>0$ and $\lg n$ grows without bound. So the ratio tends to zero and its limit inferior is zero. <cite data-source="paper">The power saving proved here gives a limit of zero through all input lengths</cite>.

The theorem refutes an eventual $\Omega(n\log n)$ lower bound <cite data-source="paper">for every fixed multiplication machine in</cite> this model.
