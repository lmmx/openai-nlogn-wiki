## This page

Concept: Packed selected-bit addition
Gloss: A binary row addition (XOR) of selected bits across many address chunks at once, done by a constant number of whole-chunk cyclic shifts using a third chunk of arbitrary contents as temporary storage, followed by a deterministic repair of an explicitly bounded set of exceptional addresses.

## This page in the argument

The step: A binary row addition on selected bits of two address chunks is done by a constant number of whole-chunk cyclic shifts, using a third chunk of arbitrary contents as temporary storage, plus a repair of an explicitly bounded set of exceptional addresses.

It serves these steps, from the main result down:

- One deterministic fixed-tape Turing machine multiplies two $n$-bit integers exactly in time $O(n(\lg n)^{1-\kappa})$ with $\kappa=2^{-182}$.; how: Keep the transform-based multiplication of Harvey and van der Hoeven (Gaussian resampling, Bluestein chirp, synthetic polynomial transforms) but replace its two costly tape operations, address rearrangement and butterfly layers, by faster procedures obtained from rank-saving linear networks, then check exactness and total cost. (on [Integer multiplication in O(n (lg n)^(1−κ)) time](main-theorem.md))
- Two tape procedures cost $O(Vu^\tau)$ for interchanging two address fields of $u$ bits and $O(Vd^{\lambda'})$ for a butterfly layer on at most $d$ chunks, where $V$ is the stored bit volume, $\tau<1$ and $\lambda'<1$.; how: Derive both procedures from the same device: a fixed linear network whose edge changes are cheaper smaller calls of the same procedure, on top of elementary linear-time stream operations.
- The map $H_0(u,v)=((u+v)/2,(u-v)/2)$ is applied at once to the same bit position of $D\le d$ address chunks of every polynomial record, with one final truncation, in $O(Vd^{\lambda'})$ for a fixed $\lambda'<1$.; how: Write $H_0^{\otimes D}$ as phase factors around the tensor power $C^{\otimes D}$ of the two-point kernel, evaluate $C^{\otimes D}$ by the complex phase network with smaller layers as children, implement the binary changes of basis by packed selected-bit additions, bound the intermediate dyadic widths, and solve the recurrence. (on [Simultaneous butterfly layer in time O(V d^λ′)](simultaneous-butterfly-layer.md))

## Evidence from the sources, with the paragraph around each quote

- "We implement a binary row addition on corresponding selected bits in two" (paper)

  > We implement a binary row addition on corresponding selected bits in two address chunks. A third chunk supplies temporary address bits; its arbitrary initial value must be restored. The construction first uses a constant number of cyclic shifts of whole chunk ranges, then corrects an explicitly bounded set of addresses. The correction depends only on addresses, so the time bound is worst-case over all payloads.

- "y_{j_i}\longleftarrow y_{j_i}\mathbin\oplus x_{j_i}" (paper)

  > <K$. Let $N_0,N_1,N_2,N_3$ be positive integers, and let $(\chi_1,\chi_2,\chi_3)$ be a permutation of $(x,y,z)$. Consider $R$-bit records in lexicographic order on \[ [N_0]\times[2^L]_{\chi_1}\times[N_1]\times[2^L]_{\chi_2} \times[N_2]\times[2^L]_{\chi_3}\times[N_3]. \] The subscript names the chunk at that position. The input supplies $N_0,\ldots,N_3,R,K,f,\rho$ as a fixed number of canonical binary integers, together with the finite permutation of the chunk names, as in Section~\ref{sec:streams}. Put \[ M=2^{3L}\prod_{h=0}^3N_h,\qquad V=MR,\qquad A_{\rm rect}=\lceil\log_2(2V)\rceil. \] At the selected positions $j_i=\rho+iK$, numbered from the least significant bit, one fixed multitape procedure performs \[ y_{j_i}\longleftarrow y_{j_i}\mathbin\oplus x_{j_i} \quad(0\le i<f). \] It preserves the spectator coordinates, all other chunk bits, and every record payload; in particular, it restores the entire chunk $z$ for every initial value. With $\delta_{\rm bad}=\min\{1,80(f-1)2^{-K}\}$, its time is \begin{equation} \label{eq:packed-rectangle-time} O\!\left(V(L^\tau+1)+MA_{\rm rect}^3+ \delta_{\rm bad}MA_{\rm rect}(R+A_{\rm rect})\right). \end{equation} When $A_{\rm rect}=O(p)$, $R$ exceeds every fixed polynomial in $p$, $f\le d\le p$, and $K/\log p\to\infty$, this is $O(V(L^\tau+1))$, uniformly over the permitted lengths and payloads in the fixed family. \end{lemma}
