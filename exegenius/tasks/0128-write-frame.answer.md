A frame of a vertex is an invertible linear operator attached to a gate of a [Linear network](linear-network.md), or to a [Source, sink and terminal of a network](network-terminal.md) of it, that fixes how the array on each wire there is stored. It keeps the net effect of a route on each role's array a single operator, which the interchange argument needs. That argument swaps two equal address fields by sending data along routes of the network.

On this page $u$ and $v$ denote vertices, not the butterfly inputs of earlier pages. For a vertex $v$, $D_v$ is the frame of $v$: an invertible linear operator on the space of arrays indexed by the common address set, the fixed finite set of positions that every role's array is indexed by. If $g$ is the logical array on a wire at $v$, the stored array is $D_v g$. All incidences of one gate share its frame.

Along an edge from $u$ to $v$, the frame change $D_vD_u^{-1}$ converts the stored form at $u$ into the stored form at $v$. Applied to $D_u g$, it gives $D_vD_u^{-1}D_ug = D_vg$. <cite data-source="paper">changes the stored array from $D_ug$ to $D_vg$</cite> For example, if $D_u = I$ and $D_v = 2I$, the change along the edge doubles the stored array.

Here $t$ is the number of inputs, $j$ indexes them, and $c_j$ is a fixed scalar. A pointwise linear gate $G$ at vertex $v$ with input arrays $g_1,\ldots,g_t$ outputs $\sum_{j=1}^{t} c_j g_j$ at every address. Because $D_v$ is linear, $\sum_{j=1}^{t} c_j (D_v g_j) = D_v\bigl(\sum_{j=1}^{t} c_j g_j\bigr)$. So $G$ applied to the stored arrays $D_v g_1,\ldots,D_v g_t$ gives $D_v$ applied to its logical output: the gate computes on stored arrays as it would on logical ones.

The argument needs frames because a role's array may change representation along the network. A route is a chain of vertices $x_0,x_1,\ldots,x_s$ with an edge from each $x_{l-1}$ to $x_l$, where $s$ is the number of edges and $l$ indexes them; $x_0$ is a source and $x_s$ a sink. The $l$-th edge applies $D_{x_l}D_{x_{l-1}}^{-1}$, so the route applies
$$D_{x_s}D_{x_{s-1}}^{-1}\cdots D_{x_2}D_{x_1}^{-1}\,D_{x_1}D_{x_0}^{-1}.$$
Each adjacent pair of factors meets as $D_{x_l}^{-1}D_{x_l}=I$, which cancels, so by induction the product reduces to the endpoint operator $D_{x_s}D_{x_0}^{-1}$. Composing the frame changes along a route therefore leaves only the frames at its two ends. <cite data-source="paper">Thus the intermediate frames cancel</cite>
