## This page

Concept: Subspace labels and the rank budget
Gloss: Each gate and terminal of the network gets a nested nondegenerate subspace of an m-dimensional space, so an edge costs its dimension change, and the only decreasing edges are central wires, keeping the total below the wire count times m.

## This page in the argument

The step: Attaching to each gate and terminal a nondegenerate subspace of an $m$-dimensional space, nested along every edge, makes an edge cost its dimension change; only the central wires lose dimension, with total loss $L<N/2$, so the sum of absolute dimension changes is $Wm-2N+2L$.
How: Choose labels from tensor products of 3-subset indicator lines and their orthogonal complements, and read off the dimension change on each edge.
Why: Ordering the gates so that every decrease happens on one return edge per central wire keeps the loss small and makes all other edges increase. (the sources say so: "The gate order below confines all decreases to this return, while the other edges realize the prescribed stage transitions." (paper))
Striking feature: All dimension loss is confined to a single return edge on each central wire, each losing exactly the same amount $h$, in all three stages and all invocations, and the loss ratios $100/539$ and $101/539$ are both below one half. (explain why it holds, from the method)

Its sub-steps, in order:

- Every triple line is nondegenerate and neighbouring triple lines are orthogonal, so the label spaces can be nested along every edge.
- Every edge joins comparable nondegenerate labels, and the only decreasing edges are the central-wire edges from time 3 to time 4, each losing dimension $h$.
- Signed dimension changes telescope to $Wm-2N$, and replacing them by absolute changes adds $2L$.
- The loss ratios are $L_{\rm b}/N=100/539$ and $L_{\rm c}/N=101/539$, both below $1/2$.

It serves these steps, from the main result down:

- A single deterministic fixed-tape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$, using fast address interchange and fast simultaneous butterfly layers inside a Gaussian-resampling, chirp and synthetic-transform reduction.; how: Reduce the product to a convolution evaluated through Gaussian-resampled, chirped synthetic transforms, make the two costly tape operations (address movement and butterfly layers) cheaper by a power of the logarithm using networks with a rank saving, and then assemble the algorithm and add up its costs. (on [Integer multiplication below n log n](main-theorem.md))
- There are two fixed linear networks, a bit network over $\mathbb F_2$ and a complex network over $\mathbb Z[i,1/2]$, that exchange two banks of values with prescribed signs, restore every scratch wire, and have total edge rank $s<Wm$.; how: Build a scalar exchange network from subset-intersection gates, attach nested nondegenerate subspaces to its gates so that an edge costs only its dimension change, and count the dimension changes.

**S3.3.1**: Every triple line is nondegenerate and neighbouring triple lines are orthogonal, so the label spaces can be nested along every edge.
Source: "Thus every triple line is nondegenerate, and neighboring triple lines are orthogonal, in the label field belonging to either construction." (paper)
> For the bit network, let $F=\mathbb Q^h$ with bilinear form \[ \langle x,y\rangle=x^{\mathsf T}(I-J/9)y, \] where $J$ is the all-one matrix. This form has eigenvalues $1$ and $1-h/9=-91/9$, so it is nondegenerate. For a triple $T$ let $t_T$ be its indicator vector. Then \[ \langle t_S,t_T\rangle=|S\cap T|-1, \qquad \langle t_T,t_T\rangle=2. \] For the complex network, take instead $F=\mathbb F_2^h$ with the ordinary dot product; here $t_T\cdot t_T=1$. Thus every triple line is nondegenerate, and neighboring triple lines are orthogonal, in the label field belonging to either construction. The scalar domain need not equal the label field. These degree-one intersection formulas specialize the construction described by Alon~\cite[Section~3, remark after Theorem~1.1]{Alon1998} to the prime $2$, with the ground-set size changed to $h=100$.

**S3.3.2**: Every edge joins comparable nondegenerate labels, and the only decreasing edges are the central-wire edges from time 3 to time 4, each losing dimension $h$.
Source: "The only decreasing edges are the central-wire edges from time 3 to time 4; their dimension loss is $h$." (paper)
> \begin{lemma}\label{lem:motif-residuals} Every edge joins comparable nondegenerate labels. The only decreasing edges are the central-wire edges from time 3 to time 4; their dimension loss is $h$. Consequently, if $c$ is the number of central wires per invocation and $W$ the total number of wires, then \begin{equation} L=Ich,\qquad \sum_{e}\bigl|\dim U_{\mathrm{head}(e)}- \dim U_{\mathrm{tail}(e)}\bigr| =Wm-2N+2L. \label{eq:rank-budget-labels} \end{equation} For the binary label space, every nonzero orthogonal residual of an edge has an orthonormal basis. \end{lemma}

**S3.3.3**: Signed dimension changes telescope to $Wm-2N$, and replacing them by absolute changes adds $2L$.
Source: "There are $Ic$ decreasing edges, each of loss $h$; replacing signed changes by absolute changes adds $2L$." (paper)
> The signed sum of dimension changes telescopes at every gate: each touched wire has one incoming and one outgoing incidence with the same gate label. The sum of source dimensions is $N$, while the sum of sink dimensions is $Wm-N$. The signed increase is therefore $Wm-2N$. There are $Ic$ decreasing edges, each of loss $h$; replacing signed changes by absolute changes adds $2L$.

**S3.3.4**: The loss ratios are $L_{\rm b}/N=100/539$ and $L_{\rm c}/N=101/539$, both below $1/2$.
Source: "In particular, both are smaller than $1/2$." (paper)
> The loss ratios have the exact values \[ \frac{L_{\rm b}}{N}=\frac{100}{539},\qquad \frac{L_{\rm c}}{N}=\frac{101}{539}. \] In particular, both are smaller than $1/2$. We now turn the dimension count into the two interfaces needed later.

## Evidence from the sources, with the paragraph around each quote

- "The saving will come from keeping the total dimension lost on decreasing edges small relative to $N$." (paper)

  > The scalar network already has the required signed exchange. We now choose its intermediate labels to make the changes of frame inexpensive. A label is a nondegenerate subspace of a fixed bilinear space. On every edge one label will contain the other. For such an edge, the \emph{orthogonal residual} is the orthogonal complement of the smaller label inside the larger one; its dimension is the absolute change in label dimension. The saving will come from keeping the total dimension lost on decreasing edges small relative to $N$.
