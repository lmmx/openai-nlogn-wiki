The limit inferior of a sequence of real numbers is the smallest value that the sequence keeps approaching as its index grows. The paper uses it to state the negation of a lower bound on multiplication time.

**Definition.** Here $k$ and $m$ are positions in a sequence, which is their meaning on this page only. Let $\chi_1, \chi_2, \chi_3, \dots$ be a sequence of real numbers, where $\chi_k$ is the $k$-th term. For each position $m$, let $\tau_m$ be the infimum of the tail from position $m$ on: the largest real number that is at most every term $\chi_k$ with $k \ge m$. A tail from $m+1$ is a subset of the tail from $m$, so $\tau_m \le \tau_{m+1}$. The limit inferior takes its values in the [extended real numbers](extended-reals.md), because a nondecreasing sequence there has a limit, its supremum. It is this limit:
$$\liminf_{k\to\infty} \chi_k = \lim_{m\to\infty} \tau_m.$$

**Zero limit inferior for nonnegative sequences.** Suppose every $\chi_k \ge 0$, and let $\varepsilon > 0$ be a real tolerance. Then every $\tau_m \ge 0$, so the nondecreasing sequence $\tau_m$ has limit $0$ exactly when every $\tau_m = 0$. Now $\tau_m = 0$ means $\varepsilon$ is not a lower bound of the tail, so some $k \ge m$ has $\chi_k < \varepsilon$. Requiring this for every $m$ gives infinitely many such $k$. Conversely, if infinitely many $k$ have $\chi_k < \varepsilon$, every tail has a term below $\varepsilon$, so $0 \le \tau_m < \varepsilon$ for all $m$.

**Use in the paper.** Here $\lg$ is the [base-2 logarithm](base-two-logarithm.md), and $A$ is a fixed machine whose running time $T_A(n)$ is the largest number of steps it takes on an input of $n$ bits. Below, $\delta$ is a real number greater than zero and $\Gamma$ is a threshold on input length, both arbitrary. The $n\log n$ optimality conjecture says that for each fixed machine $A$ there are a constant $\delta_A > 0$ and a threshold $\Gamma_A$ with
$$T_A(n) \ge \delta_A\, n\lg n \quad \text{whenever } n \ge \Gamma_A.$$
The paper states it as <cite data-source="paper">for each fixed machine A, there are constants cA > 0 and NA such that TA (n) ≥ cA n lg n</cite>.

Let $\rho_n = T_A(n)/(n\lg n)$ for $n \ge 2$. The limit inferior is applied to this ratio against the order that the authors of [Schönhage–Strassen multiplication](schonhage-strassen.md) conjectured optimal. The negation for $A$ says that for every such $\delta$ and every such $\Gamma$, some $n \ge \Gamma$ has $\rho_n < \delta$. The quantifier over every threshold asks for infinitely many small ratios, which is what the limit inferior captures. By the zero criterion, the negation is equivalent to $\liminf_{n\to\infty} \rho_n = 0$. The paper states it as <cite data-source="paper">Its negation requires one machine satisfying lim inf n→∞ TA (n)/(n lg n) = 0.</cite>

The main theorem gives the fixed machine $A$ a time bound. Here $\kappa = 2^{-182}$ is a fixed exponent with $0 < \kappa < 1$, and $C$ is a constant, so $T_A(n) \le C\, n(\lg n)^{1-\kappa}$ for all large $n$. The page uses this bound without proof: <cite data-source="paper">We give a deterministic algorithm that multiplies two n-bit integers in O(n(lg n)1−κ )</cite>.

Dividing by $n\lg n$ gives $0 \le \rho_n \le C(\lg n)^{-\kappa}$ for all large $n$, and $C(\lg n)^{-\kappa} \to 0$ since $\kappa > 0$. For large $m$, the tail from $m$ contains $\rho_m$, so $0 \le \tau_m \le \rho_m \le C(\lg m)^{-\kappa}$. By the squeeze principle (a sequence trapped between two sequences tending to zero also tends to zero), $\tau_m \to 0$, so $\liminf_{n\to\infty} \rho_n = 0$.

This refutes the conjecture. Suppose it held for $A$ with $\delta_A$ and $\Gamma_A$; then $\rho_n \ge \delta_A$ for every $n \ge \Gamma_A$. But the zero criterion with $\varepsilon = \delta_A$ gives infinitely many $n$ with $\rho_n < \delta_A$, and one of them is at least $\Gamma_A$. The paper says <cite data-source="paper">The algorithm is exact for every input length and disproves the n log n</cite>.
