## This page

Concept: Convolution over the polynomial ring from the retained layout
Gloss: Normalized convolution of arrays over the ring modulo y^r + 1: two forward synthetic transforms, pointwise ring products by signed packing, then the opposite transform consuming the same frequency order, with error O(M ℓ 2^{-p}).

## This page in the argument

The step: Normalized convolution $\mathcal M_r(f,g)=(f*g)/T$ of arrays over $\mathbb C[y]/(y^r+1)$ is computed from the retained transform layout with error below $\sqrt2\,M(3\ell+1)2^{-p}$ in $O(Tp[dK+pK^{\tau-1}+\ell d^{\lambda'}+\log(rp)])$ time.
How: Apply the synthetic forward transform to both operands, multiply pointwise in the retained frequency order with signed packed products, apply the opposite transform that consumes that order, and scale by $M$.
Why: Pointwise multiplication commutes with any common record permutation, so the frequency order left by the forward transforms need not be restored before the product. (the sources say so: "forward outputs in their retained order and pass that order directly" (paper))

Its sub-steps, in order:

- The synthetic roots $\omega_t=y^{2r/t}$ satisfy character cancellation despite zero divisors, so $F_t^+F_t^-=t^{-1}I$. (on [Synthetic Fourier transform modulo y^r + 1](synthetic-transform.md))
- Decimation in frequency leaves the frequencies in bit-reversed order, so the two exact procedures implement $B_tF_t^-$ and $F_t^+B_t^{-1}$. (on [Radix-2 butterfly layers and stored frequency order](butterfly-layers.md))
- A forward or opposite synthetic transform on $d-1$ polynomial axes, arranged by a layout permutation, has error below $\sqrt2\,\ell\,2^{-p}$ and costs $O\bigl(Tp[dK+pK^{\tau-1}+\ell d^{\lambda'}]\bigr)$. (on [Layout and cost of the synthetic transform](transform-layout.md))
- Two polynomials of the ring with $p$-bit grid coefficients can be multiplied exactly by signed Kronecker packing and the established multiplier, returning $Q_p(fg/r)$ in $O(rp\log(rp))$. (on [Signed Kronecker packing of polynomial products](signed-kronecker-packing.md))
- Expanding the finite sums gives $F^-_{\boldsymbol t}(f*g)=M(F^-_{\boldsymbol t}f)(F^-_{\boldsymbol t}g)$, which together with $F^+F^-=I/M$ identifies the retained-order pipeline with $\mathcal M_r(f,g)$.
- Using contraction of the transforms and the bilinear product, the three transform errors and the product truncation add up to $\sqrt2\,M(3\ell+1)2^{-p}$.
- There are $M=T/r$ pointwise polynomial products, so the total cost is the three transform costs plus $O(Tp\log(rp))$, with the last scaling by $M$ linear.

It serves these steps, from the main result down:

- A single deterministic fixed-tape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ worst-case time with $\kappa=2^{-182}$.; how: Start from the Gaussian-resampling reduction of integer multiplication to convolution; replace the two costly operations of the synthetic transforms (address rearrangement and butterfly layers) by faster procedures built from one recursive linear-network exchange, assemble the exact algorithm, and account for its cost. (on [Multiplying n-bit integers in O(n (lg n)^(1−κ)) time](main-theorem.md))

- "Perform both forward transforms and retain their common $LB$ order." (paper)

The returned grid array is in the original array and coefficient order, with the same two's-complement component format at width $w_M$. The procedure supplies $\Gamma(w_M)$ on the output descriptor tape, so the caller knows every component boundary from this width and the retained shape parameters. If one operand has norm at most $\rho<1$ and the bound in \eqref{eq:synthetic-convolution-error} is at most $1-\rho$, the returned grid array is a disk array. \end{proposition} \begin{proof} Perform both forward transforms and retain their common $LB$ order. - "\mathcal M_r(f,g)=\frac{f*g}{rM}=\frac{f*g}{T}" (paper)

  > For arrays on $\prod_i\mathbb Z/t_i\mathbb Z$ with values in $\mathcal R_r$, let $*$ denote cyclic convolution in the displayed axes and define \[ \mathcal M_r(f,g)=\frac{f*g}{rM}=\frac{f*g}{T}. \] For a fixed output coefficient, each of the $M$ first cyclic addresses determines one second address, and each of the $r$ first polynomial indices determines one second index modulo $r$. The negacyclic wrap supplies the sign. Thus that coefficient averages $rM$ signed scalar products, and $\mathcal M_r$ is a bilinear contraction: \[ \|\mathcal M_r(f,g)\|_\infty \leq\|f\|_\infty\|g\|_\infty. \] If the other operand is a disk array, replacing one operand changes the output by at most the norm distance between its two values.
