## This page

Concept: Power-width address interchange
Gloss: Swapping two chunks of m^k digits by running the bit network with matrix shears as edges, each edge recursing into smaller interchanges, in time O(V e^τ).

## This page in the argument

The step: Two disjoint chunks of $e=m^k$ radix-$q$ digits, given enough rows, can be interchanged in time $O(Ve^\tau)$ by running the bit network with a matrix shear on every edge, each shear recursing into smaller interchanges.
How: Induct on $k$: split rows cyclically among the $W$ roles, apply frames $\Phi_M$ so every edge is a shear that costs $\operatorname{rank}$-many half-width interchanges, perform the middle shear with the circuit, and solve the volume-normalized recurrence.
Why: The network turns one interchange of width $m^k$ into $s$ interchanges of width $m^{k-1}$ on streams of volume $V/W$; because $s<Wm$ the normalized cost grows by a factor less than $m$ per level. (the sources leave this for the reader to work out: spell it out)
Striking feature: Each level makes $s$ calls on streams of volume $V/W$, with $s$ nearly $Wm$, yet the cost exponent $\tau$ is strictly below 1 because $s/W<m^\tau$. (explain why it holds, from the method)

Its sub-steps, in order:

- Split whole rows cyclically into $W$ role streams, each of volume $V/W$ with the same remaining shape.
- The row split supplies the common address set for the frame identity, with frame $\Phi_M$ at a vertex of matrix $M$, so the output is $\Phi_{I_m}$, the shear $H\leftarrow H+D$.
- To interchange the two full chunks, perform $D\leftarrow D-H$, $H\leftarrow H+D$, $D\leftarrow H-D$; only the middle shear uses the circuit.
- The number of recursive calls is the sum of the edge ranks, exactly $s$, each on a stream of volume $V/W$.
- With $s/W<m^\tau$ the recurrence $F_k\le(s/W)F_{k-1}+O(1)$ sums geometrically to $F_k=O(e^\tau)$.
- A fixed-tape depth-first schedule parks the inactive role streams on a stack, so the overhead per node is $O(V)$ and does not multiply the call count.

It serves these steps, from the main result down:

- A deterministic multitape Turing machine multiplies two $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$, disproving the $n\log n$ optimality conjecture in that model.; how: Reduce the product to a cyclic convolution of radix digits evaluated by Fourier-type transforms, make the two costly ingredients of those transforms (address rearrangement and butterfly arithmetic) cost a power of the logarithm less than a full scan per level by two rank-saving tape procedures, then assemble the algorithm, prove exactness and total the cost. (on [Sub-n log n integer multiplication](sub-nlogn-multiplication.md))
- Two equal-width address fields of $u$ bits in an arbitrary array can be exchanged in $O(Vu^\tau)$ time for a fixed $\tau<1$, even though intermediate steps XOR data together.; how: Run the bit exchange network with every edge a rational matrix shear executed by smaller interchanges, using the lower triangular factorization, then remove the width and row restrictions. (on [Fast chunk interchange](chunk-interchange.md))

**S2.3.6**: A fixed-tape depth-first schedule parks the inactive role streams on a stack, so the overhead per node is $O(V)$ and does not multiply the call count.
Source: "Before a recursive call, append the $W-1$ inactive role streams to the" (paper)
> Before a recursive call, append the $W-1$ inactive role streams to the parking stack in a fixed order, with separators. Copy the active stream to the child I/O area, and erase the parent role tapes while traversing their current contents. Push the parent descriptor and its finite program counter to the descriptor stack. The role and work tapes are now available to the child, using the same tapes at every depth. On return, copy the child output into the designated active role. Pop the inactive streams in reverse order. To recover a stream in its original direction, prepare its destination to the known length and write the popped symbols from the destination's right end toward its left end. Erase the popped stack cells as they are left. This uses linear time and ends with the parking head at the previously saved top. No scan passes through a parked ancestor. Cleanup is always limited to the region visited by the current call; a reused tape is not swept to the largest position ever visited by an ancestor.
