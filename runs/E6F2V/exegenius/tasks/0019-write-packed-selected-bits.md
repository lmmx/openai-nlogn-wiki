## This page

Concept: Packed XOR of selected bits across address chunks
Gloss: A binary row addition y ← y ⊕ x on the selected bit of each of f chunks at once, done by a constant number of cyclic shifts of whole chunk ranges followed by deterministic repair of a small explicit set of bad addresses, using a third chunk as restored temporary space.

## This page in the argument

The step: A row addition $y\gets y\oplus x$ on the selected bit of each of $f$ chunks is done at once, using a third chunk $z$ as temporary space restored for every initial value.
How: do eight guarded cyclic shifts of whole chunk ranges that are correct away from a small set of bad addresses, then repair those addresses by a deterministic sort
Why: Several selected bits cannot be changed independently by shifts without carries across segments; guard bits make carries impossible except at a few addresses, which are rare enough to fix by sorting. (the sources leave this for the reader to work out: spell it out)
Striking feature: A chunk holding arbitrary data serves as scratch space and is returned exactly, for every initial value, and the repair of the bad addresses depends only on addresses, not on payloads. (explain why it holds, from the method)

Its sub-steps, in order:

- Eight shifts, each controlled by the other chunk, flip the parity of $u$ exactly when $c=1$ and restore the auxiliary integer $w$.
- The bad addresses $\mathcal B$ are those where some guard value leaves the interval $[10,2^{K-1}-11]$.
- Exactly twenty values of each guard are excluded, so $|\mathcal B|\le\delta_{\rm bad}M$ with $\delta_{\rm bad}=\min\{1,80(f-1)2^{-K}\}$.
- Extract the records at bad addresses with their destination ranks, sort them stably by key, and reinsert them, which implements the ideal map everywhere.
- The omitted most significant selected position is handled by a two-bit XOR.
- The total time is $O(V(L^\tau+1))$ when the packed-record family bounds hold.

It serves these steps, from the main result down:

- A single deterministic fixed-tape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ worst-case time with $\kappa=2^{-182}$.; how: start from the Gaussian-resampling reduction of multiplication to transforms, make the transforms cheaper by two tape procedures that each save a power of the logarithm, then recover the product exactly and add up all costs (on [Multiplying n-bit integers in O(n (lg n)^(1−κ)) time](main-theorem.md))
- Two tape procedures cost a power of the width less than one per unit volume: interchange of two $u$-bit address chunks in $O(Vu^\tau)$ and a simultaneous butterfly layer on $d$ chunks in $O(Vd^{\lambda'})$.; how: build the elementary scans and one fixed linear exchange network whose edges have total rank $s<Wm$, and derive from it two recursions in which each level multiplies the cost per volume by $s/W<m$
- The tensor product $\mathcal H$ of $H_0$ on one selected bit in each of $D\le d$ address chunks of polynomial records is applied in $O(Vd^{\lambda'})$ time with $\lambda'<1$, exactly up to one final truncation.; how: express $H_0^{\otimes D}$ through the Gaussian-dyadic kernel $C^{\otimes D}$, realize $C^{\otimes e}$ by the rank-saving complex network recursively on slots using packed binary basis changes, and bound guard bits (on [Simultaneous butterfly layer in O(Vd^λ') time](simultaneous-butterfly-layer.md))
