A fixed-tape machine model is a Turing machine whose alphabet and number of tapes are fixed in advance, so they do not grow with the input; only the contents of the tapes grow. The paper *Integer multiplication below n log n* (OpenAI, 2026) states its main result in this model; see [Integer multiplication below n log n](main-theorem.md).

A fixed-tape machine is constrained in three ways: its alphabet is fixed, its number of tapes is fixed, and its tapes are one-dimensional, as the paper puts it: <cite data-source="paper">A machine has one fixed finite alphabet and one fixed finite number of one-dimensional tapes.</cite> A one-dimensional tape is a row of cells, with a head that sits on one cell at a time. The last constraint is locality: <cite data-source="paper">A step reads and writes at most one cell on each tape and moves each head by at most one cell.</cite> For example, suppose a tape holds 1011 with its head on the first cell. One step can overwrite that 1 with 0 and move the head to the second cell, but it cannot jump to the fourth cell. Reaching a cell $k$ cells away from the head therefore takes at least $k$ steps.

Let $n$ be the number of bits in each of the two input integers; here $n$ counts bits, not the sequence entries used on the convolution page. For a machine $A$, let $T_A(n)$ be its running time on inputs of $n$ bits. Write $\lg n$ for $\log_2 n$, and take $\log=\log_2$ in $n\log n$; another base only multiplies $n \log n$ by a constant, which changes none of the claims below.

Costs in this model are measured against [Schönhage–Strassen multiplication](schonhage-strassen.md). That method shows that <cite data-source="paper">two n-bit integers can be multiplied in O(n log n log log n)</cite> time on a multitape machine. Its authors, Schönhage and Strassen, <cite data-source="paper">conjectured n log n as the optimal order of multiplication cost</cite>. This model restricts [the n log n optimality conjecture](n-log-n-conjecture.md) to one machine at a time. For a fixed machine $A$, let $c_A$ be a positive constant and $N_A$ the input length from which the bound holds. <cite data-source="paper">In the present fixed-tape model, an eventual lower bound for every multiplication machine means</cite> that $T_A(n) \geq c_A\, n\log n$ for all $n \geq N_A$, for each fixed machine $A$.

In this model the lower-bound question is settled by the [limit inferior](limit-inferior.md) of the ratio $T_A(n)/(n\log n)$. If $T_A(n) \geq c\, n\log n$ for all $n \geq N$, with $c>0$, then this ratio is at least $c$ from $N$ on, so its limit inferior is at least $c>0$. A machine whose ratio has limit inferior zero therefore satisfies no such bound with any $c>0$, and it refutes the claim that every machine has one.

The paper's Theorem 1 gives such a machine: <cite data-source="paper">There is one deterministic Turing machine A</cite>, with a fixed finite alphabet and a fixed number of tapes, and <cite data-source="paper">Its worst-case running time satisfies</cite> $T_A(n) = O(n(\lg n)^{1-\kappa})$, where $\kappa = 2^{-182}$ is a fixed positive constant, the exponent saving. The $O$ gives a constant $C$ with $T_A(n) \leq C\, n(\lg n)^{1-\kappa}$ for all large $n$. Dividing by $n\log n = n\lg n$ gives $T_A(n)/(n\log n) \leq C(\lg n)^{-\kappa}$. The ratio is nonnegative and bounded by a quantity that tends to zero, so the ratio tends to zero and its limit inferior is zero. The theorem refutes an eventual $\Omega(n\log n)$ lower bound <cite data-source="paper">for every fixed multiplication machine in</cite> this model.
