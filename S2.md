# S2: model × effort screen with the E7 instructions

Records of experiment S2, run in the development session of lmmx/exegenius (plan and ledger:
`calibration/plans/S2.md`; analysis: `docs/journal/2026-10-14-s2-model-effort.md`).
This branch starts from `141026-exp-e7-key-step-identity`, whose run E7F1W (Sonnet, `high`) is
the reference.

- `runs/S2F1SX`, `S2F1OX`, `S2F1SM`, `S2F1OM`: copies of E6's project E6F1 (background
  accepted), with the argument task rendered by exegenius branch `141026-exp-key-step-identity`
  (91c4fed), byte-identical to E7F1W's task apart from the project path. Each prompt as
  `exegenius next` printed it went word for word to a fresh `general-purpose` subagent:
  - `S2F1SX`: `model: "sonnet"`, `effort: "xhigh"`;
  - `S2F1OX`: `model: "opus"`, `effort: "xhigh"`;
  - `S2F1SM`: `model: "sonnet"`, `effort: "max"`;
  - `S2F1OM`: `model: "opus"`, `effort: "max"`.
  Every run was accepted on its first submit and stopped when `next` handed out write tasks.
  The runs' own helper files are kept; `__pycache__` and Rust build output (`target/`) are not.
- `results/transcripts/s2/subagents/`: the four argument subagents' transcripts and
  `.meta.json` (description `F1xx 0003-argument`). No restarts. Row 1 ran alone; rows 2-4 ran
  in parallel after a usage-window reset.
