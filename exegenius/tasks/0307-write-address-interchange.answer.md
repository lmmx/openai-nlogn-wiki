Fast address-chunk interchange is the first tape procedure behind the main result. It exchanges two disjoint equal-width address fields of an array on fixed tapes, at a cost per stored bit that is a power of the width.

The array holds $V$ bits, addressed by $(p,h,g,d,z)$: a prefix $p$, chunks $h$ and $d$ of $u$ bits each, a gap $g$ and a suffix $z$. The goal is $(p,h,g,d,z)\mapsto(p,d,g,h,z)$. Letters change meaning: $u$ is a chunk width in bits, not a DFT input sequence; $p$ is an address prefix, not a number of fractional bits; $h$ is the first chunk, not a remaining index or ground-set size; $d$ is the second chunk, not an axis count; $q$ is the digit radix, not a sequence length; $M$ is a vertex matrix, not an address count; $j$ is a recursion level, not a digit value, wrap count or stage number.

The procedure takes $O(Vu^\tau)$ steps <cite data-source="paper">Its cost is $O(Vu^\tau)$ for a fixed $\tau<1$.</cite>, with $\tau=1-2^{-50}$ <cite data-source="paper">For both recurrences we may use the fixed rational exponent</cite>. Its intermediate steps form XOR combinations of data, yet the result is exact for arbitrary initial auxiliary values <cite data-source="paper">The final permutation is exact for arbitrary initial auxiliary values.</cite>.

For chunk values $H$ and $D$, the interchange of the two full chunks is $D\gets D-H$, then $H\gets H+D$, then $D\gets H-D$, componentwise; only the middle shear uses the circuit.

Let each chunk have $e=m^k$ radix-$q$ digits, where $k$ counts recursion levels and $m$ is the label-space dimension below. Write each chunk as $m$ consecutive $b=e/m$ digit fields, giving vectors $H,D$ over $\mathbb Z/q^b\mathbb Z$, and first construct the shear $H\gets H+D$.

The circuit is the [Linear exchange network with restored scratch wires](exchange-network.md) on $W$ wires. Each source, gate and sink carries a rational $m\times m$ matrix $M$, and edge $i$ carries $A_i=M_{\mathrm{head}(i)}-M_{\mathrm{tail}(i)}$. Let $s=\sum_i\operatorname{rank}A_i$. The shear contract routes input wire $w$ to an output role $\rho(w)$ with $M_{\mathrm{out}(\rho(w))}-M_{\mathrm{in}(w)}=I_m$. By [Nested subspace labels and rank deficit](subspace-labels.md), $s<Wm$. The relative deficit $(Wm-s)/(Wm)$ exceeds $20\cdot2^{-50}$ <cite data-source="paper">Both exact deficits displayed above are greater than $20\cdot2^{-50}$.</cite>, and $\log m<20$ gives $m^{-2^{-50}}>1-20\cdot2^{-50}$, so $s/W<m^\tau$ for $\tau=1-2^{-50}$. The deficit is tiny, so $\tau$ is close to 1.

Let $\Phi_M$ move the entry at address $(H,D)$ to $(H+MD,D)$; then $\Phi_{M'}\Phi_M=\Phi_{M'+M}$. In [Frames on wire arrays](array-frames.md), the frame at a vertex with matrix $M$ is the address permutation $\Phi_M$ and every edge changes it by $\Phi_{M'-M}$; a common address permutation commutes with every pointwise bit gate. On every circuit edge we apply $\Phi_{A_i}$ to that role stream, performed by [Matrix shear by triangular factorization](matrix-shear.md), recursively interchanging each pivot pair of $b$-digit fields: an edge matrix of rank $a$ costs exactly $a$ interchanges of pairs of $b$-digit fields, plus $O(V)$ further work <cite data-source="paper">An edge matrix of rank $a$ will require $a$ smaller interchanges.</cite>.

Suppose a row field of length divisible by $W^k$ precedes both chunks. The [Elementary stream operations](stream-ops.md) split whole rows cyclically into $W$ role streams within each prefix: the row with number remainder $w-1$ modulo $W$ goes to stream $w$. Each stream has logical volume $V/W$ and its row count is divisible by $W^{k-1}$, so the same argument applies one level down.

Read the input $f_w$ of wire $w$ as the logical array $\Phi_{-M_{\mathrm{in}(w)}}f_w$. By the shear contract, the physical output is $f'_{\rho(w)}=\Phi_{M_{\mathrm{out}(\rho(w))}}\Phi_{-M_{\mathrm{in}(w)}}f_w=\Phi_{I_m}f_w$. Merging each row of role $\rho(w)$ back to its original row undoes $\rho$, and the result is $H\gets H+D$ on every original row, including rows assigned to scratch roles whose initial values were arbitrary.

The number of recursive calls is the sum of the edge ranks, exactly $s$ <cite data-source="paper">The number of recursive calls is the sum of the edge ranks, exactly $s$.</cite>, each on one stream of volume $V/W$. Splitting, merging, gates and the parking-stack scheduling of the $s$ calls cost $O(V)$ at the node, a fixed number of operations on its own volume. So $F_k$, the time divided by logical volume at width $m^k$, obeys $F_0=O(1)$ and $F_k\le(s/W)F_{k-1}+O(1)$, the recurrence of [Recursive power saving](rank-recurrence.md), because each of the $s$ calls has $1/W$ of the volume.

Unrolling over the levels $j$ gives $F_k=O\big(\sum_{j=0}^k (s/W)^j\big)$. If $s/W\le1$, every term is at most $1$, so the sum is at most $k+1=O(m^{k\tau})$. If $s/W>1$, the geometric series gives $O((s/W)^k)$, and $(s/W)^k<m^{k\tau}$. So, since $e=m^k$, $F_k=O(e^\tau)$ <cite data-source="paper">Hence $F_k=O(e^\tau)$.</cite>.

For any number $e$ of digits, let $k'=\lceil\log_m e\rceil$ be the levels needed and $\nu=\lceil k'\log W/(2\log q)\rceil$ the number of top digits set aside, so $q^{2\nu}\ge W^{k'}$ and, for large $e$, $\nu=O(\log 2e)$. Write each chunk as its top $\nu$ digits and the rest, $h^+,h^-$ and $d^+,d^-$. Interchange the top digits pairwise and join them: $(h^+,h^-,g,d^+,d^-)$ becomes $(d^+,h^+,h^-,g,d^-)$. The first two fields form a row field of range $\Lambda=q^{2\nu}\ge W^{k'}$ before both remaining chunks. Pad with zero rows, separately within each prefix, to the padded row count $\Lambda'=W^{k'}\lceil\Lambda/W^{k'}\rceil<2\Lambda$, so the volume stays below $2V$.

Write the remaining width in base $m$: $e-\nu=\sum_{j=0}^{k'}a_jm^j$ with $0\le a_j<m$, where $a_j$ is the number of pieces of width $m^j$ in each chunk. Interchange corresponding pieces by the power-width case. The total cost is $O(V)\sum_ja_jm^{j\tau}=O(Ve^\tau)$, since $a_j<m$ and $m^{k'}<me$ make this a geometric sum of order $e^\tau$.

For $u$-bit chunks, let $e$ be the least integer with $q^e\ge2^u$ and pad each chunk range from $2^u$ values to $q^e$ values, with zeros. Since $e=O(u)$ for fixed $q$, the cost is $O(Vu^\tau)$ <cite data-source="paper">Since $e=O(u)$ for fixed $q$, the bound is $O(Vu^\tau)$.</cite>.
