## This page

Concept: Linear exchange network with restored scratch wires
Gloss: A fixed network of linear gates on wires (each with a role) that, for arbitrary initial scratch values, exchanges two banks of values with prescribed signs and restores every scratch wire; run in eight rows of copy, gather, scatter and side-injection steps.
Also called: bank exchange, finite network, role

## This page in the argument

The step: A fixed linear network with $W$ wires exchanges two banks of values, with signs, and restores every scratch wire whatever its initial value.
How: run the eight-row schedule: subtract the old scratch effect, add the source effect, restore the scratch values, then compose three stages
Why: Because the scratch wires may hold arbitrary values (they will be existing data rows when the network is run on arrays), the schedule must cancel their contribution before and after use; the paper reads this as a linear form of transparent computation. (the sources leave this for the reader to work out: spell it out)
Striking feature: Scratch wires return to their arbitrary initial contents, so the network behaves as an exact permutation of the data banks even though its intermediate states are linear combinations. (explain why it holds, from the method)

Its sub-steps, in order:

- For arbitrary initial scratch values, a forward invocation changes $y_S$ to $y_S+x_S$ and leaves every other value unchanged.
- Three stages (forward, inverse forward, forward) send $(X_a,Y_a)$ to $(-Y_a,X_a)$ and restore every auxiliary value; over $\mathbb F_2$ this is the exchange of $X_a$ and $Y_a$.

It serves these steps, from the main result down:

- A single deterministic multitape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$, disproving the $n\log n$ optimality conjecture.; how: reduce integer multiplication to convolution over a polynomial ring, and speed up the data movement and the butterfly layers of its transforms with two new tape procedures that each save a power of the logarithm (on [Integer multiplication below n log n](main-theorem.md))
- Two disjoint contiguous address fields of $u$ bits can be interchanged, $(p,h,g,d,z)\mapsto(p,d,g,h,z)$, in $O(V u^{\tau})$ time for a fixed $\tau<1$.; how: use the bit network, whose edges are address shears, to swap power-of-$m$ widths recursively, then remove the width and row-count restrictions (on [Fast address-chunk interchange](address-chunk-interchange.md))
- A fixed linear network whose total number $s$ of smaller calls is less than $W m$ gives a cost-per-volume recurrence with ratio $s/W<m$, hence a power-saving exponent $\tau<1$.; how: build a bank-exchanging network whose edge changes can be done by smaller instances of the same task, and bound the recursion by the total rank $s$ of the edge changes (on [Recursive rank saving](rank-saving-recurrence.md))

## Evidence from the sources, with the paragraph around each quote

- "Each procedure arises from its own fixed linear network that exchanges two" (paper)

  > Each procedure arises from its own fixed linear network that exchanges two banks of values, with prescribed signs, and restores every auxiliary value. A wire's fixed place in the network is called its role. To use the network on an array, regard a row as the complete ordered suffix, including all active address fields, at a fixed prefix and row index. Distribute rows cyclically among the $W$ roles, padding the row count for each prefix to a multiple of $W$. Let $V$ now denote the node volume after padding. All role streams have the same local address set and each contains $V/W$ bits. A scalar gate is then applied pointwise to matching addresses on the roles that it touches.
