## This page

Concept: Multiplication complexity and the n log n conjecture
Gloss: Schönhage and Strassen multiplied n-bit integers in O(n log n log log n) on multitape machines and conjectured that n log n is optimal; later work (Fürer, then Harvey–van der Hoeven) reached O(n log n), and the paper's theorem breaks the conjectured optimum.

## Where the argument relies on this page

- One deterministic fixed-tape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$, refuting the $n\log n$ optimality conjecture in this model. (on [Integer multiplication in O(n (lg n)^(1−κ)) time](main-theorem.md))

## Pages that build on this one

- Established O(n log n) multiplier (subroutine): The Harvey–van der Hoeven O(N log N) integer multiplier, used as a black-box subroutine on short operands (never recursively on the improved algorithm).
- Integer multiplication in O(n (lg n)^(1−κ)) time: One deterministic fixed-tape Turing machine multiplies two n-bit integers exactly in O(n (lg n)^{1−κ}) time with κ = 2^{−182}, refuting the n log n optimality conjecture in this model; the saving comes from faster address interchange and butterfly layers inside a Gaussian-resampling, Bluestein, synthetic-transform reduction.
