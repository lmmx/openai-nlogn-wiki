## This page

Concept: Fixed-point complex numbers on a disk grid
Gloss: Complex values with real and imaginary parts that are integer multiples of 2^{−p} inside the unit disk, stored as two signed two's-complement words, with truncation toward zero to the grid.

## Where the argument relies on this page

- The two-point butterfly $H_0(u,v)=((u+v)/2,(u-v)/2)$ applied at one common bit position of each of $D\le d$ address chunks of polynomial records costs $O(Vd^{\lambda'})$ with $\lambda'<1$, with exact intermediate values and a single truncation. (on [Fast simultaneous butterfly layer](butterfly-layer.md))
- The accumulated numerical error on every recovered coefficient is below $1/2$, so rounding gives the exact integer convolution coefficients and radix-$2^b$ carry propagation yields the $2n$-bit product. (on [Exact recovery by rounding and carries](exact-recovery.md))

## Pages that build on this one

- Contractions and error accumulation: A linear map that never increases the maximum coordinate modulus is a contraction, so approximation errors of composed steps add and every normalized transform keeps values inside the unit disk.
- Fast simultaneous butterfly layer: The two-point butterfly H₀ applied at once to one bit position of each of up to d address chunks of polynomial records costs O(V d^λ′) with λ′ < 1, evaluated exactly in Gaussian dyadics and truncated once.
- Exact recovery by rounding and carries: Because the accumulated numerical error on every recovered coefficient is below 1/2, rounding gives the exact integer convolution coefficients, and radix-2^b carry propagation yields the 2n-bit product.

## Evidence from the sources, with the paragraph around each quote

- "A $p$-bit grid array has real and imaginary coefficient parts in $2^{-p}\mathbb Z$." (paper)

  > For an integer $r\geq 2$ that is a power of two, put \[ \mathcal R_r=\mathbb C[y]/(y^r+1),\qquad \left\|\sum_{k=0}^{r-1}z_k y^k\right\|_\infty =\max_{0\leq k<r}|z_k|. \] We always use representatives of degree less than $r$. Multiplication by $y^a$, for any integer $a$, permutes the coefficients and changes some signs; consequently it is an isometry for this norm. For arrays over $\mathcal R_r$, the same notation denotes the maximum over all coefficients in all entries. A disk array has norm at most one. A $p$-bit grid array has real and imaginary coefficient parts in $2^{-p}\mathbb Z$. For any array, let $Q_p$ truncate each real and imaginary coefficient part toward zero to this grid. Then \begin{equation} \|Q_p z-z\|_\infty<\sqrt2\,2^{-p},\qquad \|Q_p z\|_\infty\leq\|z\|_\infty. \label{eq:transform-truncate} \end{equation}

- "a signed $w_{\rm c}$-bit two's-complement word for $a$" (paper)

  > u)_k=\frac1q\sum_{j=0}^{q-1}u_j e^{-2\pi i jk/q}, \qquad (F_q^+ u)_k=\frac1q\sum_{j=0}^{q-1}u_j e^{2\pi i jk/q}. \] All subscripts on a vector of length $q$ are taken modulo $q$. The vector norm is the maximum modulus of its coordinates. All operator norms are induced by this norm: $\|L\|=\sup_{\|u\|\leq1}\|Lu\|$. Each normalized Fourier transform above is a contraction, since each output averages inputs multiplied by complex numbers of modulus one. Coordinate permutations preserve the norm. For an integer precision $p\geq1$, put \[ \mathbb D_p=\{2^{-p}(a+ib):a,b\in\mathbb Z,\ a^2+b^2\leq 2^{2p}\}. \] For storage between completed scalar routines, put $w_{\rm c}=p+2$. Represent $2^{-p}(a+ib)\in\mathbb D_p$ by a signed $w_{\rm c}$-bit two's-complement word for $a$, followed by one for $b$, with each word written most significant bit first. A coordinate list is the concatenation of these fixed-length records in its stated order. Since $|a|,|b|\leq2^p<2^{w_{\rm c}-1}$, this format includes both signs of every permitted numerator, including $-2^p$ and $2^p$. An approximation $\widetilde L:\mathbb D_p^a\to\mathbb D_p^b$ to a linear contraction $L:\mathbb C^a\to\mathbb C^b$ has error $E$ if $2^p\|\widetilde L u-Lu\|<E$ for every input in $\mathbb D_p^a$. The approximation itself need not be linear. Composing such algorithms adds their errors: at each step, insert the exact map at the computed input and use its contraction bound on the accumulated input error.
