The exceptional set is a set of [Address](address.md) values, namely those at which the generic formula must be replaced by a special rule. Outside it the generic formula is correct, so a procedure that applies the generic formula everywhere is wrong only at these addresses, and only they need extra work. The main argument needs this because a [simultaneous butterfly layer](simultaneous-butterfly-layer.md) applies a two-point map (a rule that takes a pair of values and returns a new pair) to every pair of entries whose addresses differ in one of several selected bits. It does this in one tape pass, using one generic formula for all pairs. The failures of that formula are confined to the exceptional set, and the source repairs them afterwards: <cite data-source="paper">by a deterministic correction of the explicitly identified exceptional addresses.</cite>

We write $F$ for the generic formula, a rule that gives a value $F(\alpha)$ for each address $\alpha$. We write $E$ for the exceptional set: the addresses $\alpha$ at which the special rule gives a value different from $F(\alpha)$.

Take 3-bit addresses, so $\alpha$ runs over $000, 001, \dots, 111$, and let the generic formula be $F(\alpha)=\alpha+1$, read as an integer, where the output must again be a 3-bit address. For $\alpha = 000$ to $110$, the output $F(\alpha)$ is a valid address and the special rule agrees with it. For $\alpha = 111$ (the integer 7) the formula gives 8, which has no 3-bit form, so the special rule sends $111$ to $000$. Here $E = \{111\}$.

In the layer, the generic formula is a packed addition: several small fields inside one binary number are updated by one addition, and a field that overflows carries into its neighbour. A guard value is a field value that the source tests against a fixed range before the addition. The source defines the exceptional addresses for this layer as those at which such a test fails: <cite data-source="paper">Let B consist of the addresses for which at least one used guard value, in either y or z, fails</cite> the range test. Outside this set no field carries into the next, so the generic formula is correct there: <cite data-source="paper">no segment carries into or borrows from the next segment</cite>.
