Fast address-chunk interchange is the first tape primitive of the main result: it swaps two disjoint address fields, chunks, of $u$ bits each (the chunk width) in an array of volume $V$ (stored bits) in $O(Vu^\tau)$ time on fixed tapes <cite data-source="paper">Its cost is $O(Vu^\tau)$ for a fixed $\tau<1$.</cite>, with $\tau=1-2^{-50}$. Its intermediate steps XOR data together, yet the result is an exact permutation.

An address is $(p,h,g,d,z)$ with prefix $p$, chunks $h$ and $d$, gap $g$, suffix $z$; the goal is $(p,h,g,d,z)\mapsto(p,d,g,h,z)$. The letters $u,p,h,d,q,e,k,M$ change meaning on this page. Digits are radix $q$, a fixed prime.

Write $H$ and $D$ for the values of the two chunks. The updates $D\gets D-H$, $H\gets H+D$, $D\gets H-D$ send $(H,D)$ to $(H,D-H)$, then $(D,D-H)$, then $(D,H)$. Only the middle one, the shear $H\gets H+D$, needs the circuit; the others are linear scans.

Let each chunk have $e=m^k$ digits, where $k$ counts recursion levels. Cut it into $m$ fields of $b=e/m$ digits, so $H,D$ become vectors over $\mathbb Z/q^b\mathbb Z$. The [Linear exchange network with restored scratch wires](exchange-network.md) has $W$ wires; each terminal and gate carries a rational $m\times m$ matrix $M$, and edge $i$ carries $A_i=M_{\mathrm{head}(i)}-M_{\mathrm{tail}(i)}$, with $s=\sum_i\operatorname{rank}A_i$. The shear contract: input wire $w$ is routed to an output role $\rho(w)$ with $M_{\mathrm{out}(\rho(w))}-M_{\mathrm{in}(w)}=I_m$, the identity, and $s<Wm$ by [Nested subspace labels and rank deficit](subspace-labels.md). Take $\tau$ with $s/W<m^\tau$.

Let $\Phi_M$ move the entry at address $(H,D)$ to $(H+MD,D)$; then $\Phi_{M'}\Phi_M=\Phi_{M'+M}$. The [Frames on wire arrays](array-frames.md) assign each vertex with matrix $M$ the frame $\Phi_M$, so an edge changes the frame by $\Phi_{M'-M}=\Phi_{A_i}$. A common address permutation commutes with every pointwise bit gate. It performs each edge shear by [Matrix shear by triangular factorization](matrix-shear.md): if $A_i$ has rank $a$, then $\Phi_{A_i}$ costs $a$ interchanges of $b$-digit fields <cite data-source="paper">An edge matrix of rank $a$ will require $a$ smaller interchanges.</cite>, so there are exactly $s$ smaller calls <cite data-source="paper">The number of recursive calls is the sum of the edge ranks, exactly $s$.</cite>.

Suppose a row field ahead of both chunks has length divisible by $W^k$. Within each prefix, [Elementary stream operations](stream-ops.md) split rows into role streams: row $Wx+w-1$ goes to stream $w$ as row $x$. Each stream has volume $V/W$ and row count divisible by $W^{k-1}$. Read wire $w$'s input $f_w$ as the logical array $\Phi_{-M_{\mathrm{in}(w)}}f_w$. By the composition rule and the contract, the output is $f'_{\rho(w)}=\Phi_{M_{\mathrm{out}(\rho(w))}}\Phi_{-M_{\mathrm{in}(w)}}f_w=\Phi_{I_m}f_w$. Merging rows back undoes $\rho$, giving $H\gets H+D$ on every original row.

Each smaller call acts on volume $V/W$; splitting, merging, gates and scheduling cost $O(V)$ here. So the time per unit volume $F_k$ at width $m^k$ obeys $F_0=O(1)$, $F_k\le(s/W)F_{k-1}+O(1)$, the recurrence of [Recursive power saving](rank-recurrence.md). Unrolled over levels $j$, $F_k=O(\sum_{j=0}^k (s/W)^j)$. If $s/W\le1$ this is at most $k+1=O(m^{k\tau})$; otherwise it is $O((s/W)^k)$, below $m^{k\tau}$. So $F_k=O(e^\tau)$. The saving is a power of $e$ because $s/W$ is a fixed constant below $m$ while the depth is $\log_m e$; the rank deficit is tiny, so $\tau\approx1$.

For large $e$, put $k'=\lceil\log_m e\rceil$ and $\nu=\lceil k'\log W/(2\log q)\rceil$, so $q^{2\nu}\ge W^{k'}$, $1\le\nu<e$ and $\nu=O(\log 2e)$; small $e$ use single-digit interchanges. Split each chunk into top $\nu$ digits and rest, $h^+,h^-$ and $d^+,d^-$. Interchange the high digits and move $h^+$ next to $d^+$: $(h^+,h^-,g,d^+,d^-)$ becomes $(d^+,h^+,h^-,g,d^-)$. Now $d^+,h^+$ form a row field of range $\Lambda=q^{2\nu}\ge W^{k'}$ before both remaining chunks. Pad with zero rows to $\Lambda'=W^{k'}\lceil \Lambda/W^{k'}\rceil<2\Lambda$ rows, so the volume stays below $2V$.

Write the remaining width in base $m$: $e-\nu=\sum_{j=0}^{k'}a_jm^j$ with $0\le a_j<m$, where the base-$m$ digit $a_j$ is the number of pieces of width $m^j$ into which each remaining chunk is cut. Interchange corresponding pieces by the power-width case. The total is $O(V)\sum_ja_jm^{j\tau}\le O(V)\,m\sum_jm^{j\tau}=O(Ve^\tau)$, since $m^{k'}<me$ makes $\sum_jm^{j\tau}$ a geometric sum dominated by its last term. Scan away padded rows and reverse the joining, giving $(d^+,d^-,g,h^+,h^-)$ at cost $O(V\nu)=O(Ve^\tau)$.

For $u$-bit chunks, pad $[2^u]$ to $[q^e]$ with $e$ least such that $q^e\ge2^u$, and scan the padding away. Since $e=O(u)$ the cost is $O(Vu^\tau)$ <cite data-source="paper">Since $e=O(u)$ for fixed $q$, the bound is $O(Vu^\tau)$.</cite>.
