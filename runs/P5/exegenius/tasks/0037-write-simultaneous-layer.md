## This page

Concept: Simultaneous butterfly layer in O(Vd^λ') time
Gloss: Applying H₀ to the same bit position of D≤d address chunks of a polynomial array at once, via the phase network and recursion on e=mf axes, in time O(V d^λ') instead of D passes.
Heading: Simultaneous butterfly layer in $O(Vd^{\lambda'})$ time

The symbols in this page's heading denote (say so on the page):

- $V$ (stored volume): The number of stored data bits in the array.
- $d$ (axis count): The maximum number of address chunks (axes) whose selected bits are butterflied together.
- $\lambda'$ (layer exponent): A fixed constant below 1, namely 1−2^{-54}.

## This page in the argument

The step: A normalized butterfly $H_0$ applied to the same bit position of $D\le d$ address chunks of a polynomial array is computed at once in $O(Vd^{\lambda'})$ time, with a single truncation at the end.
How: express the tensor power of the two-point kernel through the complex phase network and bit-network recursion on $e=mf$ axes, using exact dyadic arithmetic throughout
Why: Doing the $D$ butterfly factors separately costs $D$ passes over the data, so the factors are bundled into one recursion whose children are fewer and smaller. (the sources say so: "factors would require $D$ whole-array passes." (paper))
Striking feature: The cost $O(Vd^{\lambda'})$ with $\lambda'<1$ is a power of $d$ below the $D\le d$ passes of separate layers, because a strict rank deficit $s<Wm$ also holds for the complex network. (explain why it holds, from the method)

Its sub-steps, in order:

- The complex network with binary labels has frame differences that are products of translation kernels $aI+bX_v$ and gives $C\otimes\dots\otimes C$ on every role, where $H_0=b\,\mathsf S C\mathsf S$. (on [Binary phase frames and the two-point kernel C](phase-frames.md))
- Adding corresponding selected bits of address chunks is done by a constant number of cyclic shifts of whole chunks, followed by repair of an explicitly bounded exceptional set of addresses. (on [Packed selected-bit addition](packed-selected-bits.md))
- Each node of the recursion on $e=mf$ axes makes exactly $s$ child calls on $f$ axes, each on $1/W$ of the volume, and the other work per node is $O(V((eK)^\tau+1))$, giving cost $O(Vd^{\lambda'})$.
- Intermediate values of the whole layer are Gaussian dyadics whose size is bounded by $O(d^{C_1})$ guard bits, so the layer is evaluated exactly and truncated once. (on [Exact Gaussian dyadic evaluation of a layer](dyadic-exact.md))
- For fixed rational exponents the layer returns $Q_p(\mathcal H z)$ with error below $\sqrt2\,2^{-p}$ in $O(Vd^{\lambda'})$ time with $\lambda'<1$.

It serves these steps, from the main result down:

- A deterministic fixed-tape Turing machine multiplies $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.; how: build two tape procedures that save a power of the width, use them inside the Harvey and van der Hoeven Gaussian-resampling multiplication with polynomial transforms and retained permutations, then choose parameters, prove exactness and sum the costs (on [Integer multiplication in O(n (lg n)^{1−κ}) time](main-theorem.md))
- Two tape procedures, an address-chunk interchange and a simultaneous butterfly layer, each cost a power $u^\tau$ or $d^{\lambda'}$ below the naive factor.; how: derive both procedures from fixed linear networks whose rank deficit $s<Wm$ gives a recursion that saves a power

**S4.3**: Each node of the recursion on $e=mf$ axes makes exactly $s$ child calls on $f$ axes, each on $1/W$ of the volume, and the other work per node is $O(V((eK)^\tau+1))$, giving cost $O(Vd^{\lambda'})$.
Source: "The phase construction supplies one recursive call on a slot for each" (paper)
> First consider an internal node containing \(e=m^k\) consecutive active chunks, with \(k\ge1\). Split it into \(m\) consecutive slots, each containing \(e/m\) chunks. The phase construction supplies one recursive call on a slot for each vector in an edge residual basis, hence exactly \(s\) calls in one invocation of the network. If the logical volume entering this node is \(V\), binary changes of basis, their inverses, scalar gates, endpoint corrections and reassembly of the physical banks cost \[ O\bigl(V((eK)^\tau+1)\bigr) \] at this node. Each slot has \((e/m)K\) address bits, so Lemma~\ref{lem:packed-selected-bit-rectangle} gives the stated bound for a row addition. The network and all of its \(m\)-dimensional residual bases are fixed, so the total number of row additions is fixed as well. At the same guarded width, the scalar gates cost a constant number of scans of the current volume. Address and descriptor work bounded by any fixed polynomial in \(p\) per record is also absorbed: its ratio to the record's \(\Theta(rp)\) bits tends to zero.

**S4.5**: For fixed rational exponents the layer returns $Q_p(\mathcal H z)$ with error below $\sqrt2\,2^{-p}$ in $O(Vd^{\lambda'})$ time with $\lambda'<1$.
Source: "The procedure returns $Q_p(\mathcal H z)$ in the same array," (paper)
> The procedure returns $Q_p(\mathcal H z)$ in the same array, coefficient order, and component format in $O(Vd^{\lambda'})$ time, uniformly over all these choices of $p,d,r,D,P,S,\rho,w$ and $z$. Every returned coefficient belongs to the complex unit disk, and, in the maximum coefficient norm, \[ \|Q_p(\mathcal H z)-\mathcal H z\|_\infty <\sqrt2\,2^{-p}. \] The procedure evaluates the entire layer exactly before this final truncation. Put \[ C_0=128m\bigl(s_{\rm c}+64(W_{\rm c}+m+1)^3\bigr)^2, \] where $m,W_{\rm c},s_{\rm c}$ are the fixed constants of Proposition~\ref{prop:complex-motif-interface}. The procedure uses at most $p+\lceil C_0d^{C_1}\rceil$ fractional bits and $\lceil C_0d^{C_1}\rceil+3$ integer and sign bits per real component internally; these widths are $O(p)$. The time includes address changes, deterministic repair, row padding and its removal, and fixed-tape workspace cleanup. Its tape count is fixed, and its time constant is independent of the allowed array lengths and coefficient values. \end{proposition}

Other tasks run at the same time on this machine, and files elsewhere (in /tmp, for example) can be overwritten or run by them. For the same reason, never stop processes by name or pattern (`pkill`, `killall`), which would stop other tasks' commands too: stop a command of your own by its process id.
