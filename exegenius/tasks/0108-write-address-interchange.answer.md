Fast address-chunk interchange swaps two disjoint $u$-bit address fields of a bit array of volume $V$ (stored bits) in $O(Vu^\tau)$ time on fixed tapes <cite data-source="paper">Its cost is $O(Vu^\tau)$ for a fixed $\tau<1$.</cite>, with $\tau=1-2^{-50}$. It is one of two tape primitives behind the main result. Intermediate steps XOR data, yet the result is exact.

An address is $(p,h,g,d,z)$: prefix $p$, chunks $h,d$, gap $g$, suffix $z$; the goal is $(p,h,g,d,z)\mapsto(p,d,g,h,z)$. Letters $p,h,d,k,b,R$ change meaning from earlier pages. Digits are radix $q$, a fixed prime.

With $H,D$ the chunk values, $D\gets D-H$, $H\gets H+D$, $D\gets H-D$ send $(H,D)$ to $(H,D-H)$, $(D,D-H)$, $(D,H)$. Only the middle shear needs the circuit.

Let each chunk have $e=m^k$ digits. Cut it into $m$ fields of $b=e/m$ digits, so $H,D$ are vectors over $\mathbb Z/q^b\mathbb Z$. The [exchange network](exchange-network.md) has $W$ wires; each terminal and gate carries a rational $m\times m$ matrix $M$, and edge $i$ carries $A_i=M_{\mathrm{head}(i)}-M_{\mathrm{tail}(i)}$, with $s=\sum_i\operatorname{rank}A_i$. The shear contract says input wire $w$ ends at output role $\rho(w)$ with $M_{\mathrm{out}(\rho(w))}-M_{\mathrm{in}(w)}=I_m$ (the identity), and $s<Wm$ (a [rank deficit](subspace-labels.md)); take $\tau$ with $s/W<m^\tau$.

Let $\Phi_M$ move the entry at address $(H,D)$ to $(H+MD,D)$. Then $\Phi_{M'}\Phi_M=\Phi_{M'+M}$, and $\Phi_{-M}$ is the inverse. The [frame](array-frames.md) at a vertex with matrix $M$ is $\Phi_M$; an edge to a vertex with matrix $M'$ changes it by $\Phi_{M'-M}=\Phi_{A_i}$. A common address permutation commutes with every pointwise bit gate. [Matrix shear by triangular factorization](matrix-shear.md) performs each $\Phi_{A_i}$: rank $a$ costs $a$ interchanges of $b$-digit fields <cite data-source="paper">An edge matrix of rank $a$ will require $a$ smaller interchanges.</cite>.

Suppose a row field ahead of both chunks has length divisible by $W^k$. Within each prefix, [stream scans](stream-ops.md) send row $Wx+w-1$ to role stream $w$ as row $x$. Each stream has volume $V/W$ and row count divisible by $W^{k-1}$, the hypothesis one level down.

Wire $w$'s input $f_w$ is read as the logical array $\Phi_{-M_{\mathrm{in}(w)}}f_w$. By the composition rule and the contract, the output is $f'_{\rho(w)}=\Phi_{M_{\mathrm{out}(\rho(w))}}\Phi_{-M_{\mathrm{in}(w)}}f_w=\Phi_{I_m}f_w$. Merging rows back undoes $\rho$, so $H\gets H+D$ holds on every original row, scratch rows included.

There are exactly $s$ smaller calls <cite data-source="paper">The number of recursive calls is the sum of the edge ranks, exactly $s$.</cite>, each on volume $V/W$; other work costs $O(V)$. So the time per unit volume $F_k$ at width $m^k$ obeys $F_0=O(1)$, $F_k\le(s/W)F_{k-1}+O(1)$, the recurrence of [Recursive power saving](rank-recurrence.md). Unrolled, $F_k=O(\sum_{j=0}^k (s/W)^j)$. If $s/W\le1$ the sum is at most $k+1=O(m^{k\tau})$; otherwise it is $O((s/W)^k)$, below $m^{k\tau}$. Hence $F_k=O(e^\tau)$. Since $s<Wm$ by at least one rank unit, $s/W$ is barely below $m$, so $\tau$ is barely below $1$.

For general large $e$, put $k'=\lceil\log_m e\rceil$ and $\nu=\lceil k'\log W/(2\log q)\rceil$, so $q^{2\nu}\ge W^{k'}$, $1\le\nu<e$ and $\nu=O(\log 2e)$; small $e$ use single-digit interchanges. Write each chunk as top $\nu$ digits and rest, $h^+,h^-$ and $d^+,d^-$. Interchange the high digits and move $h^+$ next to $d^+$: $(h^+,h^-,g,d^+,d^-)$ becomes $(d^+,h^+,h^-,g,d^-)$. Now $d^+,h^+$ form a row field of range $R=q^{2\nu}\ge W^{k'}$ before both remaining chunks. Pad with zero rows to $R'=W^{k'}\lceil R/W^{k'}\rceil<2R$ rows (volume below $2V$).

Write $e-\nu=\sum_{j=0}^{k'}a_jm^j$, $0\le a_j<m$. Split each remaining chunk into $a_j$ pieces of width $m^j$ and interchange corresponding pieces as above, all with this row field. The total $O(V)\sum_ja_jm^{j\tau}\le O(V)\,m\sum_jm^{j\tau}=O(Ve^\tau)$, since $m^{k'}<me$. This gives $(d^+,h^+,d^-,g,h^-)$. Scan away padded rows and reverse the joining, giving $(d^+,d^-,g,h^+,h^-)$ at cost $O(V\nu)=O(Ve^\tau)$.

For $u$-bit chunks, pad $[2^u]$ to $[q^e]$ with least $e$ such that $q^e\ge2^u$ and scan the padding away. Since $e=O(u)$ the cost is $O(Vu^\tau)$ <cite data-source="paper">Since $e=O(u)$ for fixed $q$, the bound is $O(Vu^\tau)$.</cite>.
