A linear network with frames is a fixed wiring of linear gates that exchanges two banks of values while restoring its auxiliary values. It realises each tape procedure, a fixed routine that a Turing machine runs on arrays stored on its tape, so that the main theorem (the bound on exact multiplication) can count each procedure's cost.

A *wire* carries one scalar, and a *gate* is a fixed linear map on the wires it touches. <cite data-source="paper">untouched wires retain their values.</cite> <cite data-source="paper">The vertices on a wire are its source</cite>, the gates that touch it in time order, and its sink. A *bank* is a set of wires with a common index set, so exchanging two banks swaps values at matching indices. <cite data-source="paper">Each procedure arises from its own fixed linear network that exchanges two banks of values</cite>, and it <cite data-source="paper">restores every auxiliary value</cite>. <cite data-source="paper">We call the name of a wire its role</cite>.

Each scalar becomes an array over common addresses, and a *pointwise* gate acts separately at each address. The *logical array* $g$ is the array a wire represents. A vertex $v$ carries an invertible linear operator $D_v$, its *frame*, and <cite data-source="paper">the stored array is Dv g when the logical array is g</cite>. Frames are built from invertible linear operators, as defined in [Linear algebra basics](linear-algebra-basics.md).

<cite data-source="paper">Along an edge from u to v, the operator Dv Du−1 changes the stored array</cite>: the edge operator $D_v D_u^{-1}$ takes $D_u g$ to $D_v g$. Let $G$ be a pointwise linear gate with $t$ inputs, where $t$ counts the inputs here, not the induction step. <cite data-source="paper">At a pointwise linear gate G, the common frame commutes with the gate:</cite>

$$G(D_v g_1, \dots, D_v g_t) = D_v\, G(g_1, \dots, g_t).$$

This is why frames sit on the wires: a gate adds entrywise, so its inputs must share one frame to add in stored form. For example, take $t=2$, $G(g_1,g_2)=g_1+g_2$, and let $D_v$ have rows $(1,1)$ and $(0,1)$. For $g_1=(1,0)$ and $g_2=(0,1)$, the stored inputs $(1,0)$ and $(1,1)$ sum to $(2,1)=D_v(1,1)$.

<cite data-source="paper">The supplied input needs no preliminary change of frame</cite>. Write $\ell$ for an input wire, $\theta_\ell$ for its supplied array, and $\mathrm{source}(\ell)$ for its source vertex. For any vertex $x$, $D_x$ is its frame, so the logical array is $g_\ell = D_{\mathrm{source}(\ell)}^{-1}\theta_\ell$. A permutation $\rho$ of roles sends each input role $\ell$ to an output role $\rho(\ell)$, with sign $\varepsilon_\ell$. Write $\sigma$ for an output role and $\mathrm{sink}(\sigma)$ for its sink vertex. A route through vertices $x_0,\dots,x_L$ from $\mathrm{source}(\ell)$ to $\mathrm{sink}(\rho(\ell))$ has $L$ edges, where $x_0=\mathrm{source}(\ell)$, $x_L=\mathrm{sink}(\rho(\ell))$, and $x_h$ is the vertex at position $h$, from $0$ to $L$. Its operator is the composite of its edge operators in route order, $(D_{x_L}D_{x_{L-1}}^{-1})\cdots(D_{x_1}D_{x_0}^{-1})$. Each inner pair $D_{x_h}^{-1}D_{x_h}$ is the identity, so the composite telescopes to $D_{x_L}D_{x_0}^{-1}$. <cite data-source="paper">Thus the intermediate frames cancel</cite>, and the stored output is the endpoint operator

$$\varepsilon_\ell\, D_{\mathrm{sink}(\rho(\ell))}\, D_{\mathrm{source}(\ell)}^{-1}\,\theta_\ell.$$

The bit procedure interchanges two equal address fields. <cite data-source="paper">We use the bit network to interchange two equal address chunks on tape.</cite> The bit network acts on the two [Address field](address-field.md) blocks of each array, H and K. <cite data-source="paper">For the bit procedure, that endpoint operator is an address shear</cite>. It replaces the field $H$ by $H+D$ and keeps $D$, and <cite data-source="paper">H, D over a common residue ring, are updated by (H, D) 7→ (H + D, D).</cite> Over bits, $H+K$ is a pointwise XOR, adding two bits modulo 2 at each address. The bit network <cite data-source="paper">uses only pointwise XOR gates</cite>, so it realises the shear.

Each tape procedure is such a network because <cite data-source="paper">We construct two fixed linear networks that exchange two banks of values</cite>, and <cite data-source="paper">The scalar network already has the required signed exchange.</cite> Applying the scalar wiring at every address is legitimate, since a scalar gate <cite data-source="paper">is then applied pointwise to matching addresses on the roles that it touches</cite>. Once the scalar routing is fixed, <cite data-source="paper">the intermediate frames can then be chosen to</cite> make each edge change inexpensive.
