A bijection is a map that can be undone: it sends different inputs to different outputs and misses no output. Rearranging stored data by a bijection, such as a [Permutation](permutation.md), moves every value and loses or duplicates none.

Let $U$ and $W$ be sets, the source set $U$ and the target set $W$, and let $f\colon U\to W$ be a map, which sends each element $\sigma$ of $U$ to an element $f(\sigma)$ of $W$. The map $f$ is a bijection when it is one-to-one and onto:

- one-to-one: if $f(\sigma)=f(\sigma')$ for $\sigma,\sigma'\in U$, then $\sigma=\sigma'$;
- onto: for every $\upsilon\in W$ there is some $\sigma\in U$ with $f(\sigma)=\upsilon$.

So each $\upsilon\in W$ is hit by exactly one $\sigma\in U$, and the inverse $f^{-1}\colon W\to U$ sends $\upsilon$ to that $\sigma$. Thus $f^{-1}(f(\sigma))=\sigma$: applying $f^{-1}$ undoes $f$. The letters $f$, $U$, $W$ and $\sigma$ are reused here with new meanings.

**Example.** Take $U=W=\{0,1,2,3\}$ and $f(\sigma)=\sigma+1 \bmod 4$, where $a \bmod 4$ is the remainder of $a$ after division by $4$. Then $0\mapsto1$, $1\mapsto2$, $2\mapsto3$, $3\mapsto0$, so each target is hit once and $f$ is a bijection. A non-example is illustrated using the [Floor function](floor-function.md): the map $f_2(\sigma)=\lfloor \sigma/2\rfloor$ on the same sets is not a bijection, because $f_2(0)=f_2(1)=0$ and the targets $2$ and $3$ are never hit, so it has no inverse.

For a subset $G\subseteq U$, the set of elements singled out by the argument, write $G^c=U\setminus G$ for its complement. If $f$ is a bijection of $U$ onto $W$, then $f(G^c)=W\setminus f(G)$: the images of $G$ and $G^c$ are disjoint by one-to-one and cover $W$ by onto. So if two bijections $f$ and $g$ of $U$ onto itself agree outside $G$, then $f(G)=g(G)$, and if also $g(G)=G$, then $f(G)=G$.

The paper uses this in its address-field interchange, which <cite data-source="paper">interchanges two disjoint contiguous address fields of u bits in an array</cite>, <cite data-source="paper">whose addresses form a complete Cartesian product</cite>. Its update lines are bijections: <cite data-source="paper">so each line is a bijection of the rectangle</cite>. <cite data-source="paper">Let S0 be their composition.</cite> Its ideal counterpart is $T_0$, <cite data-source="paper">the ideal permutation T0 that performs the required XORs</cite>. Each of the two bijections $S_0$ and $T_0$ is compared off the [Exceptional set](exceptional-set.md) of bad addresses, which we write $G$ and the paper writes $B$. <cite data-source="paper">Let B consist of the addresses for which at least one used guard value</cite>, where a guard value $g$ is a stored value that must lie in a fixed range. <cite data-source="paper">The ideal map T0 preserves all guard values and therefore preserves B.</cite> Both $T_0$ and $S_0$ are <cite data-source="paper">bijections, and they agree off B.</cite> <cite data-source="paper">Taking complements in the finite rectangle gives</cite> $S_0(G^c)=T_0(G^c)=G^c$, so $S_0(G)=G$.

The second use is a tape procedure, a fixed procedure on one-dimensional Turing machine tapes that rearranges the bits stored on them. Its steps act on a set of integer addresses, which the paper calls $P$. The paper states that it is a <cite data-source="paper">bijection of P: for fixed controls and spectators it is a cyclic permutation of the valid target interval</cite>. For the valid interval $\{0,1,2,3\}$ and offset $1$, this is the map $f$ above, and rotating back by $-1$ undoes it. The paper also gives <cite data-source="paper">An inverse is explicit</cite>, so the stored data can be recovered after the step.
