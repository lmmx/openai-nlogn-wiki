A simultaneous butterfly layer applies the [butterfly operation](butterfly-operation.md) to one selected address bit of every record at once. Its tape cost is what saves a power in the transform layers of the multiplication algorithm.

An address chunk is a block of consecutive address bits. Here $d$ is the largest number of equal-width chunks a layer acts on, and $D \le d$ is the number used in one layer; the letter $D$ changes meaning here. The layer selects the same bit position in each of those $D$ chunks.

Each record is a polynomial with complex fixed-point coefficients, each stored with a fixed number of binary places. The layer is formed as the [tensor product](tensor-product.md) of the butterfly operation on the $D$ selected bits, acting on each coefficient and leaving other address bits unchanged. Applying the factors one at a time would take one pass over the array per selected bit.

Here $\lambda'$ is a fixed exponent below one, chosen above two exponents fixed in the proof, so it measures growth in $d$, not a count. The tape cost, the number of steps of the multitape machine, is $O(Vd^{\lambda'})$ <cite data-source="paper">the cost is $O(Vd^{\lambda'})$ for a fixed $\lambda'<1$</cite>, where $V$ is the number of stored data bits.

The bound comes from a recursion on the chunks. The proof builds the tensor product from smaller groups of selected bits joined by binary changes of basis, which are invertible maps on address positions over $\mathbb F_2$, and each change of basis moves whole chunks. The layer computes its chunk moves by the [linear network with restored auxiliary values](linear-network-exchange.md), which exchanges banks of values with prescribed signs. Splitting complete rows among the network's wire roles gives each recursive call a fixed fraction, below one, of the volume, and each level cuts the active chunks by a fixed factor. The levels sum to $O(d^{\lambda'})$ per stored bit; the source proves this in its section on fast butterfly layers.

Intermediate values are exact Gaussian dyadics, complex numbers whose real and imaginary parts have power-of-two denominators. The butterfly divides by two, so exact values avoid rounding at each step, and one truncation follows the completed layer.
