Fast address-chunk interchange is the first tape primitive in the main result: it swaps two disjoint address fields, called chunks, of $u$ bits each in an array of volume $V$ in $O(Vu^\tau)$ time on fixed tapes <cite data-source="paper">Its cost is $O(Vu^\tau)$ for a fixed $\tau<1$.</cite>, with $\tau=1-2^{-50}$. Its intermediate steps form XOR combinations of data, yet the final result is an exact permutation.

An address is $(p,h,g,d,z)$, where $p$ is a prefix (an address prefix, not a count of fractional bits), $h$ and $d$ are the two chunks (not an index or an axis count), $g$ is the gap between them and $z$ is the suffix. The goal is $(p,h,g,d,z)\mapsto(p,d,g,h,z)$. Here $u$ is the chunk width (not a DFT input sequence), $V$ is the number of stored digits (a volume, not a label), and $q$ is the fixed prime radix of the digits (not a sequence length).

For chunk values $H,D$, the componentwise updates $D\gets D-H$, $H\gets H+D$, $D\gets H-D$ send $(H,D)$ to $(H,D-H)$, then $(D,D-H)$, then $(D,H)$. Only the middle shear $H\gets H+D$ uses the circuit; the others are scans. A shear adds to $H$ a function of $D$ and leaves $D$ unchanged.

Let each chunk have $e=m^k$ digits, where $m$ is the label dimension and $k$ counts recursion levels (not the depth of a value). Cut it into $m$ fields of $b=e/m$ digits, so that $H,D$ become vectors over $\mathbb Z/q^b\mathbb Z$, and build the shear $H\gets H+D$.

The [Linear exchange network with restored scratch wires](exchange-network.md) has $W$ wires. Each source, gate and sink carries a rational $m\times m$ matrix $M$ (a vertex matrix, not an address count), and edge $i$ carries $A_i=M_{\mathrm{head}(i)}-M_{\mathrm{tail}(i)}$. Let $s=\sum_i\operatorname{rank}A_i$. The shear contract says that input wire $w$ is routed to an output role $\rho(w)$ with $M_{\mathrm{out}(\rho(w))}-M_{\mathrm{in}(w)}=I_m$, the identity. By [Nested subspace labels and rank deficit](subspace-labels.md), $s<Wm$; fix $\tau$ with $s/W<m^\tau$. The deficit is tiny, which is why $\tau$ is so close to 1.

Let $\Phi_M$ move the entry at address $(H,D)$ to $(H+MD,D)$, so $\Phi_{M'}\Phi_M=\Phi_{M'+M}$. With [Frames on wire arrays](array-frames.md), the stored form of each wire's array varies along the network: the frame at a vertex with matrix $M$ is the address permutation $\Phi_M$, and each edge changes it by $\Phi_{A_i}$. A common address permutation commutes with every pointwise bit gate, so the gates run unchanged on framed arrays.

Each edge shear $\Phi_{A_i}$ is performed by [Matrix shear by triangular factorization](matrix-shear.md). A matrix of rank $a$ costs $a$ interchanges of pairs of $b$-digit fields <cite data-source="paper">An edge matrix of rank $a$ will require $a$ smaller interchanges.</cite>. So the circuit makes exactly $s$ smaller calls <cite data-source="paper">The number of recursive calls is the sum of the edge ranks, exactly $s$.</cite>.

Suppose a row field before both chunks has length divisible by $W^k$. Rows are split cyclically into $W$ role streams by [Elementary stream operations](stream-ops.md). Within each prefix, row $Wx+w-1$ goes to stream $w$ as row $x$ ($x$ is a row number here, not a vector of $F$). Each stream has volume $V/W$ and a row count divisible by $W^{k-1}$, so the same argument applies one level down. On every circuit edge, apply $\Phi_{A_i}$ to that role stream. Read the physical input $f_w$ as the logical array $\Phi_{-M_{\mathrm{in}(w)}}f_w$, which costs no tape operation. By the composition rule and the contract, the physical output is $f'_{\rho(w)}=\Phi_{M_{\mathrm{out}(\rho(w))}}\Phi_{-M_{\mathrm{in}(w)}}f_w=\Phi_{I_m}f_w$. Merging row $x$ of stream $\rho(w)$ back to its original row undoes $\rho$, so the result is $H\gets H+D$ on every original row, including scratch rows whose initial values were arbitrary.

Let $F_k$ be the time per unit volume for chunks of $m^k$ digits. A single-digit interchange gives $F_0=O(1)$. Splitting, merging, gates and scheduling cost $O(V)$ at the node itself, since each is a fixed number of passes over the node's own volume, not its children's. The $s$ smaller calls each act on volume $V/W$, so $F_k\le(s/W)F_{k-1}+O(1)$, which obeys the recurrence of [Recursive power saving](rank-recurrence.md). Unrolling over levels $j$ ($j$ indexes recursion levels, not a stage number or a wrap count) gives $F_k=O(\sum_{j=0}^k (s/W)^j)$. If $s/W\le1$, every term is at most $1$, so the sum is at most $k+1=O(m^{k\tau})$. Otherwise the geometric series gives $O((s/W)^k)$, which is below $m^{k\tau}$. Either way $F_k=O(e^\tau)$ <cite data-source="paper">Hence $F_k=O(e^\tau)$.</cite>, so the interchange takes $O(Ve^\tau)$. The saving is a power of $e$ because each of the $k$ levels multiplies the cost per unit volume by $s/W$ instead of $m$, and $m^k=e$ would be no saving.

For other widths, take large $e$ and put $k'=\lceil\log_m e\rceil$, the number of levels needed, and $\nu=\lceil k'\log W/(2\log q)\rceil$, the number of top digits of each chunk set aside, so that $q^{2\nu}\ge W^{k'}$, $1\le\nu<e$ and $\nu=O(\log 2e)$. Split each chunk into top digits and rest, $h^+,h^-$ and $d^+,d^-$. Interchange the high digits one pair at a time and move $h^+$ next to $d^+$, turning $(h^+,h^-,g,d^+,d^-)$ into $(d^+,h^+,h^-,g,d^-)$. Now $d^+,h^+$ form a row field of range $\Lambda=q^{2\nu}\ge W^{k'}$ before both remaining chunks. Pad with zero rows to $\Lambda'=W^{k'}\lceil\Lambda/W^{k'}\rceil<2\Lambda$ rows, so the padded volume is below $2V$ and the row count is divisible by every needed $W^j$.

Write the remaining width in base $m$: $e-\nu=\sum_{j=0}^{k'}a_jm^j$ with $0\le a_j<m$, so each remaining chunk is cut into $a_j$ pieces of width $m^j$ ($a_j$ is a base-$m$ digit, not a bank index). Interchange corresponding pieces by the case above, all with the same row field. The total is $O(V)\sum_ja_jm^{j\tau}\le O(V)\,m\sum_jm^{j\tau}=O(Ve^\tau)$, because $a_j<m$ and $m^{k'}<me$ make $\sum_jm^{j\tau}$ a geometric sum of order $e^\tau$. Scan away the padded rows and undo the joining of the high parts, which gives $(d^+,d^-,g,h^+,h^-)$ at cost $O(V\nu)=O(Ve^\tau)$.

For $u$-bit chunks, let $e$ be the least integer with $q^e\ge2^u$ and pad each chunk range from $[2^u]$ to $[q^e]$, which multiplies the volume by a fixed factor; the padded entries are scanned away afterwards. Since $e=O(u)$, the cost is $O(Vu^\tau)$ <cite data-source="paper">Since $e=O(u)$ for fixed $q$, the bound is $O(Vu^\tau)$.</cite>.
