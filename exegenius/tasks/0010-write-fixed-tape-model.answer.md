The fixed-tape machine model is the computational setting in which the paper's main result is stated. It fixes, once and for all, the alphabet and the number of tapes of a Turing machine, so that the machine does not grow with the input and its running time can be compared against a single function of the input length.

A fixed-tape machine is constrained in three ways. Its alphabet is finite and fixed. It has a finite, fixed number of tapes, and each tape is one-dimensional: a row of cells with a head that sits on one cell at a time. <cite data-source="paper">A machine has one fixed finite alphabet and one fixed finite number of one-dimensional tapes.</cite> Only the contents of the tapes may grow with the input; the alphabet and the tape count may not.

Each step of such a machine is local. <cite data-source="paper">reads and writes at most one cell on each tape and moves each head by at most one cell.</cite> For example, suppose a tape holds the string 1011 with its head on the first cell. One step can overwrite that 1 with a 0 and move the head to the second cell, but it cannot jump to the fourth cell. Reaching a cell that lies many cells away from the head takes one step per cell crossed.

The fixed size of the machine is what makes the lower-bound question precise. Let $n$ be the number of bits in each of the two input integers. Let $T_A(n)$ be the running time of a machine $A$ on inputs of that length. Schönhage and Strassen conjectured that multiplication costs $n \log n$ in this setting, meaning that <cite data-source="paper">Schönhage and Strassen conjectured n log n as the optimal order of multiplication cost</cite>. Because the machine is fixed, the claim is a statement about each machine separately. <cite data-source="paper">In the present fixed-tape model, an eventual lower bound for every multiplication machine means</cite> that for each machine $A$ there are constants $c_A > 0$ and $N_A$ such that $T_A(n) \geq c_A\, n \log n$ for all $n \geq N_A$. The conjecture is therefore refuted in this model if some single fixed machine has running time whose ratio to $n \log n$ has limit inferior zero, which is the form of result the paper proves.
