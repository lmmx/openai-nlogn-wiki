Rank-saving recursion is a recursive scheme in which each call splits into several smaller calls, each on a stream holding a fixed fraction of the data, so that the cost per unit of data grows by a strictly smaller factor at each level. It is the step that gives the paper's power saving in the logarithmic factor, and the later estimates of [Integer multiplication below n log n](main-theorem.md) keep it.

Each wire of the network has a fixed place in the network, called its role, and carries a label, a subspace of a fixed ambient space. Let $m$ be the dimension of the ambient label space, a fixed number. Let $W$ be the number of wires in the network, which is also the number of roles among which the rows of the array are distributed. Let $V$ be the number of stored data bits in the array that the call works on. Let $f$ be the parameter of the call, the number of digits in the address field being interchanged, or the number of selected axes in a numerical layer. Let $s$ be the total number of smaller calls that one call makes.

Each call splits into smaller calls to the [address-field interchange](address-interchange.md), each on one role stream of $V/W$ bits. The rows are split into role streams by <cite data-source="paper">Distribute rows cyclically among the W roles</cite>, so every stream has the same size, and a call at parameter $mf$ therefore reduces to calls at parameter $f$ on streams of volume $V/W$.

Why $s < Wm$. Rank-saving recursion counts its smaller calls on the wires of the [subset-intersection network](subset-intersection-network.md). <cite data-source="paper">Their dimension changes count the smaller operations needed on an edge</cite>, so the number of smaller calls is governed by the dimension changes of the labels along the edges. Let $N$ be the sum of the dimensions of the labels at the sources, and let $L$ be the total dimension lost along decreasing edges, where an edge decreases when its label loses dimension. Summing the absolute dimension changes over all edges gives $Wm - 2N + 2L$, since <cite data-source="paper">the sum of absolute changes is</cite> the signed sum plus twice the lost dimension. Depending on the construction, $s$ equals $Wm - N + 2L$ or $Wm - 2N + 2L$, and both are at most $Wm - N + 2L$. The paper shows that <cite data-source="paper">We will obtain L < N/2.</cite>, so $2L < N$ and hence $s < Wm$. This is the key inequality: <cite data-source="paper">the total number s of smaller calls satisfies s < W m</cite>.

Why this gives a power saving. Let $g(f)$ be the cost of a call at parameter $f$ divided by its volume. A call at parameter $mf$ on volume $V$ makes $s$ calls at parameter $f$, each on volume $V/W$, plus work linear in $V$. <cite data-source="paper">After dividing cost by volume, multiplying the parameter by m increases the recursive contribution by s/W < m.</cite> Ignoring the linear work at each level, $g(mf) \approx (s/W)\, g(f)$. Set $\tau = \log_m(s/W)$, the power-saving exponent. Because $s/W < m$, we have $\tau < 1$, and iterating the relation gives $g(f) \approx f^{\tau}$. The cost of a call is therefore about $V f^{\tau}$, a power of $f$ with exponent below one. If instead $s/W$ equaled $m$, the exponent would be exactly one and no saving would occur. <cite data-source="paper">This strict inequality is the source of the power saving.</cite>

As a toy example, not the paper's values, take $W = 4$, $s = 6$ and $m = 2$. Then $s < Wm$ because $6 < 8$, and each doubling of the parameter multiplies $g$ by $s/W = 1.5$. So $\tau = \log_2 1.5 \approx 0.585$. With $s = 8$ instead, $s/W = m$, $\tau = 1$, and the saving disappears.

The two steps of the argument are therefore $s < Wm$, from the count above, and then $s/W < m$, from dividing by $W$. The second step gives the power saving.
