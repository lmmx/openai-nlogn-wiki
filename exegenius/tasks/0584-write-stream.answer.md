A stream is the order in which a procedure reads or writes a sequence of records on a tape, one position at a time. The recursion that saves a factor at each level works on streams: <cite data-source="paper">A recursive call at parameter mf therefore uses s calls at parameter f , each on a stream of volume V /W .</cite>

Visiting data in streams is what lets a procedure run in [Near-linear time](near-linear-time.md), because a tape head cannot jump. <cite data-source="paper">A step reads and writes at most one cell on each tape and moves each head by at most one cell.</cite> A scan is one pass of a head over a stream, from its first position to its last, followed by the return of the head to the start. <cite data-source="paper">Every scan includes its counters and the return of its tape heads.</cite>

A stream lists the entries of an [Array](array.md) in address order, since the array <cite data-source="paper">is stored in lexicographic order, with the first coordinate most significant</cite>. A stream position counts records from 0 within the stream and is not an address; the stream stores no addresses, because <cite data-source="paper">An address is implicit in an entry’s position in this ordered stream; it is not stored beside every data bit.</cite>

Take entries a to h at addresses 0 to 7, grouped into rows (a, b), (c, d), (e, f), (g, h). Splitting the rows cyclically gives the stream a, b, e, f (first and third rows) and c, d, g, h (second and fourth). Entry e has address 4 but stream position 2 in the first stream.

Each stream is formed by splitting an array on a specified digit of the [Mixed-radix digits](mixed-radix-digits.md) system. Each stream is scanned by a [Tape procedure](tape-procedure.md) in a fixed number of passes: <cite data-source="paper">Each stream is scanned a fixed number of times</cite>, so the work is linear in the volume. The lemma states <cite data-source="paper">Each of the following operations on an array of volume V takes O(V ) steps on a fixed number of one-dimensional tapes</cite>, including <cite data-source="paper">splitting on a specified radix-q digit, applying a fixed pointwise map to aligned streams, and merging them back</cite>.

Streams are aligned when they have the same remaining address set in the same order. <cite data-source="paper">splitting on one digit gives streams with the same remaining address set in the same order</cite>.

Each stream is carried by a wire of a fixed [Linear networks and frames](linear-network-frames.md). <cite data-source="paper">A wire’s fixed place in the network is called its role</cite>, and the stream that a role carries is its role stream. <cite data-source="paper">All role streams have the same local address set and each contains V /W bits.</cite> One scan, a fixed sequence of head moves over that address set, therefore processes every role stream in turn.

A fixed track is one of a fixed number of extra tracks that a tape carries beside its data, so each cell holds a tuple of symbols. <cite data-source="paper">Delimiters and the fixed number of tracks require only a fixed alphabet enlargement.</cite> Since a step still touches at most one cell per tape, <cite data-source="paper">Fixed tracks and finitely many work tapes change time by a fixed factor.</cite>
