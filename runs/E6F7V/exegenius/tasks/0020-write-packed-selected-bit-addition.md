## This page

Concept: Packed selected-bit addition
Gloss: A binary row addition (XOR) of selected bits across many address chunks at once, done by a constant number of whole-chunk cyclic shifts using a third chunk of arbitrary contents as temporary storage, followed by a deterministic repair of an explicitly bounded set of exceptional addresses.

## This page in the argument

The step: A binary row addition $y_{j_i}\leftarrow y_{j_i}\oplus x_{j_i}$ on the selected bit of $f$ address chunks at once, with a third chunk of arbitrary contents restored, costs $O(V(L^\tau+1))$ for the parameter family used.
How: Simulate the XORs by eight whole-chunk cyclic shifts that equal the intended parity flips whenever no segment carries, then deterministically repair the explicitly bounded set $\mathcal B$ of addresses where a guard value fails, by sorting.
Why: Adding $2^{j_i}$ to a chunk flips the selected bit without touching the other bits as long as the neighbouring $K$-bit segment does not carry; a guard margin makes carries rare, and the few exceptional addresses can be extracted and sorted cheaply. (the sources leave this for the reader to work out: spell it out)
Striking feature: A constant number (eight) of whole-chunk shifts performs the XOR on all $f$ selected positions together, regardless of how many there are, and the repaired set has fraction at most $80(f-1)2^{-K}$ because $K/\log p\to\infty$. (explain why it holds, from the method)

Its sub-steps, in order:

- The eight shifts leave the third integer $w$ unchanged and flip the parity of $u$ exactly when the control is one.
- The addresses where a guard value fails form a set $\mathcal B$ with $|\mathcal B|\le\delta_{\rm bad}M$ and $\delta_{\rm bad}=\min\{1,80(f-1)2^{-K}\}$.
- There are at most sixteen swaps and eight rotations, so the movement costs $O(V(L^\tau+1))$ by the chunk-swap and controlled-shift bounds.
- The exceptional records are extracted, sorted by destination rank and reinserted in one forward scan, which implements the ideal map everywhere.

It serves these steps, from the main result down:

- One deterministic fixed-tape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$, refuting the $n\log n$ optimality conjecture in this model.; how: Build the two accelerated tape procedures (address interchange and simultaneous butterfly layers), use them inside synthetic transforms and Gaussian resampling to compute a convolution, assemble the multiplication algorithm with exact recovery, and total the cost. (on [Integer multiplication in O(n (lg n)^(1−κ)) time](main-theorem.md))
- Two tape procedures cost less than a pass per level: interchanging two disjoint $u$-bit address fields of a volume-$V$ array costs $O(Vu^\tau)$ and a simultaneous butterfly layer on $D\le d$ chunks costs $O(Vd^{\lambda'})$, for fixed $\tau,\lambda'<1$.; how: Give each procedure its own fixed linear network that exchanges two banks of values and restores all scratch values, with total number $s$ of smaller calls below $Wm$, then run the network recursively on role streams of volume $V/W$ (interchange of address fields first, numerical layers second).
- A butterfly $H_0(u,v)=((u+v)/2,(u-v)/2)$ applied simultaneously at the same bit position of $D\le d$ address chunks of every polynomial record, followed by one truncation, costs $O(Vd^{\lambda'})$ for a fixed $\lambda'<1$ with error below $\sqrt2\,2^{-p}$.; how: Write $H_0^{\otimes D}=b^D\mathcal S_DC^{\otimes D}\mathcal S_D$, evaluate $C^{\otimes D}$ by the complex phase network recursively (children on $e/m$ axes, binary bases changed by packed selected-bit additions), evaluate everything exactly in Gaussian dyadics and truncate once. (on [Simultaneous butterfly layer in time O(V d^λ′)](simultaneous-butterfly-layer.md))

Source: "marked holes. One forward full-stream scan reinserts the sorted records." (paper)
