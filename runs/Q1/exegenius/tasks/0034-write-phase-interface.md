Gloss: Using phase frames 𝒞_U = H^{⊗m}·diag(i^{q_U(x)})·H^{⊗m} on the complex network so that each edge's frame change is a product of one translation kernel aI + bX_v per orthonormal residual vector and the whole network yields C^{⊗m} on every role.

## This page in the argument

The step: With phase frames $\mathcal C_U=H^{\otimes m}\operatorname{diag}(i^{q_U(x)})H^{\otimes m}$, each edge's frame change of the complex network is a product of one translation kernel $aI+bX_v$ (or its inverse) per orthonormal residual vector, these total $s_{\rm c}=W_{\rm c}m-2N+2L_{\rm c}<W_{\rm c}m$, and after diagonal corrections every role receives $C^{\otimes m}$.
How: Use weight additivity modulo four for orthogonal binary vectors to split each frame change into one phase per residual basis vector, conjugate by Hadamard matrices to turn each phase into a translation kernel, and fix the $X_a\to Y_a$ route with $Z$ signs.
Why: All phase frames are diagonalized by the same $H^{\otimes m}$, so frame changes are diagonal phases, and an orthonormal residual basis splits such a phase into independent one-direction factors, each one smaller $C$ layer. (the sources leave this for the reader to work out: spell it out)

Its sub-steps, in order:

- If $z\cdot w=0$ over $\mathbb F_2$, then $\operatorname{wt}(z+w)\equiv\operatorname{wt}(z)+\operatorname{wt}(w)\pmod 4$, so $q_V-q_U$ is a sum of one term per orthonormal residual vector.
- Each such phase $i^{\pm[v\cdot x]}$ becomes, after Hadamard conjugation, the kernel $aI+bX_v$ or its inverse.
- Applying $Z$ signs on the 27 support coordinates and the scalar $i^{27k}$ turns the $X_a\to Y_a$ route into $C^{\otimes mk}$ as well.

It serves these steps, from the main result down:

- One deterministic fixed-alphabet, fixed-tape Turing machine computes the exact $2n$-bit product of two $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ worst-case time with $\kappa=2^{-182}$, disproving the $n\log n$ conjecture in this model.; how: Reduce the product to radix-digit convolution, move it by a Chinese-remainder map, Gaussian resampling, chirps and a phase twist to convolution over $\mathbb C[y]/(y^r+1)$ computed by synthetic transforms; speed up the transforms' address movement and butterfly layers with two network-based tape procedures; then prove exact recovery and total the costs. - Two tape procedures save over plain scanning: address chunks of width $u$ are interchanged in $O(Vu^\tau)$ time, and a simultaneous normalized butterfly layer on $D\le d$ chunks costs $O(Vd^{\lambda'})$, with fixed $\tau,\lambda'<1$.; how: Build each procedure from its own fixed linear network that exchanges two banks and restores scratch wires, apply the network pointwise to row-split role streams with frames chosen so every edge is a few smaller calls, and solve the volume-normalized recurrence.

The function $i^{\varepsilon[v\cdot x]}$ equals \[ \frac{1+i^\varepsilon}{2} +\frac{1-i^\varepsilon}{2}(-1)^{v\cdot x}. \] The identity $H\operatorname{diag}(1,-1)H=X$, tensored over the coordinates in $\operatorname{supp}(v)$, sends the diagonal character $(-1)^{v\cdot x}$ to translation $X_v$.
