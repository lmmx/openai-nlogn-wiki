## This page

Concept: Rows distributed cyclically among wire roles
Gloss: To run the network on an array, whole rows are dealt cyclically into W role streams (padding the row count to a multiple of W per prefix), each of volume V/W with identical remaining shape, and gates act pointwise on matching addresses.

## This page in the argument

The step: Whole rows can be dealt cyclically into $W$ role streams, with the row count padded per prefix to a multiple of $W$, so that each stream has volume $V/W$ and the same remaining shape and gates act pointwise on matching addresses.
How: Write the row number as $r=Wg+(w-1)$ and send the whole row to stream $w$, indexed there by $g$.
Why: A pointwise gate needs its touched roles to have one common address set, which holds when every stream has exactly the same shape. (the sources leave this for the reader to work out: spell it out)

Its sub-steps, in order:

- Splitting whole rows cyclically gives $W$ streams of the same remaining shape, each of logical volume $V/W$.

It serves these steps, from the main result down:

- A single deterministic fixed-tape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.; how: Reduce multiplication to convolution over $\mathbb C[y]/(y^r+1)$ through radix digits, Chinese-remainder axes, Gaussian resampling and chirps, speed up the data movement and the butterfly arithmetic with two network-based tape procedures with a strict rank saving, recover the exact product by rounding and carries, and add up the costs. (on [Integer multiplication in O(n (lg n)^(1−κ)) time](main-theorem.md))
- Two tape procedures exist for fixed exponents $\tau,\lambda'<1$: one interchanges two disjoint address chunks of $u$ bits in $O(Vu^\tau)$ time, and one applies a normalized butterfly layer on up to $d$ address chunks in $O(Vd^{\lambda'})$ time, where $V$ is the logical bit volume.; how: Obtain both from one fixed linear network that exchanges two banks of values and restores every auxiliary value, whose edge frame changes are smaller calls of the same procedure; the strict inequality $s<Wm$ on their number gives a recursion with a power saving.
- There is a fixed $\tau<1$ and one fixed multitape procedure that interchanges two disjoint address chunks of $u$ bits, $(p,h,g,d,z)\mapsto(p,d,g,h,z)$, in $O(Vu^\tau)$ steps on an arbitrary bit array of volume $V$.; how: Peel off the top digits of both chunks to supply rows, pad the rows to a multiple of $W^k$, decompose the remaining width in base $m$ and apply the power-width interchange to each piece, then remove padding and reverse the high-digit moves. (on [Fast address-chunk interchange](chunk-swap.md))
- Two disjoint chunks of $e=m^k$ radix-$q$ digits each can be interchanged in $O(Ve^\tau)$ time, provided a preceding row field has length divisible by $W^k$.; how: Perform the interchange as the three shears $D\leftarrow D-H$, $H\leftarrow H+D$, $D\leftarrow H-D$ and run the middle shear through the bit network on $W$ role streams, applying an address shear to every edge by recursive smaller interchanges. (on [Power-width interchange with rows](power-width-interchange.md))

## Evidence from the sources, with the paragraph around each quote

- "Distribute rows cyclically among the $W$ roles, padding the row count
for each prefix to a multiple of $W$." (paper)

  > Each procedure arises from its own fixed linear network that exchanges two banks of values, with prescribed signs, and restores every auxiliary value. A wire's fixed place in the network is called its role. To use the network on an array, regard a row as the complete ordered suffix, including all active address fields, at a fixed prefix and row index. Distribute rows cyclically among the $W$ roles, padding the row count for each prefix to a multiple of $W$. Let $V$ now denote the node volume after padding. All role streams have the same local address set and each contains $V/W$ bits. A scalar gate is then applied pointwise to matching addresses on the roles that it touches.
