# W2 and W2b: writer runs on key-step pages, from a fixed 19/19 plan

Records of experiments W2 and W2b, run in the development session of lmmx/exegenius (plans, criteria and results: `calibration/plans/W2.md`, `calibration/plans/W2b.md`, each committed before its runs).

- **The plan:** every run writes from the same accepted argument plan (E9F4Y's, 19/19 faithful and 9/9 central in every judgement), so only the writer varies.
- **The pages:** 0014 (`S4.2`), 0015 (`subset-intersection-labels`, `S4.3`, the hard page) and 0016 (`rank-saving-recurrence`, `S4.4`, W2b only).
- **The configurations,** by the run name's third letter:
  - `S`: Sonnet `high`;
  - `M`: Sonnet `medium`;
  - `H`: Haiku `high`;
  - `O`: Opus `xhigh`.
- **The runs:**
  - W2: `W2W{S,M,H,O}P14` and `W2W{S,M,H,O}P15`;
  - W2b: the repeats `W2WSP15R` and `W2WOP15R`, and `W2WSP16` and `W2WOP16`.
- Each prompt went word for word to a fresh `general-purpose` subagent with the stated model and effort.
- **Excluded:** `W2WOP15R` compiled a small Rust word counter inside its task directory. Its `target/` build output (about 30 MB) is left out; the source (`wc/src/main.rs`, `Cargo.toml`) is kept.
- `results/transcripts/w2/subagents/`: the twelve writers' transcripts and `.meta.json`.
