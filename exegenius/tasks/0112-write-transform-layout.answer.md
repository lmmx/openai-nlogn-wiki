The tape layout arranges the address bits of an array so that each round of a [synthetic polynomial transform](synthetic-transform.md) over $\mathcal R_r$ runs as one [simultaneous butterfly layer](simultaneous-layer.md) instead of one pass per participating axis.

Write $\ell=\log_2 r$ and $D=d-1$, the number of transformed axes (not the layer's chunk count). Axis $i$ has length $t_i\in\{2^{\ell-1},2^\ell\}$: call it long if it has $\ell$ address bits and short if $\ell-1$. With $\boldsymbol t=(t_1,\dots,t_D)$, $F_{\boldsymbol t}^-$ is the forward synthetic transform along all $D$ axes, axis $i$ having length $t_i$, and $F_{\boldsymbol t}^+$ is its opposite. Records are [fixed-point Gaussian dyadic records](fixed-point.md) with $\Theta(p)$ bits per coefficient and $d\ell=O(p)$, so the array holds $\Theta(Tp)$ bits and one pass over it costs $O(Tp)$. Chunks are $K$ bits wide, $1\le K\le\ell-1$.

The layout keeps outputs in the bit-reversed order of [retained frequency order](frequency-order.md), written $B$ when applied along every axis: the pointwise product keeps it and the opposite procedure consumes it.

A round butterflies one address bit of each axis. A simultaneous layer needs those bits at a common offset in consecutive $K$-bit chunks <cite data-source="paper">we must place the selected bits of the participating axes at a common</cite>. The layout $L$ below provides this.

Put $b=(\ell-1)\bmod K$ and $q=\lfloor(\ell-1)/K\rfloor$, so $\ell-1=qK+b$. These letters change meaning here: $b$ counts the low bits of an axis left over after whole chunks, and $q$ the whole chunks per axis. Move to a prefix, one slot at a time, the top bit of each long axis and the $b$ lowest bits of each axis. At most $D(b+1)=O(dK)$ slots move, each by one pass, so the moves cost $O(TpdK)$ <cite data-source="paper">listed slots, so the moves cost $O(TpdK)$.</cite>

Each axis now keeps $qK$ bits, which are $q$ consecutive chunks. The goal is chunk 1 of every axis, then chunk 2 of every axis, and so on. Scan target positions left to right and, at each but the last, exchange the chunk there with the required one if they differ. This needs at most $Dq-1$ exchanges, even for nonadjacent chunks <cite data-source="paper">exchanges of width-$K$ address chunks, even when the chunks are</cite>. The layout groups equal-index chunks by exchanging them with the [fast address-chunk interchange](address-interchange.md), each exchange costing $O(TpK^\tau)$. Since $DqK\le D\ell\le d\ell=O(p)$, the exchanges cost $O(Tp\,DqK^\tau)=O(Tp\,(DqK)K^{\tau-1})=O(Tp\,pK^{\tau-1})$. The prefix moves and exchanges define the record permutation $L$ (a record at address $x$ moves to $Lx$, its coefficients intact); undoing them in reverse order gives $L^{-1}$ at the same cost.

There is one round per bit position of a long axis: $b+1$ rounds on prefix slots and $qK$ on the chunks, $\ell$ in all. In a chunk round the selected bit has the same offset in $D$ consecutive chunks. The layout runs each chunk round as one [simultaneous butterfly layer](simultaneous-layer.md), costing $O(Tpd^{\lambda'})$, so the chunk rounds cost $O(Tp\ell d^{\lambda'})$ in total <cite data-source="paper">$O(Tpd^{\lambda'})$ per round and $O(Tp\ell d^{\lambda'})$ in total.</cite> A prefix round processes its at most $D$ bits individually, each in $O(Tp)$, so costs $O(Tpd)$; at most $b+1\le K$ such rounds cost $O(TpdK)$.

Each round is the contraction $\mathcal H$ (a linear map that does not increase norms), the signed coefficient permutation $J_E$, and one truncation $Q_p$. Truncation toward zero is odd and acts separately on each real and imaginary part, so for the array $z$ entering a round, $J_EQ_p(\mathcal Hz)=Q_p(J_E\mathcal Hz)$: the layer's own truncation equals one truncation after the exact round. Compare the computed array with the exact one. The exact round does not increase the norm of their difference, and the truncation then moves each real and imaginary part by less than $2^{-p}$, hence each entry by less than $\sqrt2\,2^{-p}$. By the triangle inequality each round raises the error by less than $\sqrt2\,2^{-p}$. Starting from zero error, the $\ell$ rounds leave error below $\sqrt2\,\ell\,2^{-p}$ <cite data-source="paper">zero error, at most $\ell$ rounds therefore</cite>. The permutations in $L$ are isometries and add none.

Executing the arithmetic on named slots after $L$ conjugates it by $L$. The forward procedure first moves records by $L$, then runs $BF_{\boldsymbol t}^-$ on the named slots, giving $(LBF_{\boldsymbol t}^-L^{-1})L=LBF_{\boldsymbol t}^-$. The opposite procedure runs its arithmetic and then restores by $L^{-1}$, giving $L^{-1}(LF_{\boldsymbol t}^+B^{-1}L^{-1})=F_{\boldsymbol t}^+B^{-1}L^{-1}$. So the forward entry with frequency address $j$ is stored at $L(Bj)$. Adding the costs, both procedures cost $O(Tp[dK+pK^{\tau-1}+\ell d^{\lambda'}])$.
