A fixed-tape machine is a multitape Turing machine whose alphabet and number of one-dimensional tapes are fixed before any input is read and do not change with the input length, so one machine must handle inputs of every size. A standard multitape machine may use more tapes, or a larger alphabet, as its input grows; a fixed-tape machine may not. The integer multiplication result of this argument is proved in this model, so its bounds on multiplication cost are claims about such machines.

Running time is measured as usual: the worst case, over all inputs of a given size, of the number of steps the machine takes. Here $n$ is the length in bits of each input.

The step that needs a fixed-tape machine is the existence of one machine that works for all sizes. The paper's main theorem supplies it. It states that there is one deterministic machine with <cite data-source="paper">a fixed finite alphabet and a fixed finite number of one-dimensional tapes</cite>, which computes the exact product of two integers for every input size. Because one program serves every $n$, its alphabet and tape count cannot grow with $n$. The theorem also bounds its worst-case time by a constant times $n(\lg n)^{1-\kappa}$, where $\kappa = 2^{-182}$ is a fixed constant, the same for every $n$. So the multiplication bound is a claim about a fixed-tape machine. The proof of the theorem is in the paper.
