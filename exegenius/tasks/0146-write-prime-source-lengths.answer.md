Prime source lengths are distinct odd primes $s_1,\dots,s_d$, where $s_i$ is the prime source length of axis $i$ and $d$ is the number of axes of a multidimensional transform, each prime chosen close to the power of two to which its axis is padded. Their product fills a fixed fraction of the padded box, which is what lets the [integer multiplication below n log n](main-theorem.md) algorithm keep every term of its cost table within the bound of the theorem.

An axis is one coordinate direction of a multidimensional array, and a multidimensional transform acts along every axis. Padding an axis to length $t$ means extending it with unused positions up to $t$ entries. Let $d$ be the number of axes. Let $\beta=\lceil\log_2 n\rceil$ be the number of bits needed to write $n$. Let $t_i$ be the padded length of axis $i$, a power of two, and let $T=t_1t_2\cdots t_d$ be the size of the padded box. The source takes <cite data-source="paper">Take the power of two T in [4n/b, 8n/b)</cite>, so $4n/\beta\le T<8n/\beta$.

Let $u$ be the smallest power of two with $u^d\ge T$. The source calls this length $r$, but $r$ is the record length on earlier pages, so here it is $u$. Let $w$ be the number of axes whose padded length is $u/2$; the other axes have length $u$. The source's rule is to choose <cite data-source="paper">of the d axis lengths to be r/2 and the others to be r</cite>. The lengths then multiply to $u^d/2^w$, which must equal $T$, so $w=d\log_2 u-\log_2 T$. Minimality of $u$ gives $(u/2)^d<T\le u^d$, so $0\le w<d$ and such a choice exists. The bound on $T$ alone does not fix the lengths; the construction does.

The counting tool is a prime-interval bound. <cite data-source="paper">The prime-interval result [15, Lemma 5.1], based on explicit estimates of Rosser and Schoenfeld [23], gives the following bound</cite>. Here $\eta$ is a slack fraction, $\xi$ is a real scale, and $\sigma$ is a prime. For $0<\eta<1/4$ and $\xi>e^{2/\eta}$, the interval $(1-2\eta)\xi<\sigma\le(1-\eta)\xi$ contains at least $\eta\xi/(2\ln\xi)$ primes $\sigma$, where $\ln$ is the natural logarithm.

Take $\eta=1/(4d)$, so $2/\eta=8d$ and the lower bound is $\xi/(8d\ln\xi)$. Apply it with $\xi=u/2$ and $\xi=u$. Each needs $\xi>e^{8d}$, that is $\ln\xi>8d$, and a count above $d$, that is $\xi>8d^2\ln\xi$. Both persist for larger $\xi$, so it suffices to check $\xi=u/2$. The source's parameters give $\ln(u/2)/d\to\infty$. With $Y=\ln(u/2)$, for large $n$ we have $Y>8d$ and $d<Y$, so $u/2=e^Y>8Y^3\ge 8d^2Y$.

Both intervals lie above $2$, so their primes are odd. They are disjoint, since $(1-\eta)u/2<(1-2\eta)u$ when $3\eta<1$. Each holds more than $d$ primes, so the axes of length $u/2$ take distinct primes from the first and the others from the second. Let $s_i$ be the prime source length of axis $i$, a distinct odd prime, chosen so that
$$(1-2\eta)\,t_i<s_i\le(1-\eta)\,t_i .$$

Here $\gcd$ is the greatest common divisor. <cite data-source="paper">Every gcd(si , ti ) equals one because ti is a power of two.</cite> The lengths $s_1,\dots,s_d$ are distinct primes, so they satisfy the pairwise form of [Coprime](coprime.md). The distinct primes supply pairwise coprime lengths to the [Chinese-remainder map](chinese-remainder-map.md), which relabels coefficient positions by [Mixed-radix digits](mixed-radix-digits.md).

Let $S=s_1s_2\cdots s_d$, the total number of positions. Since $2\eta=\frac{1}{2d}$, each $s_i>(1-\frac{1}{2d})t_i$, and multiplying these bounds with $\prod_i t_i=T$ gives $S>(1-\frac{1}{2d})^dT$. The source derives the next step from <cite data-source="paper">bounds on si and applying strict Bernoulli inequality gives</cite> $(1-\frac{1}{2d})^d>\frac12$ for $d\ge2$. Bernoulli's inequality $(1+x)^d\ge1+dx$ is strict for $x\ne0$ and $d\ge2$, and with $x=-\frac{1}{2d}$ the right side is $\frac12$. Since $s_i<t_i$ for each $i$, $S<T$, so <cite data-source="paper">this gives T /2 < S < T</cite>. The lengths set the place values of the [Mixed-radix digits](mixed-radix-digits.md) of the $S$ positions, so digit $i$ runs from $0$ to $s_i-1$.

Let $\theta_i=t_i/s_i-1$ be the relative gap of axis $i$. From $s_i\le(1-\eta)t_i$ we get $t_i/s_i\ge1/(1-\eta)$, so $\theta_i\ge\eta/(1-\eta)>\eta$. Each ratio $t_i/s_i$ must leave enough separation for [Gaussian resampling](gaussian-resampling.md). The source checks this gap against its parameter choices; this page establishes only $\theta_i>\eta=1/(4d)$.

The machine finds these primes <cite data-source="paper">by scanning the two intervals deterministically</cite>, testing each candidate by trial division (dividing by the integers up to its square root). Scanning $O(u)$ candidates with $O(\sqrt u)$ divisors each costs $O(d\,u^{3/2}\,\mathrm{poly}(\beta))$. Since $\log_2 u<1+(\beta+3)/d$, the logarithm of this cost is $O(\log\beta)+O(\beta/d)=o(\beta)$, because $d$ grows with $\beta$. As $2^\beta$ is about $n$, the search takes $n^{o(1)}=o(n)$ time, as the source states: <cite data-source="paper">the search takes no(1) = o(n) time.</cite>

Worked example. Take $d=2$, so $\eta=1/8$, and $T=128$. Then $u=16$, since $8^2<128\le 16^2$, and $w=1$, so $t_1=16$ and $t_2=8$. The interval $(12,14]$ contains only $13$, and $(6,7]$ contains only $7$, so $s_1=13$, $s_2=7$, $S=91$, and $64<91<128$. The gap $\theta_1=16/13-1\approx0.23$ exceeds $\eta/(1-\eta)=1/7$. The lemma needs $\xi>e^{2/\eta}=e^{16}\approx 8.9\times10^6$, far above the scales $8$ and $16$, so the example picks the primes by hand.
