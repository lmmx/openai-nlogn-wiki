Address-field interchange is a tape procedure that swaps two disjoint contiguous address fields of an array in time that grows like a power of the field width. [Integer multiplication below n log n](main-theorem.md) uses it to organize the layouts of its transforms. The procedure runs on the [Fixed-tape machine model](fixed-tape-model.md) with a fixed number of one-dimensional tapes.

The paper states: <cite data-source="paper">The first procedure interchanges two disjoint contiguous address fields of u bits in an array</cite>. Here $u$ is the field width and $V$ the stored bit volume. <cite data-source="paper">Its cost is O(V uτ ) for a fixed τ < 1.</cite> The letter $\tau$ changes meaning here: it is this fixed exponent, below 1.

The method uses XOR combinations: <cite data-source="paper">Our address procedure forms XOR combinations of intermediate data</cite>, although its final effect is a permutation. Let $x$ and $y$ be the two fields, each read as a block of bits at matching positions; these letters change meaning here. Let $\oplus$ be exclusive or (XOR), addition modulo 2. Three XOR updates swap the fields:
$$(x,y)\to(x,\;x\oplus y)\to(y,\;x\oplus y)\to(y,\;x).$$
The second update works because $x\oplus(x\oplus y)=y$, a block XORed with itself being zero. Each update is its own inverse, so their composition is a permutation. For $x=10$, $y=01$ the chain is $(10,01)\to(10,11)\to(01,11)\to(01,10)$. With signs, the paper writes: <cite data-source="paper">(x, y), the three stages give (x, y + x), then (−y, y + x), then (−y, x).</cite> Over bits the signs vanish.

The interchange is carried out by a [Linear networks and frames](linear-network-frames.md) network. Its gates act pointwise: <cite data-source="paper">Execute each circuit gate pointwise at matching addresses of its role streams.</cite> The network has scratch wires with arbitrary starting values. Its schedule subtracts their effect, then adds the same terms back, so they cancel from the net change, which depends only on $x$. The network thus [restores its scratch storage](scratch-storage.md) to its starting contents, whatever they were. <cite data-source="paper">For arbitrary initial values of its auxiliary wires, a forward invocation changes yS to</cite> <cite data-source="paper">yS + xS and leaves every other value unchanged.</cite>

The cost comes from a recursion on width. Let $m\ge 2$ be a fixed integer, the number of pieces each field is cut into; this letter changes meaning here. Take $u=m^k$, so the recursion has $k$ levels, where $k=\log_m u$ counts them; this letter changes meaning here too. The base case is one digit: <cite data-source="paper">For k = 0 apply the single-digit operation of Lemma 3.</cite>

Let $s$ be the number of smaller calls one call makes; this letter changes meaning here. <cite data-source="paper">The number of recursive calls is the sum of the edge ranks, exactly s.</cite> An edge whose matrix has [matrix rank](matrix-rank.md) $r$ needs $r$ smaller interchanges. Each call works on one stream, and <cite data-source="paper">each contains V /W bits.</cite> The counting gives <cite data-source="paper">that the total number s of smaller calls satisfies s < W m.</cite> So $s/W<m$.

Let $\vartheta_j$ be the time per unit volume of a call on width $m^j$, the level $j$; the letter $j$ changes meaning here. A call of volume $V$ spends $CV$ on its own work, with $C$ a constant, since <cite data-source="paper">triangular operations have total cost O(V ) because their number is fixed.</cite> Its $s$ children each have volume $V/W$. So $\vartheta_0=O(1)$ and
$$\vartheta_j\le C+\frac{s}{W}\,\vartheta_{j-1}.$$
The exponent is chosen as in the paper: <cite data-source="paper">Choose a rational number τ ∈ (0, 1) with s/W < mτ .</cite> Such $\tau$ exists because $s/W<m$ and $m^{\tau}\to m$ as $\tau\to 1$.

Unrolling gives $\vartheta_k\le C\sum_{j=0}^{k-1}(s/W)^j+(s/W)^k\vartheta_0$. If $s/W\le 1$, this is $O(k)=O(m^{\tau k})$. If $s/W>1$, it is $O((s/W)^k)$, and $(s/W)^k<(m^{\tau})^k$. Since $(m^{\tau})^k=(m^k)^{\tau}=u^{\tau}$, either way $V\vartheta_k=O(Vu^{\tau})$.
