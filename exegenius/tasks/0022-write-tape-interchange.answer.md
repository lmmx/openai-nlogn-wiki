Fast interchange of address chunks is a procedure that runs on a [fixed-tape machine model](fixed-tape-model.md) and swaps two disjoint, equal-width address fields of an array in time less than linear in the field width. The multiplication algorithm uses it to rearrange the layouts of its tapes, so that the tape cost per unit of stored data falls below linear in the chunk width.

Let $A$ and $B$ be two disjoint address fields of equal width, where an address field is a block of consecutive bits in the address of each array entry. The interchange sends each address to the address with the bits in $A$ and $B$ exchanged. Here $u$ is the width of each field, the number of bits in it, and $V$ is the stored volume, the total number of data units held in the array. The interchange costs $O(Vu^{\tau})$ for a fixed exponent $\tau<1$ <cite data-source="paper">Its cost is $O(Vu^\tau)$ for a fixed $\tau<1$</cite>.

The procedure is computed by a [rank-saving recursion](recursive-saving.md) on a bit network, and $m$ is the recursion parameter of that scheme. The bit network is closed by an [address shear](address-shear.md), its endpoint operator. Each edge matrix of rank $a$ requires $a$ smaller interchanges, and the sum of these ranks over the wires is less than the number of wires times $m$. Because that sum is less than the number of wires times $m$, the resulting recurrence saves a power of the chunk width. The saving is what makes the cost sublinear in $u$.

The intermediate steps of the procedure form pointwise XOR combinations of data, bit by bit. The final permutation is nevertheless exact for arbitrary initial auxiliary values, so the auxiliary cells can hold any contents when the interchange starts.
