Fast address-chunk interchange is the first tape primitive in the main result: it swaps two disjoint address fields, called chunks, of $u$ bits each in an array of volume $V$ in $O(Vu^\tau)$ time on fixed tapes <cite data-source="paper">Its cost is $O(Vu^\tau)$ for a fixed $\tau<1$.</cite>, with $\tau=1-2^{-50}$. Intermediate steps XOR data, yet the result is exact.

An address is $(p,h,g,d,z)$, where $p$ is a prefix (not fractional bits), $h$ and $d$ are the two chunks (not an index or axis count), $g$ is the gap between them and $z$ is the suffix. The goal is $(p,h,g,d,z)\mapsto(p,d,g,h,z)$. Here $u$ is the chunk width (not a DFT input sequence), $V$ is the number of stored digits (a volume, not a label), and $q$ is the fixed prime radix of the digits (not a sequence length).

For chunk values $H,D$, the updates $D\gets D-H$, $H\gets H+D$, $D\gets H-D$ send $(H,D)$ to $(H,D-H)$, then $(D,D-H)$, then $(D,H)$. Only the middle shear $H\gets H+D$ uses the circuit; the others are scans.

Let each chunk have $e=m^k$ digits, where $m$ is the label dimension and $k$ counts recursion levels (not a depth). Cut it into $m$ fields of $b=e/m$ digits, so $H,D$ become vectors over $\mathbb Z/q^b\mathbb Z$.

The [Linear exchange network with restored scratch wires](exchange-network.md) has $W$ wires. Each vertex carries a rational $m\times m$ matrix $M$ (a vertex matrix, not an address count), and edge $i$ carries $A_i=M_{\mathrm{head}(i)}-M_{\mathrm{tail}(i)}$. Let $s=\sum_i\operatorname{rank}A_i$. The shear contract: input wire $w$ is routed to an output role $\rho(w)$ with $M_{\mathrm{out}(\rho(w))}-M_{\mathrm{in}(w)}=I_m$, the identity. By [Nested subspace labels and rank deficit](subspace-labels.md), $s<Wm$; fix $\tau$ with $s/W<m^\tau$. The deficit is tiny, so $\tau$ is close to 1.

Let $\Phi_M$ move the entry at address $(H,D)$ to $(H+MD,D)$, so $\Phi_{M'}\Phi_M=\Phi_{M'+M}$. With [Frames on wire arrays](array-frames.md), the frame at a vertex with matrix $M$ is the address permutation $\Phi_M$, and each edge changes it by $\Phi_{A_i}$. A common address permutation commutes with every pointwise bit gate.

Each edge shear $\Phi_{A_i}$ is performed by [Matrix shear by triangular factorization](matrix-shear.md). A matrix of rank $a$ costs $a$ interchanges of pairs of $b$-digit fields <cite data-source="paper">An edge matrix of rank $a$ will require $a$ smaller interchanges.</cite>. So the circuit makes exactly $s$ smaller calls <cite data-source="paper">The number of recursive calls is the sum of the edge ranks, exactly $s$.</cite>.

Suppose a row field before both chunks has length divisible by $W^k$. Rows are split cyclically into $W$ role streams by [Elementary stream operations](stream-ops.md). Row $Wx+w-1$ goes to stream $w$ as row $x$ ($x$ is a row number, not a vector of $F$). Each stream has volume $V/W$ and row count divisible by $W^{k-1}$, so the argument repeats one level down. On every circuit edge, apply $\Phi_{A_i}$ to that role stream. Read the input $f_w$ as the logical array $\Phi_{-M_{\mathrm{in}(w)}}f_w$. By the contract, the physical output is $f'_{\rho(w)}=\Phi_{M_{\mathrm{out}(\rho(w))}}\Phi_{-M_{\mathrm{in}(w)}}f_w=\Phi_{I_m}f_w$. Merging rows back undoes $\rho$, so the result is $H\gets H+D$ on every original row, including scratch rows.

Let $F_k$ be the time per unit volume for chunks of $m^k$ digits. Then $F_0=O(1)$. Splitting, merging, gates and scheduling are fixed passes, costing $O(V)$ at the node itself. The $s$ smaller calls each act on volume $V/W$, so $F_k\le(s/W)F_{k-1}+O(1)$, which obeys the recurrence of [Recursive power saving](rank-recurrence.md). Unrolling over levels $j$ ($j$ is a level index, not a stage number or wrap count) gives $F_k=O(\sum_{j=0}^k (s/W)^j)$. If $s/W\le1$, every term is at most $1$, so the sum is at most $k+1=O(m^{k\tau})$. Otherwise the geometric series $\sum_{j=0}^k (s/W)^j=((s/W)^{k+1}-1)/(s/W-1)$ gives $O((s/W)^k)$, below $m^{k\tau}$. Either way $F_k=O(e^\tau)$ <cite data-source="paper">Hence $F_k=O(e^\tau)$.</cite>. The saving is a power of $e$ because each level multiplies the cost by $s/W$ rather than $m$, and $m^k=e$.

For other widths and large $e$, put $k'=\lceil\log_m e\rceil$, the number of levels needed, and $\nu=\lceil k'\log W/(2\log q)\rceil$, the count of top digits set aside, so that $q^{2\nu}\ge W^{k'}$ and $\nu=O(\log 2e)$. Split each chunk into top digits and rest, $h^+,h^-$ and $d^+,d^-$. Interchange the high digits and move $h^+$ next to $d^+$, turning $(h^+,h^-,g,d^+,d^-)$ into $(d^+,h^+,h^-,g,d^-)$. Now $d^+,h^+$ form a row field of range $\Lambda=q^{2\nu}\ge W^{k'}$ before both remaining chunks. Pad with zero rows to $\Lambda'=W^{k'}\lceil\Lambda/W^{k'}\rceil<2\Lambda$ rows, so the volume stays below $2V$ and the count is divisible by each needed $W^j$.

Write the remaining width in base $m$: $e-\nu=\sum_{j=0}^{k'}a_jm^j$ with $0\le a_j<m$, cutting each remaining chunk into $a_j$ pieces of width $m^j$. Interchange corresponding pieces by the case above. The total is $O(V)\sum_ja_jm^{j\tau}\le O(V)\,m\sum_jm^{j\tau}=O(Ve^\tau)$, because $a_j<m$ and $\sum_jm^{j\tau}=O(m^{k'\tau})=O(e^\tau)$ as $m^{k'}<me$. Removing the padding and joining costs $O(V\nu)=O(Ve^\tau)$.

For $u$-bit chunks, let $e$ be the least integer with $q^e\ge2^u$ and pad each chunk range from $[2^u]$ to $[q^e]$, a fixed volume factor. Since $e=O(u)$, the cost is $O(Vu^\tau)$ <cite data-source="paper">Since $e=O(u)$ for fixed $q$, the bound is $O(Vu^\tau)$.</cite>.
