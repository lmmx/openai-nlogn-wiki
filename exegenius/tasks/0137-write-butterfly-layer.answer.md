The simultaneous butterfly layer $H_0$ is the map that applies a two-point butterfly to one selected address bit of every chunk in one pass. It is the basic step of the transforms, which need many address bits transformed at once.

A butterfly on one bit takes two values $u$ and $v$ at the two addresses that differ only in that bit, and replaces them by $(u+v)/2$ and $(u-v)/2$. An address chunk is a block of consecutive address bits. Here $d$ is the number of chunks, not the number of axes used on the transform page. The layer is the map $H_0(u,v)=\bigl((u+v)/2,(u-v)/2\bigr)$ applied at once to one selected bit of each of the $d$ equal-width chunks, with the selected bits at a common offset from the least significant end.

Applying $H_0$ to all $d$ selected bits is built by the [Tensor product](tensor-product.md) of the $d$ single-bit butterflies, so applying them one at a time in any order gives the same result.

The layer acts on arrays stored in the [Frame of a vertex](frame.md) on each wire. Each address holds a polynomial record of $r$ complex coefficients, where $r$ is the number of complex coefficients in a record. $H_0$ acts coefficientwise. For $u=1+i$ and $v=1-i$ the output pair is $(1,\,i)$, since $(u+v)/2=1$ and $(u-v)/2=i$.

Intermediate values in the layer are exact [Gaussian dyadic numbers](gaussian-dyadic.md), whose real and imaginary parts have power-of-two denominators, each stored with $p$ bits after the binary point.

The cost counts tape operations, with $V$ the stored volume. The pointwise arithmetic costs $O(V)$: each pair of coefficients takes a fixed number of exact operations on these parts, and the source charges each such pass to the stored volume. The rest is address movement, using the fast chunk interchange of [Fast interchange of address chunks](tape-interchange.md). Swapping two chunks of $e$ positions each costs $O(Ve^\tau)$ for a fixed $\tau<1$, where $e$ is the number of positions in each chunk. <cite data-source="paper">The chunks can be interchanged in $O(Ve^\tau)$ time</cite>.

The layer costs $O(Vd^{\lambda'})$ in total <cite data-source="paper">the cost is $O(Vd^{\lambda'})$</cite>, where $\lambda'<1$ is a fixed exponent. The chunks have equal width and a common selected offset, so a group of chunks can be moved by one swap. The proof, in the paper's section on fast butterfly layers, splits the chunks into groups of power-of-base sizes, moves each group with swaps, and sums the costs over $O(\log d)$ levels. The sum is $O(d^{\lambda'})$ for any $\lambda'$ above the swap exponents and below 1. Since $d^{\lambda'}<d$ for $d\ge2$, this beats the $d$ whole-array passes that separate single-bit butterflies would take, each costing $O(V)$.
