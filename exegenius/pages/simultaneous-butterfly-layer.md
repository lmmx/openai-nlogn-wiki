A simultaneous butterfly layer applies the two-point map of a [butterfly](butterfly.md) to one selected bit of each of several transform axes at once, computing the exact result in one tape procedure. It is the step that lets a transform round apply its butterflies on all participating axes together, as the [main theorem](main-theorem.md) requires. A transform round is one step of a multidimensional transform: <cite data-source="paper">A round applies one current H0 on each participating axis.</cite>

The layer acts on $D$ [transform axes](transform-axis.md), where $D$ is the number of axes. Each axis is a chunk of $\delta$ consecutive address bits, where $\delta$ is the number of bits in each chunk. In each chunk one bit is selected, at the same offset $o$ with $0\le o<\delta$, where $o$ is the position of the selected bit within its chunk, counted from the least significant end. The layer acts on these $D$ selected bits and fixes every other bit. Each address holds a record of $r$ complex coefficients, and the layer acts on every coefficient.

Write $H_0(u,v)=((u+v)/2,(u-v)/2)$ for the two-point map, whose matrix is $H_0=\frac12\left(\begin{array}{cc}1&1\\1&-1\end{array}\right)$. The layer is the tensor power of $H_0$ on the selected bits, written $H_0^{\otimes D}$, the [tensor product](tensor-product.md) of $D$ copies of $H_0$, one for each selected bit.

Let $F_q$ be the transform with $(F_q u)_k=\frac1q\sum_{j=0}^{q-1}u_j e^{-2π i jk/q}$, where $q$ is the number of values transformed, $j$ indexes the input values and $k$ the output coordinates. The layer applies the length-two case of the [discrete Fourier transform](discrete-fourier-transform.md) to each selected bit. For $q=2$, $e^{-π i jk}=(-1)^{jk}$, so $F_2$ is exactly $H_0$. The unitary normalization $1/\sqrt q$ gives the normalized Hadamard matrix $\mathcal H=\frac1{\sqrt2}\left(\begin{array}{cc}1&1\\1&-1\end{array}\right)=\sqrt2\,H_0$.

Take $D=2$, $\delta=1$, $o=0$ and $r=1$. Put the values $1,2,3,4$ at addresses $00,01,10,11$. Applying $H_0$ to the first bit maps $(1,3)$ and $(2,4)$ to $2,-1$ and $3,-1$, so the addresses hold $2,3,-1,-1$. Applying $H_0$ to the second bit maps $(2,3)$ and $(-1,-1)$ to $2.5,-0.5$ and $-1,0$, so the result is $2.5,-0.5,-1,0$.

Applying the one-axis factors in turn is costly: <cite data-source="paper">separate butterfly factors would require D whole-array passes</cite>, where one pass reads and rewrites every stored record. The sources instead run the whole layer as <cite data-source="paper">one fixed finite-alphabet multitape procedure</cite>, a fixed program of tape reads and writes. Three rewritings make this possible.

First, phase identities. $H_0$ is not yet a two-point kernel, since its diagonal entries $\frac12$ and $-\frac12$ differ. Let $\Delta=\mathrm{diag}(1,i)$ be a diagonal phase matrix, $X=\left(\begin{array}{cc}0&1\\1&0\end{array}\right)$ the bit-flip matrix, and $I$ the $2\times2$ identity matrix. Let $\lambda=(1+i)/2$ and $\mu=(1-i)/2$, where $\lambda$ is the coefficient of the identity $I$ and $\mu$ the coefficient of $X$. Define $C=\mathcal H\Delta\mathcal H$, which equals $\lambda I+\mu X$. <cite data-source="paper">These identities use only Gaussian dyadic coefficients.</cite> Direct multiplication gives $H_0=\mu\,\Delta C\,\Delta$. The layer is built from the [two-point kernel](two-point-kernel.md) $C$ on each selected bit. Here $\Delta_D=\Delta^{\otimes D}$ multiplies the value at each address by $i$ raised to the number of selected bits equal to 1 there, so $\Delta_D$ is diagonal. Since the tensor product of matrices satisfies $(AB)\otimes(A'B')=(A\otimes A')(B\otimes B')$, this gives $H_0^{\otimes D}=\mu^D\,\Delta_D\,C^{\otimes D}\,\Delta_D$. The layer expresses its phase frames through the [complex phase network](complex-phase-network.md), as products of $C$ on the selected bits. The remaining work is $C^{\otimes D}$.

Second, binary changes of basis. $C^{\otimes D}$ still acts on all $D$ bits. The layer groups the selected bits by [binary changes of basis](binary-change-of-basis.md), invertible row additions over the [binary field](binary-field.md) that relabel the bits, so that each group gives a smaller tensor product. <cite data-source="paper">We implement those changes by moving whole address chunks.</cite> The layer moves its address chunks by [address-field interchange](address-interchange.md), a tape procedure. <cite data-source="paper">The first procedure interchanges two disjoint contiguous address fields of u bits in an array</cite>. A chunk swap is one such interchange.

Third, exact values and one truncation. Here $p$ is the working precision in bits. The inputs are <cite data-source="paper">initially in the unit disk on the grid 2−p Z[i]</cite>. Here $s$ changes meaning and counts the individual factors $H_0$ applied. <cite data-source="paper">after s ≤ D individual H0 factors, the coefficients are exact dyadics on the 2−(p+s) grid and still lie in the disk.</cite> Each $H_0$ carries a factor $\frac12$, so $s$ factors refine the grid spacing to $2^{-(p+s)}$. A component in $[-1,1]$ on that grid is an integer multiple of $2^{-(p+s)}$, so it needs $p+s+O(1)$ bits. <cite data-source="paper">Hence p + D + O(1) = O(p) bits per component suffice, since D ≤ d and dℓ = O(p).</cite>

The layer rests on [Gaussian dyadics](gaussian-dyadics.md). <cite data-source="paper">wrappers, and scalar corrections above are exact Gaussian dyadic operations.</cite> The procedure ends with one final [truncation](truncation.md) of its values. <cite data-source="paper">The procedure evaluates the entire layer exactly before this final truncation.</cite> Rounding after each factor would add error at every step; with exact values, this one truncation is the only rounding.
