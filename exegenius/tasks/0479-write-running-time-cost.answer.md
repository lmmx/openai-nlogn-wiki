The running time cost of a machine is the number of steps it takes on an input, as a worst-case function of $n$, the number of cells that hold the input. It is the quantity that the [main theorem](main-theorem.md) bounds. That theorem gives one machine that multiplies two $n$-bit integers exactly. Here $\kappa = 2^{-182}$ is a fixed constant of the theorem, and its running time is $O(n(\lg n)^{1-\kappa})$. <cite data-source="paper">Its worst-case running time satisfies</cite> that bound. The bound uses the [base-2 logarithm](base-two-logarithm.md) $\lg n$. The letter $n$ takes a new meaning here: it is the input length, not the logarithm's argument on earlier pages.

Running time cost is defined on a [fixed-tape machine](fixed-tape-model.md), a machine whose alphabet and number of tapes do not grow with the input. In this model, the machine's alphabet and tape count are fixed: <cite data-source="paper">A machine has one fixed finite alphabet and one fixed finite number of one-dimensional tapes.</cite> The alphabet is the finite set of symbols that any cell may hold. A tape is a row of cells, and each tape has a head that sits on one cell at a time. The inputs here are binary strings, so each cell holds $0$ or $1$.

One step is one local move. A step <cite data-source="paper">reads and writes at most one cell on each tape and moves each head by at most one cell.</cite> A head that must cross $5$ cells therefore needs at least $5$ steps.

For a machine $A$ and an input length $n$, the running time cost is $T_A(n)$, the largest number of steps $A$ takes on any input of length $n$. The maximum is needed because the number of steps varies from input to input.

Take the machine $M$ that starts on the first cell. In each step it reads the cell under its head. If that cell holds $1$, or is the last cell, $M$ halts in that step; otherwise it moves one cell right. Each step reads one new cell, so $M$ takes at most $4$ steps on an input of length $4$. On $0001$ it reads cells $1$, $2$, $3$ (each holds $0$) and halts in step $4$ on the $1$ in cell $4$. On $0000$ it reads all four cells and halts in step $4$. Both inputs take $4$ steps and none takes more, so $T_M(4) = 4$, the maximum over the $16$ binary inputs of length $4$.

Each bound in the proof concerns the same machine: it counts steps of the theorem's single machine $A$ on inputs of one length. The steps of a computation are the sum of the steps of its parts, so a bound on each term of the [cost table](cost-table.md), summed, bounds $T_A(n)$.
