## This page

Concept: Fixed-point and Gaussian dyadic arithmetic
Gloss: Complex numbers stored as signed two's-complement grid numerators over 2^p, added and scaled exactly with guard bits and truncated once toward zero.

## Where the argument relies on this page

- For the complex network with binary labels, the phase frames $\mathcal C_U=H^{\otimes m}\operatorname{diag}(i^{\operatorname{wt}(P_Ux)\bmod 4})H^{\otimes m}$ change along each edge by a product of translation kernels $aI+bX_v$, one per vector of an orthonormal basis of the edge residual, for $s<W m$ kernels in all, and telescope to $C^{\otimes m}$ on every role. (on [Binary phase frames and the two-point kernel C](phase-frames.md))
- The map $H_0(u,v)=((u+v)/2,(u-v)/2)$ applied at one common bit offset in each of $D\le d$ equal-width $K$-bit address chunks of an array of records, each a polynomial with $r$ complex coefficients on the grid $2^{-p}\mathbb Z[i]$, of total volume $V$, with a single final truncation, costs $O(V d^{\lambda'})$ for a fixed $\lambda'<1$. (on [Simultaneous butterfly layer](simultaneous-butterfly-layer.md))
- Since $H_0^{\otimes D}=b^D\mathcal S_D C^{\otimes D}\mathcal S_D$ with the diagonal phase operator $\mathcal S_D$, a layer of $H_0$ follows from a layer of $C$ exactly in Gaussian dyadics.
- One $C$ kernel on one selected bit costs $O(V)$ by splitting on that bit and scanning aligned record pairs, so $e$ kernels cost $O(V e)$.
- The number of extra guard bits needed to keep every intermediate coefficient of one layer exact grows only like a fixed power of $d$, which is $o(p)$ for $d$ a small enough power of $p$, so coefficients keep width $O(p)$.
- Every row of $\mathcal H$ has absolute row sum one, so $\mathcal H$ maps disk arrays to disk arrays and the final truncation $Q_p$ changes each coefficient by less than $\sqrt2\,2^{-p}$.
- On a layout that places the selected bits of the $d-1$ participating axes at a common offset in consecutive $K$-bit chunks, the forward transform $L B F_{\boldsymbol t}^-$ and the opposite transform $F_{\boldsymbol t}^+B^{-1}L^{-1}$ each have error below $\sqrt2\,\ell\,2^{-p}$ and cost $O(T p[d K+p K^{\tau-1}+\ell d^{\lambda'}])$. (on [Synthetic transform tape layout](synthetic-transform-layout.md))
- Rounds on prefix slots process the participating bits individually, each in $O(T p)$ time, and there are at most $K$ of them, for a total $O(T p\,d K)$.

## Evidence from the sources, with the paragraph around each quote

- "Intermediate values are exact Gaussian dyadics," (paper)

  > The second procedure applies \[ H_0(u,v)=\bigl((u+v)/2,(u-v)/2\bigr) \] simultaneously on selected coordinate bits of the numerical arrays. Each record is a polynomial with complex fixed-point coefficients, and $H_0$ acts coefficientwise. On the layouts used in the multiplication algorithm, one selects the same bit position in each of at most $d$ equal-width address chunks, and the cost is $O(Vd^{\lambda'})$ for a fixed $\lambda'<1$. Intermediate values are exact Gaussian dyadics, whose real and imaginary parts have power-of-two denominators. A single truncation follows the completed contractive layer. Section~\ref{sec:tape-interchange} proves the address bound, and Section~\ref{sec:fast-butterfly-layers} gives the numerical layout, precision hypotheses, and layer bound.

- "$p$-bit grid array has real and imaginary coefficient parts in" (paper)

  > For an integer $r\geq 2$ that is a power of two, put \[ \mathcal R_r=\mathbb C[y]/(y^r+1),\qquad \left\|\sum_{k=0}^{r-1}z_k y^k\right\|_\infty =\max_{0\leq k<r}|z_k|. \] We always use representatives of degree less than $r$. Multiplication by $y^a$, for any integer $a$, permutes the coefficients and changes some signs; consequently it is an isometry for this norm. For arrays over $\mathcal R_r$, the same notation denotes the maximum over all coefficients in all entries. A disk array has norm at most one. A $p$-bit grid array has real and imaginary coefficient parts in $2^{-p}\mathbb Z$. For any array, let $Q_p$ truncate each real and imaginary coefficient part toward zero to this grid. Then \begin{equation} \|Q_p z-z\|_\infty<\sqrt2\,2^{-p},\qquad \|Q_p z\|_\infty\leq\|z\|_\infty. \label{eq:transform-truncate} \end{equation}
