## This page

Concept: Two-point kernel C
Gloss: The Gaussian-dyadic 2×2 kernel C = H·diag(1, i)·H = aI + bX with a = (1 + i)/2, b = (1 − i)/2, satisfying C⁴ = I and H₀ = b·S·C·S, so a layer of H₀ equals a layer of C up to diagonal phases and a scale.
Also called: translation kernel, aI+bX
Heading: Two-point kernel $C$

The symbols in this page's heading denote (say so on the page):

- $C$ (two-point kernel): The 2×2 complex matrix aI + bX with a = (1 + i)/2, b = (1 − i)/2 and X the coordinate swap.

## Where the argument relies on this page

- The simultaneous butterfly layer: on an array of polynomial records with $D\le d$ consecutive $K$-bit chunks, $H_0$ applied to one common bit position of every chunk, followed by truncation $Q_p$, is computed in $O(Vd^{\lambda'})$ time with error below $\sqrt2\,2^{-p}$. (on [Simultaneous butterfly layer](simultaneous-layer.md))
- The tensor product $C^{\otimes D}$ of the kernel $C$ on the selected bits of $D\le d$ chunks is computed exactly in $O(Vd^{\lambda'})$ time, by recursion in which a group of $e$ selected axes uses $s_{\rm c}$ children on $e/m$ axes, each on a stream of volume $V/W$. (on [Recursive C-layer via phase frames](recursive-c-layer.md))
- With phase frames $\mathcal C_U=H^{\otimes m}\operatorname{diag}(i^{q_U(x)})H^{\otimes m}$, each edge's frame change of the complex network is a product of one translation kernel $aI+bX_v$ (or its inverse) per orthonormal residual vector, these total $s_{\rm c}=W_{\rm c}m-2N+2L_{\rm c}<W_{\rm c}m$, and after diagonal corrections every role receives $C^{\otimes m}$. (on [Binary phase interface of the complex network](phase-interface.md))
- The identity $H_0^{\otimes D}=b^D\mathcal S_DC^{\otimes D}\mathcal S_D$ converts the exact $C$ layer into the normalized layer $\mathcal H$.

## Evidence from the sources, with the paragraph around each quote

- "auxiliary two-point kernel $C$" (paper)

  > We first construct tensor products of the auxiliary two-point kernel $C$ from Proposition~\ref{prop:complex-motif-interface}. Its phase frames express a $C$ tensor product using smaller groups of selected bits, separated by binary changes of basis. We implement those changes by moving whole address chunks. Splitting complete rows among the network's wire roles then reduces the volume of each recursive call. Finally, we bound the intermediate dyadic values and convert the completed $C$ layer to the normalized $H_0$ layer. The entire layer is evaluated exactly before one final truncation.

- "In particular, $C=iZC^{-1}Z$." (paper)

  > Put \[ H_0=\frac12\begin{pmatrix}1&1\\1&-1\end{pmatrix},\qquad H=\sqrt2 H_0,\qquad \mathsf S=\operatorname{diag}(1,i),\qquad Z=\operatorname{diag}(1,-1). \] For the bit-flip matrix $X=\bigl(\begin{smallmatrix}0&1\\1&0\end{smallmatrix}\bigr)$, define \begin{equation}\label{eq:phase-C} C=H\mathsf SH=aI+bX,\qquad a=\frac{1+i}{2},\quad b=\frac{1-i}{2}. \end{equation} Direct multiplication gives \begin{equation}\label{eq:phase-basic-identities} H_0=b\mathsf SC\mathsf S,\qquad C^2=X,\qquad C^4=I,\qquad C^{-1}=bI+aX=-iZCZ. \end{equation} In particular, $C=iZC^{-1}Z$. These identities use only Gaussian dyadic coefficients. The Hadamard matrices in the definition of $\mathcal C_U$ are used to prove identities; they need not be executed by the machine.
