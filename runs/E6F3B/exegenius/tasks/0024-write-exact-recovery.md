## This page in the argument

The step: Removing the known normalizations $S$ and $2^{2b+4}$, the recovered coefficient error is strictly below $1/2$, so rounding gives the exact integer coefficients and carry propagation outputs the exact $2n$-bit product.
How: Track disk membership and an absolute error bound through every computed call, scale the final error by the known normalizations, and compare with $1/2$.
Why: The true coefficients are integers, so an error strictly below $1/2$ identifies each one uniquely by rounding. (the sources say so: "The strict error below $1/2$ makes the nearest integer to" (paper))
Striking feature: The final error is below $448b\,2^{-3b/4}$, exponentially small in $b$, although the computed values are rescaled by about $2^{2b+4}S$; the precision $p=6b$ is what absorbs these scale factors. (explain why it holds, from the method)

Its sub-steps, in order:

- A linear contraction propagates an input error without increasing it, and a bilinear contraction adds the errors of its operands, so errors compose by adding through every call.
- The source transform has error below $E_s h_p$ with $E_s=9\cdot2^\gamma TL$ for $L=\log_2T$, and its output stays in the disk.
- The pointwise product $z$ has norm below $.5$ and error below $(2E_s+2)h_p$.

- After the second scale $2^{2b+4}S$ the absolute error is below $448b\,2^{-3b/4}<1/2$, since $p=6b$.
