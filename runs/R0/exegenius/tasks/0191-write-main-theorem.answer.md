The main theorem is that one fixed deterministic Turing machine multiplies two $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time, where $n$ is the number of bits in each input and $\kappa=2^{-182}$ is a fixed saving exponent. It disproves the [n log n optimality conjecture](nlogn-conjecture.md) for this model.

The machine uses a fixed finite alphabet and a fixed number of one-dimensional tapes, and computes the exact product for every $n\ge1$ <cite data-source="paper">There is one deterministic Turing machine $A$, with a fixed finite</cite>.

[Reduction of integer product to digit convolution](radix-digit-reduction.md) turns the product into a convolution of short coefficients. The machine places its coefficient list by the [Chinese-remainder map to prime cyclic axes](crt-address-map.md). The machine computes its convolution by [Convolution with retained transform order and cancelled permutations](ring-convolution-retained-order.md). The machine recovers its coefficients by [Fixed-point precision and exact recovery](fixed-point-precision.md).

The machine performs its address moves by [Fast interchange of address fields](fast-address-interchange.md). It performs its butterfly layers by [Fast simultaneous butterfly layers](fast-butterfly-layers.md). These cost $O(Vu^\tau)$ and $O(Vd^{\lambda'})$, where $V$ is the stored bit volume, $u$ the field width, $d$ the number of selected chunks, and $\tau,\lambda'<1$ fixed exponents. Here $u$ and $d$ are powers of $\lg n$ with exponents below one.

The $n\log n$ cost scans all $V$ stored bits at each of the $\Theta(\log n)$ transform levels, so cheaper moves and layers lower the whole bound.

The logarithmic factor drops by the fixed power $\kappa$ because $\kappa$ is set by the smallest margin in the sources' cost table. Each row of that table is a power $p$ with exponent one minus a margin, where $p=6\lceil\lg n\rceil$. The smallest margin is $2^{-181}$ <cite data-source="paper">Thus $\min_i g_i=2^{-181}=2\kappa$</cite>, which is $2\kappa$, so the largest power is $p^{1-2\kappa}$. A fixed power of $\log p$ is at most $p^{\kappa}$ for large $p$, so $p^{1-2\kappa}$ times it is $O(p^{1-\kappa})=O((\lg n)^{1-\kappa})$.

Both procedures come from one fixed linear network with $W$ roles and $s$ child calls. For the bit network, $s$ equals $Wm$ minus $N$, the number of negative source projections, plus twice the lost label dimension $L$ <cite data-source="paper">W_{\rm b}m-N+2L_{\rm b}</cite>, so $s<Wm$ needs $N>2L$. A negative source projection is a source operator $-P_U$, where $P_U$ projects onto a label subspace along its orthogonal complement.

Let $\ell=m^k$ be the number of radix-$q$ digits in a chunk at recursion level $k$, where $m$ is the number of fields per chunk and $q$ is a fixed prime. Let $\Phi(\ell)$ be the time divided by $V$ at that level. Each chunk is cut into $m$ fields of $\ell/m$ digits. A call makes $s$ child calls on streams of volume $V/W$, and its own splitting, gates and reassembly cost $O(1)$ per unit volume <cite data-source="paper">merging, gates, and triangular operations have total cost $O(V)$ because</cite>.

Hence $\Phi(\ell)\le (s/W)\Phi(\ell/m)+O(\ell^\tau+1)$ with $\Phi(1)=O(1)$, since the children cost $s(V/W)\Phi(\ell/m)$ and dividing by $V$ gives $s/W$. Since $s/W<m$, some rational $\tau<1$ gives $(s/W)/m^\tau<1$; this is where $s<Wm$ is used. Dividing by $m^{k\tau}$ gives $m^{-k\tau}\Phi(m^k)\le \frac{s/W}{m^\tau}\,m^{-(k-1)\tau}\Phi(m^{k-1})+O(1)$, since $\ell^\tau+1\le 2\ell^\tau$. Unrolling gives a geometric sum with ratio $(s/W)/m^\tau<1$, so $\Phi(m^k)=O(m^{k\tau})$. A field of $\ell$ radix-$q$ digits has $\Theta(\ell)$ bits, because $q$ is fixed, so $\ell$ is proportional to $u$ and the interchange costs $O(Vu^\tau)$. The butterfly layer uses a second fixed network, also with $s<Wm$, and runs the same recursion on the $d$ selected chunks, so it costs $O(Vd^{\lambda'})$ once $\lambda'$ exceeds two exponents. Nodes with at least $\sqrt d$ active chunks have node overhead of $O(\ell^\lambda)$ per unit volume, with $\ell\le d$ and $\lambda=1-2^{-52}$. Smaller nodes, the small-level leaves, cost $O(d^{\sigma+(1-\sigma)/2})$ with $\sigma=1-2^{-50}$. So $\lambda'$ must exceed $\lambda$ and $\sigma+(1-\sigma)/2$, and $\lambda'=1-2^{-54}$ does.
