## This page

Concept: Packed selected-bit addition with deterministic repair
Gloss: Performs y←y⊕x on the same bit position of f chunks at once using eight cyclic shifts of whole chunk ranges (a three-chunk rotation trick that restores a scratch chunk), then corrects the small explicitly identified set of addresses where guard values fail.

## This page in the argument

The step: The selected bit can be added to the same position of $f$ chunks at once, $y\leftarrow y\oplus x$, restoring a scratch chunk, in time $O(V(L^\tau+1))$ away from a small exceptional set of addresses.
How: do the packed update with a fixed number of whole-chunk cyclic shifts, then repair the explicitly identified exceptional addresses
Why: The shifts are linear-time and need no per-bit work, but guard values fail at a few addresses; since those addresses depend only on the address, repairing them keeps the bound worst case over payloads. (the sources say so: "The correction depends only on addresses, so the time bound is" (paper))

Its sub-steps, in order:

- Eight conditional increments of two integers induce a parity flip of $u$ and restore the scratch integer $w$.
- The small set of addresses where the guard values fail is identified from the addresses alone and corrected deterministically.

It serves these steps, from the main result down:

- There is one deterministic fixed-alphabet, fixed-tape Turing machine multiplying $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$, disproving the $n\log n$ optimality conjecture in this model.; how: build two fast tape procedures from linear networks with a rank saving, insert them into a Gaussian-resampling and chirp reduction of the digit convolution to a ring convolution, and balance all parameters (on [Integer multiplication in O(n (lg n)^(1−κ)) time](main-theorem.md))
- The two-point butterfly $H_0$ can be applied at one bit position in each of at most $d$ address chunks of an array at once, with one final truncation, in $O(Vd^{\lambda'})$ time for a fixed $\lambda'<1$.; how: recurse on the complex phase network applied to the selected bits, implementing basis changes by packed bit addition and splitting rows among the wire roles (on [Simultaneous butterfly layer](simultaneous-layer.md))
