## This page in the argument

The step: Over Gaussian dyadic values with binary labels and phase frames $\mathcal C_U$, each edge change is a product of two-point kernels $aI+bX_v$, and telescoping gives $C^{\otimes m}$ on every role with $s_{\rm c}<W_{\rm c}m$ kernel factors.
How: Replace the rational projections by binary labels and phase operators $H^{\otimes m}\operatorname{diag}(i^{\operatorname{wt}(P_Ux)})H^{\otimes m}$; weight additivity over an orthonormal residual basis turns each edge change into one kernel per basis vector.
Why: In characteristic two the weight of a sum of orthogonal vectors is additive modulo four, so the phase difference across an edge splits over an orthonormal basis of the residual, one kernel per vector, which is the same count as the rank in the bit network.
