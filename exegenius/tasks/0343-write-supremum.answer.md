The supremum is the least upper bound of a set of real numbers. The paper uses it to name the largest value of a quantity over an infinite family of inputs, and the later pages that bound how errors pass through the computation rely on that measure.

Let $\Sigma$ be a nonempty set of real numbers. Let $\chi$ denote an arbitrary element of $\Sigma$. Let $\Omega$ denote a real number, and call $\Omega$ an *upper bound* of $\Sigma$ when $\chi \le \Omega$ for every element $\chi$ of $\Sigma$. The supremum $\sup \Sigma$ is the least upper bound: it is an upper bound of $\Sigma$, and it is at most every other upper bound of $\Sigma$.

The supremum need not be an element of $\Sigma$. Take $\Sigma = \{\,1-2^{-k} : k \ge 1\,\} = \{1/2, 3/4, 7/8, \dots\}$. Every element is less than $1$, so $1$ is an upper bound. No smaller number is an upper bound: if $\Omega < 1$, choose $k$ with $2^{-k} < 1-\Omega$; then $1-2^{-k} > \Omega$, so $\Omega$ is not an upper bound. Hence $\sup \Sigma = 1$, although $1 \notin \Sigma$. This is why the name is "least upper bound" rather than "largest element": a largest element, when it exists, is the supremum, but the supremum can exist without being attained.

The paper defines the operator norm of a linear map $L$, the largest factor by which $L$ stretches a vector, as a supremum over all vectors: <cite data-source="paper">∥L∥ = sup∥u∥≤1 ∥Lu∥</cite>. The inputs $u$ range over infinitely many vectors of norm at most one, so the definition takes the supremum of the set of all the values $\|Lu\|$ rather than a maximum that would have to be attained.
