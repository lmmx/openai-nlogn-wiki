## This page in the argument

The step: Disk-margin and error bookkeeping shows the error in each recovered coefficient is below $1/2$, so rounding gives the exact integer convolution coefficients and carries give the exact binary product.
How: Track norm bounds and additive errors through every computed step, using that contractions pass errors through unchanged and errors of composed steps add, then compare the final error with $1/2$.
Why: A linear contraction does not enlarge an input error, so the errors of composed steps simply add and can be tallied step by step. (the sources say so: "A linear contraction propagates an input error without increasing it." (paper))
Striking feature: Although Gaussian resampling inflates errors by $2^{\gamma}$ and the scales multiply them by $S$ and $2^{2b+4}$, the final error $448b\,2^{-3b/4}$ stays below $1/2$ with precision only $p=6b$, because $\gamma=o(b)$. (explain why it holds, from the method)

Its sub-steps, in order:

- Every computed ring convolution output is a disk grid array of norm below $.701$, so no clipping occurs.
- The computed chirp transform differs from $QF_{\boldsymbol t}x$ by less than $8TLh_p$.
- The source transform has error below $E_sh_p$ with $E_s=9\,2^\gamma TL$, and its output stays in the disk.
- The pointwise product satisfies $\|z-U\cdot V_1\|<(2E_s+2)h_p$.
- After the first scale by $S$ the error is below $E_wh_p$ with $E_w=S(3E_s+2)<28\,2^\gamma T^2L$.
- After the second scale the absolute error is below $448b\,2^{-b+\gamma}\le448b\,2^{-3b/4}<1/2$.
- Since the true coefficients are integers and the error is below $1/2$, the nearest integer is the unique correct coefficient.
- The carries obey $0\le k_j\le q(Q_0-1)<Q_0^2$, so the carry propagation yields exactly the digits of the product.

It serves these steps, from the main result down:

- A single deterministic fixed-tape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$, using fast address interchange and fast simultaneous butterfly layers inside a Gaussian-resampling, chirp and synthetic-transform reduction.; how: Reduce the product to a convolution evaluated through Gaussian-resampled, chirped synthetic transforms, make the two costly tape operations (address movement and butterfly layers) cheaper by a power of the logarithm using networks with a rank saving, and then assemble the algorithm and add up its costs. (on [Integer multiplication below n log n](main-theorem.md))
- Choosing compatible parameters, the radix-digit convolution is mapped to prime axes, transformed, multiplied pointwise, inverted, rescaled, rounded and carried to give the exact binary product in time $O(n(\lg n)^{1-\kappa})$.; how: Fix the parameters, place the digits on a product of prime cyclic axes, run the source transform on each operand, multiply and invert, then bound the error to round exactly and add up the costs.
