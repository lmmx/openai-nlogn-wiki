An address field is a contiguous block of address bits, and the choice of fields gives the layout of an array on a tape. Transform levels rearrange these fields, so the layout sets their cost.

An array is stored in tape order: the item at position $m$ sits in the $m$-th cell, and its address is $m$ written in binary. Write $u$ for the number of bits in one address field. Splitting the address bits into contiguous blocks of $u$ bits gives address fields. An address is then a tuple of field values, and the set of all addresses is the Cartesian product of the fields' value sets.

Example. A 4-item array has two one-bit fields, the high bit and the low bit. Interchanging them sends the item at address 01 to address 10, the item at 10 to 01, and leaves the items at 00 and 11 in place. The items are unchanged; only their cells move.

Why levels rearrange fields. The transform is computed in levels, each a two-point butterfly that replaces entries $x$ and $y$ by $x+y$ and $x-y$, up to a scale factor. A level pairs the entries whose addresses differ in one bit of one axis's field, and successive levels pair different bits. A fixed-tape machine combines entries only when both are scanned together, so a level may first need an interchange of two disjoint address fields that brings its pair into the scanned position.

Rearranging is not free. A layout's cost is counted in the [Fixed-tape machine model and stream operations](fixed-tape-model.md), where each step touches one cell per tape, so moving data is the cost to minimize. An interchange scans the stored bits. Write $V$ for the stored bit volume, the total number of bits the array holds. Each entry is a fixed-width coefficient of $\Theta(\log n)$ bits, and the entries fill a power-of-two box of about $n/\log n$ entries, so $V=\Theta(n)$ <cite data-source="paper">a full padded array has $\Theta(V)$ stored bits</cite>. Scanning all stored bits at each level costs $\Theta(n\log n)$ over $\Theta(\log n)$ levels <cite data-source="paper">$\Theta(\log n)$ transform levels already costs $\Theta(n\log n)$</cite>.
