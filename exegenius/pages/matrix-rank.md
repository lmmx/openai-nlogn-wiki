The rank of a matrix is the largest number of linearly independent rows, which also equals the largest number of independent columns and the number of nonzero pivots found by Gaussian elimination. The lower-triangular factorization uses rank to count the ones of a partial permutation matrix, a 0-1 matrix with at most one 1 in each row and each column.

Let $A$ be a real matrix. Its rows are linearly independent when no nontrivial combination of them is the zero row, and $\operatorname{rank} A$ is the largest number of such rows. For example, the rows $(1,2)$ and $(2,4)$ have rank 1, because the second row is twice the first.

Elimination computes rank because invertible row and column operations preserve it. Reorder the rows and columns so that a nonzero entry, the pivot, sits in the top-left corner. Clearing the entries below it and to its right leaves the pivot alone, together with the smaller matrix left after deleting the pivot's row and column. Every remaining row has zero in the pivot's column, so the pivot row is independent of them and the rank drops by exactly one. Each pivot therefore lowers the remaining rank by one. <cite data-source="paper">Each step isolates a rank-one block and leaves the remaining rank in the active submatrix</cite>. Repeating the step until no nonzero entry is left gives $\operatorname{rank} A$ equal to the number of pivots.
