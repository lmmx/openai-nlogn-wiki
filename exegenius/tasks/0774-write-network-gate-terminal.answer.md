A *gate* is a vertex where several wires meet and their values are combined, and a *terminal* is a vertex at an end of a wire, its source or its sink, where the network's values enter or leave. The subset-intersection network, a linear network on the three-element subsets of a ground set, is built from gates and terminals. This page explains what each one does and why a gate can act on stored arrays.

A network carries values on *wires*. <cite data-source="paper">A wire carries one scalar.</cite> <cite data-source="paper">The vertices on a wire are its source, the gates that touch it in time order, and its sink</cite>, and <cite data-source="paper">its edges join consecutive vertices</cite>. The source and the sink of a wire are its *terminals*.

A *gate* is a fixed linear map on a set of wires: <cite data-source="paper">A gate is a fixed linear map on a specified set of wires; untouched wires retain their values.</cite> The pair of a gate and a wire that it touches is an *incidence*. A *scalar gate* combines the values at each *address*, a position in the arrays that the wires carry, using only the values at that same address. <cite data-source="paper">A scalar gate is then applied pointwise to matching addresses on the roles that it touches.</cite> A *pointwise linear gate*, also called a gate applied pointwise, is one whose combination is the same fixed linear combination at every address.

Example. Let a gate act on two wires that hold $3$ and $1$ at an address. It replaces them by their sum and their difference, both computed from the original values: the first wire gets $3+1=4$ and the second gets $3-1=2$. A third wire at that address keeps its value.

Each gate and terminal $v$ is a vertex type of [Linear networks and frames](linear-network-frames.md), and carries a frame $D_v$, an invertible linear operator on arrays. <cite data-source="paper">the stored array is Dv g when the logical array is g</cite>, so the frame $D_v$ converts a logical array $g$ into the array actually stored at $v$. <cite data-source="paper">All incidences of one gate have the same frame.</cite> A gate therefore has one frame $D_v$ on all its wires.

Why one frame? Take a two-input gate $G$ with logical input arrays $g_1$ and $g_2$, whose logical output is $G(g_1, g_2) = \vartheta_1 g_1 + \vartheta_2 g_2$, where $\vartheta_1$ and $\vartheta_2$ are fixed scalar weights, the same at every address. Let $u$ and $u'$ be the vertices just before the gate on the two input wires, with frames $D_u$ and $D_{u'}$. The stored inputs are then $D_u g_1$ and $D_{u'} g_2$. If $D_{u'} \neq D_u$, the gate would form $\vartheta_1 D_u g_1 + \vartheta_2 D_{u'} g_2$, which in general is not a frame applied to $G(g_1, g_2)$. If both inputs carry the gate's frame $D_v$ instead, the stored output is
$$\vartheta_1 D_v g_1 + \vartheta_2 D_v g_2 = D_v(\vartheta_1 g_1 + \vartheta_2 g_2) = D_v\, G(g_1, g_2),$$
because $D_v$ is linear and the weights are scalars that do not depend on the arrays. At a pointwise linear gate, <cite data-source="paper">the common frame commutes with the gate</cite>: $G(D_v g_1, D_v g_2) = D_v\, G(g_1, g_2)$.

So the gate can be applied to the stored arrays, and the frame removed afterwards, without changing the logical result.
