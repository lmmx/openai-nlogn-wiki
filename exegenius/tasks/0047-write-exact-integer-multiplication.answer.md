Exact integer multiplication is the problem of computing the complete binary product of two integers of equal bit length, with no rounding and no truncation. The target result bounds its cost, so its input and output format must be fixed first.

Let $n$ be the number of bits in each of the two binary strings to multiply, and let $x$ and $y$ be those strings. For a binary string $w$, let $\mathrm{val}(w)$ be its nonnegative integer value, with the leftmost bit most significant. Let $L$ be the length of a padded output. For an integer $z$ with $0 \le z < 2^L$, let $\mathrm{bin}_L(z)$ be its binary representation padded on the left with zeros to length $L$.

The input is the string $x\#y$, where $\#$ is a separator symbol, and the output must be $\mathrm{bin}_{2n}(\mathrm{val}(x)\cdot\mathrm{val}(y))$. The output length $2n$ is always enough: $\mathrm{val}(x)$ and $\mathrm{val}(y)$ are at most $2^n-1$, so their product is at most $(2^n-1)^2$, which is less than $2^{2n}$. For example, with $n=3$, $x=101$ and $y=011$ have values 5 and 3, and the output is $\mathrm{bin}_6(15)=001111$.

A deterministic Turing machine computes exact multiplication if, on every input $x\#y$ with $x$ and $y$ of length $n$, it halts with this output. Its running time, as a function of $n$, is the worst case over all such inputs. The target result uses a fixed finite alphabet and a fixed finite number of one-dimensional tapes, so neither grows with $n$. This is the fixed finite-tape model.

Schönhage and Strassen proposed $n\log n$ as the optimal order of growth, and gave a multitape Turing machine running in $O(n\log n\log\log n)$ time <cite data-source="paper">two n-bit integers can be multiplied in O(n log n log log n) time on a multitape Turing machine</cite>. Harvey and van der Hoeven later gave an unconditional $O(n\log n)$ upper bound for this problem <cite data-source="paper">reached the unconditional O(n log n) upper bound</cite>. The target result is measured against this bound, since both concern the same problem: multiplying two $n$-bit integers on a multitape Turing machine.

A strict power saving in the logarithmic factor means a running time smaller than $O(n\log n)$ by a fixed positive power of $\log n$ in the denominator. The target result gives such a saving <cite data-source="paper">We obtain a strict power saving in the logarithmic factor, in the same fixed finite-tape model</cite>.
