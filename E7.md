# E7: the key-step instruction asks for identities and exceptions

Records of experiment E7, run in the development session of lmmx/exegenius (plan:
`calibration/plans/E7.md` at 8fe040c; analysis: `docs/journal/2026-10-14-e7-key-step-identity.md`).
This branch starts from `141026-exp-e6-key-step-confirm`, whose runs E6F1V–E6F8V are the
comparison arm.

- `runs/E7F1W`–`E7F8W`: copies of E6's projects E6F1–E6F8 (background accepted), with the
  argument task rendered by exegenius branch `141026-exp-key-step-identity` (91c4fed): E6's
  key-step paragraph plus one sentence asking for the identity, lemma or definition behind each
  counted, bounded or equated sub-step and every exception. In each pair the task files of FkV
  and FkW differ only in that sentence and the project path. Each prompt as `exegenius next`
  printed it went word for word to a fresh `general-purpose` subagent, `model: "sonnet"`,
  `effort: "high"`; every run stopped when `next` handed out write tasks.
- `results/transcripts/e7/subagents/`: the eight argument subagents' transcripts and
  `.meta.json` (description `FkW 0003-argument`). No restarts.
