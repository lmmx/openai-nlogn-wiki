A simultaneous butterfly layer applies the [butterfly operation](butterfly-operation.md) to one selected address bit of every record at once. It is the transform step of the [target multiplication algorithm](integer-multiplication-target.md) whose tape cost must save a power, so the layer's cost is what the proof has to bound.

An address chunk is a block of consecutive address bits. Here $d$ is the largest number of equal-width chunks a layer acts on, and $D \le d$ is the number used in one layer; the letter $D$ changes meaning here. The layer selects the same bit position in each of those $D$ chunks.

Each record is a polynomial with complex fixed-point coefficients, each stored with a fixed number of binary places. The layer is formed as the [tensor product](tensor-product.md) of $D$ copies of the butterfly operation, one for each selected bit, acting on each coefficient and leaving the other address bits unchanged. Intermediate values are exact Gaussian dyadics, complex numbers whose real and imaginary parts have power-of-two denominators, so the division by two in the butterfly causes no rounding; one truncation follows the completed layer.

Applying the $D$ factors one at a time takes one pass over the array per selected bit. A pass that touches all $V$ stored bits costs $O(V)$ steps, so this method costs $O(VD)$, at most $O(Vd)$. Here $\lambda'$ is a fixed exponent below one. The layer runs in $O(Vd^{\lambda'})$ tape steps <cite data-source="paper">the cost is $O(Vd^{\lambda'})$ for a fixed $\lambda'<1$</cite>, where $V$ is the number of stored data bits. Since $\lambda'<1$, the layer saves a factor $d^{1-\lambda'}$, a power of $d$, over the factor-by-factor method.

The layer computes its chunk moves by the [linear network with restored auxiliary values](linear-network-exchange.md), which carries each input role to an output role with a prescribed sign and restores every auxiliary value. The address bound behind this cost is proved in the source's tape-interchange section <cite data-source="paper">Section~\ref{sec:tape-interchange} proves the address bound</cite>, and the layer bound is stated in its fast-butterfly section <cite data-source="paper">Section~\ref{sec:fast-butterfly-layers} gives the numerical layout, precision hypotheses, and layer bound</cite>.
