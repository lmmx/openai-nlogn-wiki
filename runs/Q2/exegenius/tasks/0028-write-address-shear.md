## This page

Concept: Address shear
Gloss: The address permutation (H, D) ↦ (H + MD, D) on two groups of address fields; the bit network's endpoint frames make it implement the shear H ← H + D on every role, which three such updates turn into an interchange.
Also called: rational matrix interface

## This page in the argument

The step: With frames $\Phi_{M_v}$ and endpoint identity $M_{\mathrm{sink}(\rho(w))}-M_{\mathrm{source}(w)}=I_m$, the network applies the shear $H\gets H+D$ on every role, and two further linear-cost updates turn it into the interchange $(H,D)\mapsto(D,H)$.

It serves these steps, from the main result down:

- One deterministic fixed-alphabet multitape Turing machine computes $\operatorname{bin}_{2n}(\operatorname{val}(x)\operatorname{val}(y))$ for all $n$-bit inputs in time $O(n(\lg n)^{1-\kappa})$ with $\kappa=2^{-182}$, refuting the $n\log n$ optimality conjecture in that model.; how: build two sub-logarithmic tape procedures (address-chunk interchange and simultaneous butterfly layers) from finite linear networks with a rank saving, insert them into the Harvey--van der Hoeven reduction of multiplication to convolution over $\mathbb C[y]/(y^r+1)$ via a Chinese-remainder map, Gaussian resampling, chirps and a phase twist, recover the integer coefficients exactly, and sum the normalized cost table (on [Integer multiplication in O(n (lg n)^(1−κ)) time](main-theorem.md))
- Two disjoint contiguous address fields of $u$ bits in an array of logical volume $V$ can be interchanged on a fixed number of tapes in $O(Vu^\tau)$ time for a fixed $\tau<1$.; how: run the bit network on row-split role streams, with frames given by rational address shears so that every edge is a few smaller interchanges, solve the volume-normalized recurrence at power widths, then remove the width and row restrictions (on [Fast address-chunk interchange](chunk-swap.md))
- For widths $e=m^k$ with a row field divisible by $W^k$, two chunks of $e$ digits can be interchanged in $O(Ve^\tau)$ time.; how: implement the shear $H\gets H+D$ by the bit network on $W$ row-split role streams with frames $\Phi_M$, realize each edge matrix of rank $a$ by $a$ smaller interchanges, finish with two linear-cost updates, and solve $F_k\le(s/W)F_{k-1}+O(1)$ (on [Recursive power-width interchange](power-width-interchange.md))
