The endpoint operator is realised by a [linear network](linear-network-frames.md) on each role array once all intermediate frames have cancelled, so it depends only on the frames at the two ends of a route. The recursion in [rank-saving recursion](rank-saving-recursion.md) uses it to count the smaller calls on each edge.

The endpoint operator is instantiated by the [bit procedure](bit-procedure.md) as an [address shear](address-shear.md): a map that adds one address field to the other and leaves the second unchanged. <cite data-source="paper">For the bit procedure, that endpoint operator is an address shear</cite>. That shear is implemented by a small number of [field interchanges](address-interchange.md).

The frame at a vertex $v$ is the invertible operator $D_v$ on arrays, and the stored array at $v$ is $D_v g$ when the [logical array](logical-array.md) is $g$. Take a path of three vertices $v_0$, $v_1$, $v_2$, and write $D_{v_0}$, $D_{v_1}$, $D_{v_2}$ for the frames at them. <cite data-source="paper">Along an edge from u to v, the operator</cite> $D_v D_u^{-1}$ changes the stored array from $D_u g$ to $D_v g$. So the stored array changes from $D_{v_0} g$ to $D_{v_1} g$ on the first edge and from $D_{v_1} g$ to $D_{v_2} g$ on the second. The two edge changes compose to
$$(D_{v_2} D_{v_1}^{-1})(D_{v_1} D_{v_0}^{-1}) = D_{v_2} D_{v_0}^{-1},$$
because $D_{v_1}^{-1} D_{v_1}$ is the identity. The frame at the middle vertex cancels, and only the frames at the ends remain.

A route through the whole network composes in the same way. Each edge contributes its change, and a pointwise linear gate passes a common frame through unchanged: <cite data-source="paper">At a pointwise linear gate G, the common frame commutes with the gate</cite>. Write $\rho$ for the signed role permutation that the [scalar network](subset-intersection-network.md) realises, so input role $w$ goes to output role $\rho(w)$, and $\varepsilon_w$ for the sign that the route carries. Then the route applies
$$\varepsilon_w\, D_{\mathrm{sink}(\rho(w))}\, D_{\mathrm{source}(w)}^{-1}$$
to the input array, where $D_{\mathrm{source}(w)}$ is the frame at the vertex where input role $w$ starts and $D_{\mathrm{sink}(\rho(w))}$ the frame at the vertex where output role $\rho(w)$ ends. The endpoint operator maps the stored form of the [logical array](logical-array.md) $g$ at the start of the route to its stored form at the end.

The route also exchanges roles, so output role $\rho(w)$ holds what input role $w$ held. To undo this, move each output role back to the role it came from, which applies the inverse of $\rho$, and multiply by $\varepsilon_w$ again. A sign squares to $1$, so this removes the sign. Each role $w$ then holds $D_{\mathrm{sink}(\rho(w))} D_{\mathrm{source}(w)}^{-1}$ applied to its array.
