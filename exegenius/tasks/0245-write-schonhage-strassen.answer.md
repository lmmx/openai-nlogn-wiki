Schönhage–Strassen multiplication is a fast method for [exact integer multiplication](exact-integer-multiplication.md), and it is the bound that the main theorem sharpens. <cite data-source="paper">Schönhage and Strassen proved in 1971 that two n-bit integers can be multiplied in O(n log n log log n)</cite> time. The main theorem goes further: <cite data-source="paper">We obtain a strict power saving in the logarithmic factor</cite>, in the same fixed finite-tape model. Here $n$ is the number of bits in each input integer, and $\lg$ is the base-2 logarithm.

The bound above is stated for a multitape Turing machine, a machine with a fixed finite alphabet and a finite number of one-dimensional tapes. <cite data-source="paper">In the multitape Turing model, Schönhage and Strassen proved the bound O(n log n log log n) in</cite> 1971. They also <cite data-source="paper">Schönhage and Strassen conjectured n log n as the optimal order of multiplication cost</cite>, the question treated in [the n log n optimality conjecture](n-log-n-conjecture.md).

The method works with arithmetic modulo a number one more than a power of two. Let $m$ be a positive integer, and let the modulus be $2^m+1$. The residue ring of integers modulo $2^m+1$ is a Fermat-type residue ring. In this ring $2^m \equiv -1$, so a multiplication by $2^m$ is a negation. For example, take $m=4$ and modulus $17$. Then $2^4 = 16 \equiv -1 \pmod{17}$, so $2$ has multiplicative order $8$ modulo $17$. Multiplying a residue by $2^j$ for $0 \le j < m$ shifts its $m$ bits cyclically and flips the sign of the bits that wrap around. Schönhage–<cite data-source="paper">Strassen multiplication uses roots of unity in Fermat-type residue rings, where certain multiplications</cite> become shifts.
