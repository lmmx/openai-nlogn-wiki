# E4: the key-step instruction, paired on E1's extractions

Records of experiment E4, run in the development session of lmmx/exegenius (plan:
`calibration/plans/E4.md` at ec4a2b6; analysis: `docs/journal/2026-10-14-e4-key-step.md`).
This branch starts from `131026-exp-e1-config`, whose runs P1–P5 supplied the extractions and
backgrounds.

- `runs/E4B1`–`E4B5`: each of E1's P1–P5 projects reset to just before the argument task, the
  argument task rendered by the baseline binary (master af36d6d), answered by a fresh
  `general-purpose` subagent on Sonnet at high effort.
- `runs/E4V1`–`E4V5`: the same, with the argument task rendered by the variant binary
  (exegenius branch `131026-exp-key-step`, 0c29556), whose task file differs only by the
  key-step paragraph.
- `results/transcripts/e4/subagents/`: the transcript, with its `.meta.json`, of each argument
  subagent whose answer was accepted (the description names the run without its `E4` prefix,
  for example `B1 0052-argument (retry)`).
- `results/e4-killed-attempts/`: eight first attempts killed by the account's rate limit (HTTP
  429) before submitting; each task was retried with the same prompt and parameters. B2 and B3
  completed on their first attempt. Kept apart so that resource figures count only the
  attempts that produced the plans.

The sources (`paper.tex`) are omitted from the E4 runs: they are byte-identical to
`template/sources/paper.tex`.
