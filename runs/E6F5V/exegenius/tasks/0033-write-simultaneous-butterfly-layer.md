## This page

Concept: Simultaneous butterfly layer
Gloss: One H₀ butterfly applied at the same bit offset in D ≤ d address chunks at once, computed exactly via the phase network with recursive calls on 1/m of the axes and a single final truncation, in O(V d^{λ'}) time with λ' < 1.

## This page in the argument

The step: One $H_0$ butterfly applied at the same bit offset in $D\le d$ address chunks at once is computed exactly, with a single final truncation, in $O(Vd^{\lambda'})$ time for a fixed $\lambda'<1$.
How: Compute the layer of the auxiliary kernel $C=H\mathsf SH$ through the complex rank-saving network, recursing on $1/m$ of the axes, do the binary changes of basis by packed selected-bit addition, and convert to $H_0$ by the identity $H_0=b\mathsf SC\mathsf S$.
Why: The phase frames of the complex network express a tensor product of $C$ on many bits through smaller groups of bits separated by binary changes of basis, which can be done by moving whole address chunks. (the sources say so: "Its phase frames express a $C$ tensor product using smaller groups of selected bits, separated by binary changes of basis." (paper))
Striking feature: Applying $D$ butterflies at once costs only $O(Vd^{\lambda'})$ with $\lambda'<1$, sublinear in the number $D\le d$ of axes, whereas separate butterflies would need $D$ whole-array passes. (explain why it holds, from the method)

Its sub-steps, in order:

- An edge's frame change is $\mathcal P_M\big(\prod_j C_{e_j}^{\epsilon_j}\big)\mathcal P_M^{-1}$: apply a binary change of basis to each column, one child call per residual vector on the $f$ axes of a slot, and change back.
- Summing the residual dimensions gives exactly $s$ child calls, each on the $f=e/m$ axes of one slot.
- The network therefore gives $C^{\otimes e}$ on every role, including roles whose scratch values were arbitrary.
- The normalized layer is recovered from the $C$ layer by $H_0^{\otimes D}=b^D\mathcal S_DC^{\otimes D}\mathcal S_D$, with exact Gaussian dyadic phases.
- An XOR of the same bit position in $f$ chunks of one address range into another is done together by a constant number of cyclic shifts of whole chunk ranges, followed by a deterministic repair of the small explicitly identified set of exceptional addresses. (on [Packed selected-bit addition](packed-selected-bit-addition.md))
- The cost per unit volume of the $C$ layer obeys $F(e)\le(s/W)F(e/m)+O((eK)^\tau+1)$ and unrolls to $O(d^{\lambda'})$ for the whole layer.
- Intermediate coefficients are exact Gaussian dyadics whose denominator and magnitude growth is bounded by $\lceil C_0d^{C_1}\rceil=o(p)$ bits, so the whole layer is evaluated exactly before the single truncation $Q_p$.
- Every row of $H_0^{\otimes D}$ has absolute row sum one, so the layer maps the disk to the disk and a single truncation adds an error below $\sqrt2\,2^{-p}$.

It serves these steps, from the main result down:

- A single deterministic fixed-tape Turing machine multiplies two $n$-bit integers exactly in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$, using fast address interchange and fast simultaneous butterfly layers inside a Gaussian-resampling, chirp and synthetic-transform reduction.; how: Reduce the product to a convolution evaluated through Gaussian-resampled, chirped synthetic transforms, make the two costly tape operations (address movement and butterfly layers) cheaper by a power of the logarithm using networks with a rank saving, and then assemble the algorithm and add up its costs. (on [Integer multiplication below n log n](main-theorem.md))
