The order of an element is the number of distinct powers that one element of a group produces before the powers return to the identity. It is the quantity that the [Chinese-remainder map](chinese-remainder-map.md) needs in order to show that the image of the indeterminate of the cyclic ring reaches every target monomial exactly once, so that the map loses no coefficient.

Let $G$ be a group, a set with an associative operation, an identity element $1$ and an inverse for each element, and let $\sigma$ be an element of $G$. Its powers $\sigma^0 = 1$, $\sigma^1 = \sigma$, $\sigma^2 = \sigma\sigma$, and so on, all lie in $G$. If $G$ is finite, these powers cannot all be different, so some positive power of $\sigma$ equals $1$. The order of $\sigma$, written $\rho$, is the least positive integer with $\sigma^\rho = 1$. It is also called the multiplicative order of $\sigma$.

The powers $\sigma^0, \sigma^1, \dots, \sigma^{\rho-1}$ are all different. If $\sigma^a = \sigma^b$ with $0 \le a < b < \rho$, then multiplying by the inverse of $\sigma^a$ gives $\sigma^{b-a} = 1$ with $0 < b-a < \rho$, contradicting the minimality of $\rho$. So $\rho$ counts the distinct powers of $\sigma$. Division with remainder also shows that $\sigma^\nu = 1$ exactly when $\rho$ divides $\nu$.

For example, in the group of nonzero residues modulo $7$ under multiplication, the identity is $1$. For $\sigma = 2$ the powers are $2$, $4$, and $2^3 = 8 \equiv 1$, so the order of $2$ is $3$. For $\sigma = 3$ the powers $3, 2, 6, 4, 5, 1$ are six different residues, so the order of $3$ is $6$, the size of the group.

Within a [cyclic group](cyclic-group.md), the order of an element is the size of the group that the element generates. So the generator $\tau$ of $C_\kappa$ has order $\kappa$.

The [Chinese-remainder map](chinese-remainder-map.md) applies this to pairwise coprime source lengths $s_1, \dots, s_d$ with product $S$. Here $x$ is the indeterminate of $\mathbb{C}[x]/(x^S-1)$, and $x_i$ is the indeterminate of axis $i$; the letter $x$ changes meaning from earlier pages. The map $\Phi$ sends $x$ to $\prod_i x_i^{\mu_i}$, where each $\mu_i$ is an inverse, modulo $s_i$, of the product of the lengths before axis $i$. The paper's claim is that the image of $x$ <cite data-source="paper">has order S, because each µi is a unit and the si are pairwise coprime.</cite> Its powers therefore run <cite data-source="paper">through all target basis monomials exactly once.</cite>.

Take source lengths $3$ and $5$, so $S = 15$. The inverse of $3$ modulo $5$ is $2$, since $3 \cdot 2 = 6 \equiv 1$, so $\mu_1 = 1$ and $\mu_2 = 2$, and the map sends $x$ to $\Phi(x) = x_1 x_2^2$. Since $x_1^3 = 1$, $x_2^5 = 1$, and the monomials $x_1^a x_2^b$ with $a < 3$, $b < 5$ are distinct basis elements, $\Phi(x)^\nu = x_1^{\nu} x_2^{2\nu}$ equals $1$ exactly when $3$ divides $\nu$ and $5$ divides $2\nu$. Since $2$ is invertible modulo $5$, the second condition means $5$ divides $\nu$. So $\Phi(x)$ has order $15$, the least positive $\nu$ divisible by both $3$ and $5$.

Hence the $15$ powers $\Phi(x)^0, \dots, \Phi(x)^{14}$ are $15$ distinct monomials, which is all $S = 15$ basis monomials of the target. If the order were $5$ instead, the powers would repeat after five steps and reach only five of the fifteen monomials. The order is therefore what makes the map a bijection on bases: the basis $1, x, \dots, x^{S-1}$ goes to the target basis, each monomial used once.
