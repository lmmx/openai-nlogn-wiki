A modular inverse of an integer is a second integer whose product with it is $1$ modulo a fixed positive integer. The argument needs such inverses for the exponents of its [Chinese-remainder map](chinese-remainder-map.md), which places the radix-digit coefficients on cyclic axes with pairwise [coprime](coprime.md) lengths.

Let $\beta$ be the integer to be inverted and $M \ge 1$ the modulus; the letter $M$ changes meaning here. An inverse is an integer $\mu$ for which $\beta\mu$ is [congruent](congruence-modulo.md) to $1$ modulo $M$, so the inverse is defined by that congruence.

An inverse of $\beta$ modulo $M$ exists exactly when $\beta$ and $M$ are [coprime](coprime.md), that is, when their greatest common divisor is $1$. If $\beta\mu \equiv 1 \pmod M$, then $\beta\mu - 1 = \nu M$ for some integer $\nu$, namely the quotient $(\beta\mu-1)/M$, so every common divisor of $\beta$ and $M$ divides $1$. Conversely, the inverse is obtained from [Bézout's identity](bezout-identity.md) applied to $\beta$ and $-M$: it gives integers $\mu$ and $\nu$ with $\beta\mu - \nu M = 1$, so this $\mu$ is an inverse.

Let $M_i$ be the length of axis $i$, the number of values its coordinate takes, where $i$ is the axis index. The paper's lengths $s_i$ are pairwise coprime: <cite data-source="paper">Let s1 , . . . , sd be the pairwise coprime source lengths</cite>. Put $S = \prod_i M_i$ for their product, and $\pi_i = \prod_{j<i} M_j$ for the product of the lengths before axis $i$, with $\pi_1 = 1$. A prime dividing $\pi_i$ and $M_i$ would divide some $M_j$, $j<i$, and $M_i$, which pairwise coprimality forbids, so $\pi_i$ is coprime to $M_i$. Let $\mu_i$ be the inverse of $\pi_i$ modulo $M_i$, which exists.

Each inverse $\mu_i$ supplies exponents to the paper's map, which acts on $\xi$, a generator of a [cyclic group](cyclic-group.md) of order $S$. For each axis $i$, let $\xi_i$ be a generator of a cyclic group of order $M_i$, so $\xi_i^{M_i} = 1$. The paper's map sends $\xi$ to $\prod_i \xi_i^{\mu_i}$. A generator's powers make up the group, and the order of an element is its least positive power equal to $1$. The paper asserts the image has order $S$: <cite data-source="paper">because each µi is a unit and the si are pairwise coprime</cite>, where a unit is an integer with an inverse modulo $M_i$.

The argument: since each $M_i$ divides $S$, the image raised to the power $S$ is $1$. Conversely, let $\kappa$ be a positive integer exponent with $\left(\prod_j \xi_j^{\mu_j}\right)^{\kappa} = 1$, and fix an axis $i$. Raising to the power $S/M_i$ turns every factor with $j \ne i$ into $1$, since $M_j$ divides $S/M_i$, leaving $\xi_i^{(S/M_i)\kappa\mu_i} = 1$; so $M_i$ divides $(S/M_i)\kappa\mu_i$. Now $S/M_i$ and $\mu_i$ are both coprime to $M_i$, so $M_i$ divides $\kappa$. Doing this for every $i$, pairwise coprimality makes $S$ divide $\kappa$, so the image has order $S$.

For $M_1 = 3$ and $M_2 = 5$, we have $\mu_1 = 1$ and $\mu_2 = 2$, so the image is $\xi_1\xi_2^2$. Its $\kappa$-th power is $1$ exactly when $3 \mid \kappa$ and $5 \mid 2\kappa$, that is, when $15 \mid \kappa$, so the order is $15 = S$.
