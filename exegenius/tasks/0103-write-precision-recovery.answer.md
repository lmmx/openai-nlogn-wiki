Error tracking and exact recovery shows that the computed convolution coefficients lie within $1/2$ of the true integers, so rounding recovers them exactly and carry propagation gives the binary product.

The computation runs on [Fixed-point Gaussian dyadic records](fixed-point.md) with $p=6b$ fractional bits, where $b=\lceil\log_2 n\rceil$ is the digit width, so $n\le2^b$ for $n$-bit inputs. Let $h_p=2^{-p}$ be the grid step, $L=\log_2T$, and $S\le T$. Since $T<8n/b$, for large $n$ we have $T<2^b$ and $L<b$. Norms are sup norms of coefficient moduli; an array is in the disk if its norm is at most $1$; an error of $a$ means error less than $ah_p$. Every computed array is also tracked to stay in the disk, so nothing is clipped. By the paper's cost lemma for the [Synthetic polynomial transform](synthetic-transform.md), which applies because coefficient widths are $O(p)$, each synthetic transform has error below $L$ for large $n$ <cite data-source="paper">$\sqrt2\ell\,2^{-p}<L2^{-p}$</cite>.

It adds errors through the [Contractions and bilinear contractions](contraction-maps.md) that make up each normalized transform and product. A linear contraction does not enlarge an input error. A bilinear contraction $\mathcal M$ has $\|\mathcal M(f,g)\|\le\|f\|\|g\|$ and
$$\mathcal M(f',g')-\mathcal M(f,g)=\mathcal M(f'-f,g')+\mathcal M(f,g'-g),$$
so replacing operands $f,g$ by $f',g'$ changes the output by at most $\|f'-f\|\|g'\|+\|f\|\|g'-g\|$. For operands in the disk, the two input errors therefore add rather than multiply.

Take a unit phase $e$, a disk-grid approximation $\widetilde e$ with $|\widetilde e-e|<2h_p$, and a disk operand $x$ (not the polynomial variable). Then $|\widetilde ex-ex|\le2\|x\|h_p$, and the truncation $Q_p$ moves each real and imaginary part by less than $h_p$. So $\|Q_p(\widetilde ex)-ex\|<(2\|x\|+\sqrt2)h_p<4h_p$. Since $|\widetilde e|\le1$ and $Q_p$ never increases a norm, $\|Q_p(\widetilde ex)\|\le\|x\|$.

The ring convolution $\mathcal M_r$ of [Phase twist](phase-twist.md) returns $(f*g)/T$. With $M=T/r$ records, it is computed by two normalized synthetic forward transforms, a pointwise product divided by $r$, a normalized opposite transform, which give $(f*g)/(rM^2)$, and a final exact multiplication by $M$. Before that multiplication the three transforms and the product truncation contribute error below $3L+2$, and the multiplication scales it by $M$: $E_{\rm ring}:=M(3L+2)<5TL$ <cite data-source="paper">E_{\rm ring}:=M(3L+2)<5TL.</cite> If one operand has norm at most $.7$, contraction gives $\|\mathcal M_r(f,g)\|\le.7$. The computed output differs by less than $5TLh_p$, below $10^{-3}$ for large $n$, so its norm is below $.701$.

The computed complex convolution twists both inputs (error below $4$ each, and the smaller operand keeps norm at most $.7$), applies $\mathcal M_r$, and untwists the output (below $4$). The two input errors add, so the error is below $(E_{\rm ring}+4+4+4)h_p<6TLh_p$.

The computed chirp transform $\widetilde{\mathscr C}$ evaluates the [Bluestein chirp identity](chirp.md): a phase product, a convolution with the chirp, a phase product. Let $\boldsymbol t$ list the axis lengths, $F_{\boldsymbol t}$ be the exact Fourier transform with those lengths, and $Q$ the target permutation. The kernel approximation adds below $2$, the first phase product below $4$, the convolution below $6TL$ and the last phase product below $4$: $\|\widetilde{\mathscr C}(x)-QF_{\boldsymbol t}x\|<(6TL+2+4+4)h_p<8TLh_p$.

A source transform applies [Gaussian resampling](gaussian-resampling.md) maps and a chirp transform, then an exact scaling by $2^\gamma$. The first stage has error below $2dp^2+8TL$. Because $2dp^2<TL$ eventually, the scaled error is below $E_sh_p$ with $E_s=9\cdot2^\gamma TL$. Here $\gamma$ is the source scale exponent, and $b\ge2^{24}$ gives $\gamma\le b/4$ <cite data-source="paper">$b\ge2^{24}$ implies $\gamma\le b/4$</cite>.

Now write $u,v$ for the arrays of scaled digits (the letters change meaning here): a digit $a_j<2^b$ is stored as $a_j2^{-b-2}$, so the norm is below $1/4$. Let $U,V_1$ be their exact source transforms and $\widetilde U,\widetilde V_1$ the computed ones, with norms below $1/4+E_sh_p<.26$. The computed product $z=Q_p(\widetilde U\cdot\widetilde V_1)$ has norm at most $.26^2<.5$. From
$$\widetilde U\cdot\widetilde V_1-U\cdot V_1=(\widetilde U-U)\cdot\widetilde V_1+U\cdot(\widetilde V_1-V_1)$$
each term is below $E_sh_p$, and truncation adds below $2h_p$, so $\|z-U\cdot V_1\|<(2E_s+2)h_p$.

Let $G$ be the exact opposite source transform. Both source transforms carry a factor $1/S$, so $F(u*v)=S\,Fu\cdot Fv$ and $F^+F=I/S$; the retained source permutation commutes with pointwise products and cancels ([Retained permutation cancellation](retained-permutations.md)). Hence $G(U\cdot V_1)=(u*v)/S^2$ <cite data-source="paper">If $S=\prod_i s_i$, then</cite>. Since $\|z\|<.5$, the computed opposite transform accepts $z$ and is within $E_sh_p$ of $Gz$, while $G$ is a contraction, so $\|G(z-U\cdot V_1)\|<(2E_s+2)h_p$. The total error is below $(3E_s+2)h_p$.

The first exact multiplication by $S$ gives $\widetilde w$ approximating $w=(u*v)/S$ with error below $E_wh_p$, $E_w:=S(3E_s+2)<28\cdot2^\gamma T^2L$ <cite data-source="paper">E_w:=S(3E_s+2)<28\,2^\gamma T^2L.</cite> Each coefficient of $w$ averages $S$ products below $1/16$, so $\widetilde w$ stays in the disk.

The integer coefficients are $2^{2b+4}Sw$: $2^{2b+4}$ undoes the two digit scales and $S$ the remaining $1/S$. This second scaling multiplies the error by $2^{2b+4}S$, and the error was only $2^{-p}=2^{-6b}$ per unit. Using $S\le T<2^b$ and $L<b$, we get $ST^2L<b\,2^{3b}$, so the absolute error is below
$$2^{2b+4}S\cdot28\cdot2^\gamma T^2L\cdot2^{-6b}<448b\,2^{-b+\gamma}\le448b\,2^{-3b/4}<\tfrac12.$$
The amplification of up to $2^{5b+4}$ is absorbed only because $p=6b$ leaves $2^{-b}$ of margin. The true coefficients are integers, so an error strictly below $1/2$ makes the nearest integer to the represented value (the stored integer over $2^p$) the unique correct coefficient.

Carry propagation then rebuilds the binary product from the coefficients $c_j$ of the [Multiplication as radix-digit convolution](radix-digit-reduction.md), where $0\le c_j\le q(2^b-1)^2$ and $q=\lceil n/b\rceil\le2^b$. With $Q_0=2^b$, set $k_0=0$ and
$$d_j=(c_j+k_j)\bmod Q_0,\qquad k_{j+1}=\lfloor(c_j+k_j)/Q_0\rfloor,$$
where $d_j$ is output digit $j$ and $k_j$ the carry into position $j$. Then $0\le k_j\le q(Q_0-1)<Q_0^2$. This holds at $j=0$; if it holds at $j$, then $c_j+k_j\le q(Q_0-1)^2+q(Q_0-1)=qQ_0(Q_0-1)$, and dividing by $Q_0$ gives it at $j+1$. Since $c_j+k_j=d_j+Q_0k_{j+1}$, adding $c_jQ_0^j$ to both sides of the invariant
$$\sum_{h<j}c_hQ_0^h=\sum_{h<j}d_hQ_0^h+k_jQ_0^j$$
turns its right side into $\sum_{h\le j}d_hQ_0^h+k_{j+1}Q_0^{j+1}$, so it holds for all $j$, starting from $j=0$. The unprocessed terms of the product are multiples of $Q_0^j$, so the first $j$ radix digits are $d_0,\dots,d_{j-1}$. The inputs are below $2^n$, so the exact product is below $2^{2n}$: all bits above position $2n-1$ are zero, and exactly $2n$ bits are output.
