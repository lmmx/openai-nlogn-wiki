## This page

Concept: Recursive power saving
Gloss: A call at parameter m·f uses s calls at parameter f on streams of volume V/W, so cost per volume obeys F_k ≤ (s/W)F_{k−1} + O(1) with s/W < m, giving cost O(V e^τ) for some fixed τ < 1.

## This page in the argument

The step: A fixed linear network that exchanges two banks of values, restores its scratch wires and has total edge rank $s<Wm$ yields a recursion whose cost per volume grows only like a fixed power $m^\tau$ with $\tau<1$ per multiplication of the parameter by $m$.
How: build the network from subset gates, carry arrays along it by frames, label its vertices by subspaces, and read off the recursion
Why: The source states that the strict inequality is the origin of the saving. (the sources say so: "is the source of the power saving." (paper))
Striking feature: The saving comes from the strict inequality $s/W<m$: the number of smaller calls per unit of volume is below the growth $m$ of the parameter, so each recursion level pays less than the naive factor. (explain why it holds, from the method)

Its sub-steps, in order:

- Three-element subset gates (copy, gather, scatter, side injection) are fixed linear maps whose net coefficient from $x_T$ to $y_S$ depends only on the intersection size $|S\cap T|$, and auxiliary side and center wires cancel the unwanted coefficients. (on [Three-element subset gates (copy, gather, scatter, side wires)](subset-intersection-gates.md))
- Three staged invocations of the gate schedule exchange the two banks, sending $(X_a,Y_a)$ to $(-Y_a,X_a)$, and restore every auxiliary scratch value whatever its initial content. (on [Scratch-restoring bank-exchange network](bank-exchange-network.md))
- Replacing scalars by arrays with an invertible frame $D_v$ at each vertex lets pointwise linear gates commute with the common frame, so the whole network acts as $D_{\rm out}\mathsf S_\Omega D_{\rm in}^{-1}$. (on [Frames: changing representation along a network](frames-network.md))
- Nested subspace labels on the gates and terminals make each edge cost its rank in smaller operations, and the total rank $s$ over all edges is strictly less than $Wm$, where $W$ is the number of wires and $m$ the dimension of the label space. (on [Subspace labels and the rank deficit](subspace-rank-saving.md))
- A call at parameter $mf$ uses $s$ calls at parameter $f$ on streams of volume $V/W$, so the cost per volume obeys $F_k\le(s/W)F_{k-1}+O(1)$ with $s/W<m^\tau$ for the explicit exponent $\tau=1-2^{-50}<1$.

It serves these steps, from the main result down:

- A deterministic fixed-tape Turing machine multiplies $n$-bit integers in $T_A(n)=O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.; how: reduce the product to a digit convolution computed by synthetic transforms, replace the address rearrangement and butterfly layers inside those transforms by two faster recursive tape procedures, then assemble, round and bound the cost (on [Integer multiplication below n log n](sub-nlogn-multiplication.md))
- Two recursive tape procedures, an address-chunk interchange and a simultaneous butterfly layer, run faster than the naive costs of address rearrangement and Fourier layers by a power of the width.; how: build the elementary tape tools, derive a general recursive power saving from a fixed linear network, and instantiate it twice, once for bits and once for complex values

## Evidence from the sources, with the paragraph around each quote

- "This strict inequality is the source of the power saving." (paper)

  > A recursive call at parameter $mf$ therefore uses $s$ calls at parameter $f$, each on a stream of volume $V/W$. The parameter counts field digits for address interchange and selected axes for a numerical layer. After dividing cost by volume, multiplying the parameter by $m$ increases the recursive contribution by $s/W<m$. This strict inequality is the source of the power saving. The later tape and arithmetic estimates preserve it, including the work of changing numerical address coordinates. Those changes are implemented by whole-chunk moves and controlled shifts, followed by a deterministic correction of the explicitly identified exceptional addresses.

- "F_0=O(1),\qquad F_k\le(s/W)F_{k-1}+O(1)." (paper)

  > The number of recursive calls is the sum of the edge ranks, exactly $s$. Each acts on one role stream of volume $V/W$, retaining all other fields as spectators. Splitting, merging, gates, and triangular operations have total cost $O(V)$ because their number is fixed. Below we verify that scheduling the recursive calls on fixed tapes also costs $O(V)$ at this node. Thus if $F_k$ is a uniform upper bound for time divided by logical volume, then \begin{equation} \label{eq:swap-recurrence} F_0=O(1),\qquad F_k\le(s/W)F_{k-1}+O(1). \end{equation} For $a=s/W<m^\tau$ the geometric sum $\sum_{j=0}^k a^j$ is $O(m^{k\tau})$. If $a\le1$, the sum is at most $k+1=O(m^{k\tau})$; if $a>1$, it is $O(a^k)$. Hence $F_k=O(e^\tau)$.
