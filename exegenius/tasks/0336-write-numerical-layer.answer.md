A numerical layer is one stage of the transform calculation: a simultaneous butterfly applied to selected axes of the array. Its cost bound lets the [Rank-saving recursion](rank-saving-recursion.md) save a power at each level.

The numerical layer computes the [Simultaneous butterfly layer](simultaneous-butterfly-layer.md) on its selected bits. Each address is written as $D$ consecutive chunks of $K$ address bits, and each chunk selects one bit at the same offset $\rho$. Each address holds a [record](payload.md) of $r$ complex coefficients. The layer acts on the [record](payload.md) at each address, coefficient by coefficient.

On one selected bit the map is $H_0(\mu,\nu) = ((\mu+\nu)/2, (\mu-\nu)/2)$. Applied to all $D$ selected bits, it is the tensor product $H_0^{\otimes D}$, which combines each group of $2^D$ values that agree outside the selected bits. For example, take $D = 2$ and first coefficients $1, 3, 5, 7$ at the settings $(0,0)$, $(0,1)$, $(1,0)$ and $(1,1)$. Then $H_0^{\otimes 2}$ gives $4, -1, -2, 0$ at the same settings; at $(0,1)$ the value is $(1-3+5-7)/4 = -1$.

The layer costs $O(V d^{\lambda'})$, where $d$ is an upper bound on $D$ (the letter changes meaning here) and $\lambda'$ is a fixed exponent below one. One axis at a time is worse: <cite data-source="paper">separate butterfly factors would require D whole-array passes</cite>, each scanning all $V$ stored bits, for $O(VD)$ in total.

Here $W$ is the number of roles among which rows are distributed, and $m$ is the fixed integer by which each call divides its number of axes (the letter changes meaning here). Here $s$ is the number of smaller calls that one call makes. The cost count is a recursion that needs $s < Wm$. <cite data-source="paper">Distribute rows cyclically among the W roles</cite>. Let $e$ be the number of selected axes a call acts on. A call on $e$ axes makes $s$ calls on $e/m$ axes, each on $V/W$ stored bits. <cite data-source="paper">The decisive property is that the total number s of smaller calls satisfies s < W m.</cite>

<cite data-source="paper">Dividing by the current volume V gives the factor s/W</cite>, so each level multiplies the work by $s/W$. Counting only the calls, with $\log_m d$ levels the total is $O(V(s/W)^{\log_m d}) = O(V d^{\log_m(s/W)})$, where $\log_m x$ is the exponent to which $m$ must be raised to give $x$. Since $s/W < m$, this exponent is below one. <cite data-source="paper">This strict inequality is the source of the power saving.</cite>

The layer is computed exactly. Its operations are <cite data-source="paper">complex additions, subtractions, halvings, sign changes and multiplication by i</cite>, which keep every value a Gaussian dyadic, a Gaussian integer over a power of two. The inputs lie on the grid $2^{-p}\mathbb{Z}[i]$, so <cite data-source="paper">Intermediate values are exact Gaussian dyadics</cite>.
