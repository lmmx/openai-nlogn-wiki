Recursive power saving is the mechanism that gives a tape procedure, a procedure that rearranges stored data on the tapes of a Turing machine, a cost that is a fixed power of its parameter, with exponent below one. It is built from a [Linear network with restored auxiliary values](linear-network-exchange.md), a fixed network that exchanges two banks of values and restores every auxiliary value.

A call moves a volume $V$ of data. The network has $W$ roles and makes $s$ smaller calls. In this page the letter $m$ changes meaning: $m$ is the factor by which the parameter grows, not a digit count. A call at parameter $me$ makes $s$ calls at parameter $e$, where $e$ is the parameter of a smaller call. Each smaller call works on a stream of volume $V/W$, and the call also does linear work on its own volume.

Let $L$ be the number of levels, so the top call has parameter $m^L$ and the base calls have parameter $1$. Base calls cost time linear in their volume. Let $\ell$ be the level index, counted from the top with $\ell=0$. After $\ell$ levels there are $s^\ell$ calls, each on volume $V/W^\ell$, so level $\ell$ costs $V(s/W)^\ell$ up to a constant. Put $\alpha=\log_m(s/W)$, the exponent of the saving, so $s/W=m^\alpha$ and level $\ell$ costs $Vm^{\alpha\ell}$. If $s>W$, then $\alpha>0$, and the sum over $\ell=0,\dots,L$ is a geometric sum with ratio $m^\alpha>1$, dominated by its last term. The total is therefore $O(V(m^L)^\alpha)$.

The exponent is uniform. Each level multiplies the call count by $s$ and divides each volume by $W$, so $s/W$ is the same at every level, and $\alpha$ depends only on $s$, $W$ and $m$, not on $V$. The saving is strict exactly when $s<Wm$, that is $\alpha<1$, since then $m^\alpha<m$. <cite data-source="paper">This strict inequality is the source of the power saving</cite> If $s=Wm$, the cost is linear in the parameter and nothing is saved.

Applied to the [Fast address interchange](address-interchange.md) with digit count $e$ as parameter, this recursion bounds the cost of the interchange by $O(Ve^\tau)$ for a fixed $\tau$ with $\alpha<\tau<1$. <cite data-source="paper">Choose a rational number $\tau\in(0,1)$ with $s/W<m^\tau$.</cite> Any such $\tau$ works because $m^\alpha<m^\tau$, so the level sum is at most a constant times $m^{L\tau}=e^\tau$ for the top parameter $e=m^L$.

The same mechanism is applied to the [Simultaneous butterfly layer](simultaneous-butterfly-layer.md), with chunk count $d$ as the parameter.
