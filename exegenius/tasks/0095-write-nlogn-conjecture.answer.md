Here $n$ is the number of bits in each input integer, and time is worst-case running time as a function of $n$. The Schönhage–Strassen conjecture says that $n\log n$ is the optimal order of growth of the time to multiply two integers on a multitape Turing machine.

"Optimal" has two halves: $n\log n$ is achievable, and no algorithm is faster. A running time is $o(n\log n)$ when its ratio to $n\log n$ tends to $0$ as $n \to \infty$, so it grows strictly more slowly. The conjecture says that no multiplication algorithm on this machine has running time $o(n\log n)$.

The upper half is known. Schönhage and Strassen gave a multiplication method with running time $O(n\log n\log\log n)$ <cite data-source="paper">proved in 1971 that two $n$-bit integers can be multiplied in $O(n\log n\log\log n)$ time</cite>. The conjectured order is matched from above by the unconditional $O(n\log n)$ bound of [Harvey–van der Hoeven O(n log n) multiplication](harvey-hoeven-multiplier.md). The open question is therefore the lower half.

The exponent gap $\kappa = 2^{-182}$ is a fixed positive constant. The conjecture is refuted by [Integer multiplication in O(n(lg n)^(1-κ)) time](integer-multiplication-target.md), which multiplies in $O(n(\lg n)^{1-\kappa})$ worst-case time. Its time is $o(n\log n)$: changing the base of a logarithm multiplies it by a constant, so $n\log n$ is a constant times $n\lg n$. The ratio of the two is then a constant times $(\lg n)^{1-\kappa}/\lg n = (\lg n)^{-\kappa}$, which tends to $0$ because $\kappa > 0$. Hence the conjecture is false in this model.
