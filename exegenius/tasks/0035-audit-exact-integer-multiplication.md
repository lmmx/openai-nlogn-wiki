## Page to audit (`exact-integer-multiplication`)

````markdown
# Exact integer multiplication

Exact integer multiplication is the task of computing the complete product of two binary integers, with no rounding and no bits lost. The main result bounds the cost of this task ([Integer multiplication below n log n](main-theorem.md)), and its method begins by splitting each input into digits, which reduces the product to a convolution ([radix-digit convolution](radix-digit-convolution.md)).

Here $n$ is the number of bits in each input. Let $x$ and $y$ be binary strings, each of length $n$. For a binary string $x$ of length $n$, $\mathrm{val}(x)$ is its nonnegative integer value, with the leftmost bit most significant. For $0 \le z < 2^k$, $\mathrm{bin}_k(z)$ is the binary representation of $z$ padded on the left with zeros to length $k$.

The input is the string $x\#y$, and the output must be $\mathrm{bin}_{2n}(\mathrm{val}(x)\cdot\mathrm{val}(y))$, the $2n$-bit representation of the product. The output has $2n$ bits because each value is at most $2^n - 1$, so the product is below $2^{2n}$.

For example, take $n = 2$, $x = 10$ and $y = 11$. Then $\mathrm{val}(x) = 2$ and $\mathrm{val}(y) = 3$, so the product is $6$, and the required output is $\mathrm{bin}_4(6) = 0110$.

Exactness must hold for every input length, not only for large $n$. Costs are measured on a machine whose alphabet and number of tapes are fixed in advance. The machine does not change as $n$ grows; only the input does.

The classical question is how fast this product can be computed. (see [the n log n optimality conjecture](n-log-n-conjecture.md)).
````
