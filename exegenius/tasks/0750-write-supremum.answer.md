The supremum of a set of real numbers is its least upper bound, the smallest real number that is at least every element of the set. It is the quantity from which the operator norm of a linear map is defined, and the [linear contraction](linear-contraction.md) bound on how errors pass through a computation is stated with it.

Let $\Sigma$ be a nonempty set of real numbers. Let $\chi$ denote an arbitrary element of $\Sigma$. Let $\Omega$ denote a real number. Call $\Omega$ an *upper bound* of $\Sigma$ when $\chi \le \Omega$ for every element $\chi$ of $\Sigma$. The supremum $\sup \Sigma$ is the least upper bound: it is an upper bound of $\Sigma$, and it is at most every other upper bound of $\Sigma$. Every nonempty set of real numbers with an upper bound has a supremum, a standard property of the real numbers.

The supremum need not be an element of $\Sigma$. Take $\Sigma = \{\,1-2^{-\nu} : \nu \ge 1\,\} = \{1/2, 3/4, 7/8, \dots\}$, where $\nu$ is a positive integer index. Every element is less than $1$, so $1$ is an upper bound. Let $\Omega < 1$, and let $\varepsilon = 1-\Omega > 0$ be the gap between $\Omega$ and $1$. Choose a positive integer $\nu$ with $\nu+1 > 1/\varepsilon$. Since $2^m \ge m+1$ for every integer $m \ge 0$ (by induction), this $\nu$ gives $2^{-\nu} \le 1/(\nu+1) < \varepsilon$. Then $1-2^{-\nu} > \Omega$, so $\Omega$ is not an upper bound. Hence $\sup \Sigma = 1$, although $1 \notin \Sigma$.

For a linear map $T$, meaning a map that preserves sums and scalar multiples, the largest factor by which $T$ stretches a vector is its operator norm $\|T\|$. Here $v$ denotes one input vector, a finite list of complex numbers, and $\|v\|$ denotes its largest modulus (absolute value) over all entries. The paper writes this with its own letters, $L$ and $u$ for $T$ and $v$: <cite data-source="paper">∥L∥ = sup∥u∥≤1 ∥Lu∥</cite>. In our notation,

$$\|T\| = \sup_{\|v\| \le 1} \|Tv\|.$$

The set over which the supremum is taken is restricted by the [Array norm](array-norm.md) of $v$: only inputs with $\|v\| \le 1$ are used. This set of values is nonempty, since the zero input gives $0$, and bounded above, since each entry of $Tv$ is a fixed combination of the entries of $v$. So $\|T\|$ is a real number. A linear map with $\|T\| \le 1$ does not increase the size of any input, which is the [linear contraction](linear-contraction.md) property.
