A linear network with restored auxiliary values is a fixed network of linear gates that exchanges two banks of values, with prescribed signs, and returns every auxiliary (scratch) value to its starting content. Each tape procedure on this page is built from one such network: the wiring is the same for every input, and only the data changes. The network matters because it turns the exchange into one fixed computation whose scratch values cancel out.

Each wire has a fixed place in the network, its *role*. The values on a wire form an array indexed by a finite address set $\Omega$, and a gate acts pointwise: at each fixed address it takes a linear combination, with scalar coefficients, of the values on the wires it touches.

Each source, gate and sink $v$ carries an invertible linear operator $D_v$ on arrays indexed by $\Omega$, its *frame*. Each frame is invertible, so it has full [matrix rank](matrix-rank.md) on the $|\Omega|$ addresses. The stored array at $v$ is $D_v$ applied to the logical array that the network computes with. An edge from $u$ to $v$ changes the stored array by $D_vD_u^{-1}$ and leaves the logical array fixed. A gate commutes with a common frame: if all its inputs are stored in frame $D_v$, its output is stored in frame $D_v$ too, because it combines values pointwise with scalar coefficients. So the frames on intermediate vertices cancel. A route from input role $w$ to output role $\rho(w)$ with sign $\varepsilon_w$ applies $\varepsilon_w D_{\mathrm{sink}(\rho(w))}D_{\mathrm{source}(w)}^{-1}$ to the array. Only the endpoint frames matter, so the intermediate frames can be chosen to make each edge change cheap.

Example. Take the values on the two wires at one address to be $x$ and $y$. The three-invocation schedule of the lemma changes them to $(x,y+x)$, then $(-y,y+x)$, then $(-y,x)$. The schedule therefore sends $(X_a,Y_a)$ to $(-Y_a,X_a)$, with $X_a$ and $Y_a$ the auxiliary values of the two banks. It also <cite data-source="paper">restores every auxiliary value.</cite>
