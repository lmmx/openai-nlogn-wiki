## This page

Concept: Running time cost
Gloss: The number of machine steps an algorithm takes, as a worst-case function of the input length, on a machine with a fixed alphabet and fixed number of tapes.
Also called: cost, linear-cost update, bit-complexity bound

The running time cost of a machine is the number of steps it takes on an input, written as a function of the input length and taken in the worst case over all inputs of that length. The main theorem is a statement about this quantity, so every bound on the way to it is a bound on the running time cost of one specific machine.

Running time cost is defined on a fixed-tape machine, namely a machine with one fixed finite alphabet and one fixed finite number of one-dimensional tapes. <cite data-source="paper">A machine has one fixed finite alphabet and one fixed finite number of one-dimensional tapes.</cite> The alphabet is the finite set of symbols that any cell may hold. Each tape is a row of cells, and each tape has a head that sits on one cell at a time.

One step of the machine is one local move: <cite data-source="paper">step reads and writes at most one cell on each tape and moves each head by at most one cell.</cite> So a head that must cross $5$ cells needs at least $5$ steps, and the cost of a computation is the number of such moves, including the moves that bring the heads back.

For a machine $A$ and an input length $n$, the running time cost is $T_A(n)$, the largest number of steps $A$ takes on any input of length $n$. The worst case is needed because a machine may stop early on some inputs. Consider a machine that scans its input from left to right and halts at the first $1$. On the input $0001$ of length $4$ it takes $4$ steps, but on the input $0000$ it takes $4$ steps as well, since it must scan every cell before it finds no $1$. The cost $T_A(4)$ is the maximum over all $16$ inputs of length $4$, and an input that is all zeros is the one that realises it. The main theorem's bound is of this kind: <cite data-source="paper">Its worst-case running time satisfies</cite> an $O(\cdot)$ bound in $n$, and $O(\cdot)$ means that the cost is at most a constant times the stated function for all large enough $n$.

As a second example, a head that starts at the left end of an input of $n$ cells, walks to the right end and returns to the left end makes $2(n-1)$ moves. For $n = 4$ that is $6$ steps, so the running time cost of this procedure is $2(n-1)$, a linear function of $n$.
