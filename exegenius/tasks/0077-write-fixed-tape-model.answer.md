A fixed-tape machine model is a Turing machine whose alphabet and number of tapes are fixed in advance, so that they do not grow with the input. It is the setting of the paper *Integer multiplication below n log n* (OpenAI, 2026), whose main result is stated in this model; see [Integer multiplication below n log n](main-theorem.md).

A fixed-tape machine is constrained in three ways. Its alphabet is finite and fixed. It has a finite, fixed number of tapes, and each tape is one-dimensional: a row of cells with a head that sits on one cell at a time. <cite data-source="paper">A machine has one fixed finite alphabet and one fixed finite number of one-dimensional tapes.</cite> Only the contents of the tapes may grow with the input; the alphabet and the tape count may not.

Each step is local. <cite data-source="paper">A step reads and writes at most one cell on each tape and moves each head by at most one cell.</cite> For example, suppose a tape holds the string 1011 with its head on the first cell. One step can overwrite that 1 with a 0 and move the head to the second cell, but it cannot jump to the fourth cell. Reaching a cell $k$ cells away from the head therefore takes at least $k$ steps.

Fixing the size makes the lower-bound question precise. Let $n$ be the number of bits in each of the two input integers. Let $T_A(n)$ be the running time of a machine $A$ on inputs of that length. Schönhage and Strassen <cite data-source="paper">conjectured n log n as the optimal order of multiplication cost</cite>. Because the machine is fixed, the conjecture is a claim about each machine separately. For a machine $A$, let $c_A > 0$ be a constant and $N_A$ a threshold input length, both depending on $A$. <cite data-source="paper">In the present fixed-tape model, an eventual lower bound for every multiplication machine means</cite> that $T_A(n) \geq c_A\, n \log n$ for all $n \geq N_A$.

In this model the conjecture is refuted through one machine whose ratio $T_A(n)/(n \log n)$ has [limit inferior](limit-inferior.md) zero. The paper's Theorem 1 supplies such a machine. <cite data-source="paper">Its worst-case running time satisfies</cite> $T_A(n) = O(n(\lg n)^{1-\kappa})$ with $\kappa = 2^{-182}$, where $\lg n$ denotes $\log_2 n$. Since $(\lg n)^{-\kappa}$ tends to zero, the ratio $T_A(n)/(n \log n)$ tends to zero and so has limit inferior zero. The theorem refutes an eventual $\Omega(n \log n)$ lower bound <cite data-source="paper">for every fixed multiplication machine in this model.</cite>
