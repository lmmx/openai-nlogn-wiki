## This page

Concept: Subset-intersection network
Gloss: A linear network on the three-element subsets of a ground set, whose wires carry scalars and whose gates combine them by intersection size, so that it swaps two banks while cancelling arbitrary scratch values.
Also called: three-element subset network

## This page in the argument

The step: A linear network on three-element subsets exchanges two banks of values and restores its scratch wires.
How: label the triples by subspaces whose inclusions bound the change of frame
Why: Orthogonality of the indicator vectors gives subspace assignments with the nesting that the change of frame needs. (the sources leave this for the reader to work out: spell it out)

Its sub-steps, in order:

- The construction uses three-element subsets, with gather and scatter creating coefficients from intersection sizes.

It serves these steps, from the main result down:

- Exact multiplication of two $n$-bit integers runs in $O(n(\lg n)^{1-\kappa})$ time on one fixed fixed-tape machine, with $\kappa = 2^{-182}$.; how: reduce exact multiplication to radix-digit convolution, compute that convolution with fast tape transforms, and check that the output is exact (on [Integer multiplication below n log n](main-theorem.md))
