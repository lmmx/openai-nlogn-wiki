A permutation is a rearrangement of a finite set of positions: a map that moves each position to another so that every position is filled exactly once. The paper uses permutations to move stored data, and the page [Address-field interchange](address-interchange.md) builds on this one, because swapping two blocks of address bits is a permutation of an array's addresses.

Here $W$ is a finite set of positions, and $\sigma$ is the permutation, the map that sends each position to its new position. A permutation of $W$ is defined as a [bijection](bijection.md) of $W$ onto itself: a map $\sigma$ from $W$ to $W$ that is one-to-one (no two positions have the same image) and onto (every position is an image). Because $\sigma$ is a bijection, it has an inverse $\sigma^{-1}$ that undoes the move.

**Rearranging a sequence.** Take $W=\{1,2,3,4\}$, with $\sigma(1)=3$, $\sigma(2)=1$, $\sigma(3)=4$ and $\sigma(4)=2$. Here $\alpha$, $\beta$, $\gamma$ and $\delta$ are four entries of a sequence, one at each of the positions $1,2,3,4$; these letters change meaning here. Applying $\sigma$ moves the entry at each position to its image, so $\alpha$ goes to position 3, $\beta$ to position 1, $\gamma$ to position 4 and $\delta$ to position 2, giving $(\beta,\delta,\alpha,\gamma)$. Every position of the result is filled exactly once, so no entry is lost or copied.

The bijection property is what makes this work. If $\sigma$ were not one-to-one, two entries would land in the same position and one would be overwritten. If it were not onto, some position would receive no entry. Both failures destroy data, while a bijection only moves it.

**Permutations of arrays.** Write $\xi$ for an address, the position of one entry of an array. Let $G$ be an array whose entries are stored at addresses. An address permutation $\sigma$ moves the entry at $\xi$ to $\sigma(\xi)$. The paper writes this map as $f$ and states: <cite data-source="paper">An address permutation f moves the entry at x to f (x).</cite> The moved array $G'$ holds the same entries at the new addresses, so $G'(\sigma(\xi))=G(\xi)$ for every address $\xi$. No entry is recomputed.

**Cost of a move.** <cite data-source="paper">A machine has one fixed finite alphabet and one fixed finite number of one-dimensional tapes.</cite> <cite data-source="paper">A step reads and writes at most one cell on each tape and moves each head by at most one cell.</cite> A scan is one pass of a head over the cells of a tape, and the time of an operation is its number of steps. Moving one digit in a fixed radix is cheap: it <cite data-source="paper">needs a bounded number of scans</cite>. Moving whole fields whose digit counts grow needs more work. The paper realizes this interchange in its Section 4 <cite data-source="paper">by computing XOR combinations of intermediate data streams</cite>, where the bitwise exclusive or of two bits is 1 exactly when the bits differ.
