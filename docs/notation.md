# Notation

The symbols that more than one page uses, in the order they are bound. Each is bound once, on a page or in a concept's name, and used on the pages listed. A symbol used on one page only is explained on that page and is not listed here.

- $a$ — **real numerator part**: The integer real part of the numerator $a + bi$ of a Gaussian dyadic. Bound on [Gaussian dyadics](glossary.md#gaussian-dyadics "Complex numbers whose real and imaginary parts are integers divided by a power of two, with the Gaussian integer part also an integer."); used on [Bilinear form](glossary.md#bilinear-form "A function of two vectors that is linear in each argument; a form is nondegenerate when no nonzero vector is orthogonal to every vector of the space.").

- $u$ — **first coefficient**: The first coefficient of a pair on which the two-point map $H_0$ acts. - $n$ — **input length**: The number of bits in each of the two inputs, the common length of x and y.
