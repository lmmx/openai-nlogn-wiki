The order of an element of a group is the number of distinct powers that the element produces before the powers return to the identity. The [Chinese-remainder map](chinese-remainder-map.md) needs this number to show that its image of the indeterminate reaches every target monomial exactly once, so the map loses no coefficient.

Let $\mathcal{G}$ be a group: a set with an associative operation, an identity element $1$, and an inverse for each element. Let $\chi$ be an element of $\mathcal{G}$. Its powers $\chi^0 = 1$, $\chi^1 = \chi$, $\chi^2 = \chi\chi$, and so on, are elements of $\mathcal{G}$, where the exponent is a nonnegative integer. If $\mathcal{G}$ is finite, these powers cannot all be different, so some positive power of $\chi$ equals $1$. The order of $\chi$, written $m$, is the least positive integer with $\chi^m = 1$. It is also called the multiplicative order of $\chi$.

The powers $\chi^0, \dots, \chi^{m-1}$ are all different. If $\chi^a = \chi^b$ with $0 \le a < b < m$, multiplying by the inverse of $\chi^a$ gives $\chi^{b-a} = 1$ with $0 < b-a < m$, contradicting the minimality of $m$. So $m$ counts the distinct powers of $\chi$. Division with remainder also shows that $\chi^k = 1$ exactly when $m$ divides $k$, so the powers repeat with period $m$.

For example, the nonzero residues modulo $7$ form a group under multiplication, with identity $1$. For $\chi = 2$ the powers are $2$, $4$, and $2^3 = 8 \equiv 1$, so the order is $3$. For $\chi = 3$ the powers $3, 2, 6, 4, 5, 1$ are six different residues, so the order is $6$, the size of the group.

Within a [cyclic group](cyclic-group.md), the order of an element is read off from the group it generates. A generator therefore has order equal to the size of the group.

The [Chinese-remainder map](chinese-remainder-map.md) applies this to pairwise coprime axis lengths $t_1, \dots, t_d$, where axis $i$ has length $t_i$ and their product is $S = t_1 t_2 \cdots t_d$, the number of target monomials. Let $t$ be the indeterminate of $\mathbb{C}[t]/(t^S-1)$, and let $Y_i$ be the variable of axis $i$. A target monomial is a product $Y_1^{a_1} \cdots Y_d^{a_d}$ with $0 \le a_i < t_i$. Each $\mu_i$ is the inverse of $\prod_{j<i} t_j$ modulo $t_i$, which exists because that product is coprime to $t_i$. The map $\Phi$ sends $t$ to $\prod_i Y_i^{\mu_i}$, the product of the axis variables raised to the powers $\mu_i$. The claim is that the image of $t$ <cite data-source="paper">has order S, because each µi is a unit and the si are pairwise coprime.</cite> Its powers therefore run <cite data-source="paper">through all target basis monomials exactly once.</cite>

Take axis lengths $t_1 = 3$ and $t_2 = 5$, so $S = 15$. The inverse of $3$ modulo $5$ is $2$, since $3 \cdot 2 = 6 \equiv 1$. The product before axis $1$ is empty, so $\mu_1 = 1$ and $\mu_2 = 2$, and $\Phi(t) = Y_1 Y_2^2$. Then $\Phi(t)^k = Y_1^k Y_2^{2k}$. Since $Y_1^3 = 1$, $Y_2^5 = 1$, and the monomials $Y_1^a Y_2^b$ with $a < 3$, $b < 5$ are distinct, $\Phi(t)^k = 1$ exactly when $3$ divides $k$ and $5$ divides $2k$. Because $2$ is invertible modulo $5$, the second condition means $5$ divides $k$. So $\Phi(t)$ has order $15$, the least positive $k$ divisible by both $3$ and $5$.

The $15$ powers $\Phi(t)^0, \dots, \Phi(t)^{14}$ are therefore $15$ distinct monomials, which is all $S = 15$ target basis monomials. If the order were $5$ instead, the powers would repeat after five steps and reach only five of the fifteen monomials. The order is what makes $\Phi$ a bijection on bases: the basis $1, t, \dots, t^{S-1}$ goes to the target basis, each monomial used once.
