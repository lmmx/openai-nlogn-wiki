# Notation

The symbols that more than one page uses, in the order they are bound. Each is bound once, on a page or in a concept's name, and used on the pages listed. A symbol used on one page only is explained on that page and is not listed here.

- $h$ — **ground set size**: The number of elements of the ground set, from which the three-element subsets are taken. Bound on [Linear network that restores auxiliary values](linear-network.md "A fixed network of linear gates that exchanges two banks of values with prescribed signs and returns every auxiliary value to its starting state."); used on [Subset-intersection network](subset-network.md "A linear network whose subspace labels come from intersection sizes of three-element subsets, so that the total number of smaller calls is less than the number of wires times the dimension.").
- $a$ — **bank index**: A triple of subsets $a=(a_1,a_2,a_3)$ that indexes each value of the two banks. Bound on [Linear network that restores auxiliary values](linear-network.md "A fixed network of linear gates that exchanges two banks of values with prescribed signs and returns every auxiliary value to its starting state."); used on [Subset-intersection network](subset-network.md "A linear network whose subspace labels come from intersection sizes of three-element subsets, so that the total number of smaller calls is less than the number of wires times the dimension.").
- $X_a$ — **data bank X**: The first data bank, holding one value for each index $a$. Bound on [Linear network that restores auxiliary values](linear-network.md "A fixed network of linear gates that exchanges two banks of values with prescribed signs and returns every auxiliary value to its starting state."); used on [Subset-intersection network](subset-network.md "A linear network whose subspace labels come from intersection sizes of three-element subsets, so that the total number of smaller calls is less than the number of wires times the dimension.").
- $Y_a$ — **data bank Y**: The second data bank, holding one value for each index $a$. Bound on [Linear network that restores auxiliary values](linear-network.md "A fixed network of linear gates that exchanges two banks of values with prescribed signs and returns every auxiliary value to its starting state."); used on [Subset-intersection network](subset-network.md "A linear network whose subspace labels come from intersection sizes of three-element subsets, so that the total number of smaller calls is less than the number of wires times the dimension.").
- $T$ — **subset T**: A three-element subset of $[h]$ used as a varying coordinate, not the linear map of the earlier page. Bound on [Linear network that restores auxiliary values](linear-network.md "A fixed network of linear gates that exchanges two banks of values with prescribed signs and returns every auxiliary value to its starting state."); used on [Subset-intersection network](subset-network.md "A linear network whose subspace labels come from intersection sizes of three-element subsets, so that the total number of smaller calls is less than the number of wires times the dimension.").
- $S$ — **subset S**: A three-element subset of $[h]$ used as the varying target coordinate of an invocation. Bound on [Linear network that restores auxiliary values](linear-network.md "A fixed network of linear gates that exchanges two banks of values with prescribed signs and returns every auxiliary value to its starting state."); used on [Subset-intersection network](subset-network.md "A linear network whose subspace labels come from intersection sizes of three-element subsets, so that the total number of smaller calls is less than the number of wires times the dimension.").
