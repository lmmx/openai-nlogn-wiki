A diagonal scaling is a linear operator that multiplies each coordinate of a vector by its own fixed scalar. It is the phase step of the argument: the paper's [simultaneous butterfly layer](simultaneous-butterfly-layer.md) combines each pair of entries whose addresses differ in the selected bits, and <cite data-source="paper">becomes the simultaneous H0 layer after diagonal phase operations and a dyadic scale.</cite>

A diagonal scaling is built from the linear maps of [Linear algebra basics](linear-algebra-basics.md). Let $\mathcal I$ be the finite set of coordinate labels, one for each coordinate of the vectors. Each label $\iota\in\mathcal I$ names one coordinate, and $x_\iota$ is the value of a vector $x$ at that coordinate. Write $F^{\mathcal I}$ for the vector space of arrays $x=(x_\iota)_{\iota\in\mathcal I}$ with entries $x_\iota\in F$. Given a family of scalars $\upsilon=(\upsilon_\iota)_{\iota\in\mathcal I}$ with each $\upsilon_\iota\in F$, the diagonal scaling $\Delta_\upsilon$ is the map

$$(\Delta_\upsilon x)_\iota=\upsilon_\iota\,x_\iota \qquad\text{for every } \iota\in\mathcal I.$$

The letter $\upsilon$ names this family only, so the fixed exponent $\tau$ of the [payload](payload.md) page keeps its meaning. Each output coordinate depends on only one input coordinate, and it does so linearly, so $\Delta_\upsilon(x+y)=\Delta_\upsilon x+\Delta_\upsilon y$ and $\Delta_\upsilon(\gamma x)=\gamma\,\Delta_\upsilon x$ for vectors $x,y$ and scalars $\gamma\in F$. Its matrix has $\upsilon_\iota$ in position $(\iota,\iota)$ and zeros elsewhere, which is where the name comes from.

The phase operator of the butterfly layer is a diagonal scaling whose index set is the set of addresses. For an address $\alpha$, let $\operatorname{ones}(\alpha)$ be the number of selected bits of $\alpha$ equal to $1$. The scalar at $\alpha$ is the power $i^{\operatorname{ones}(\alpha)}$ of the imaginary unit $i$, so it depends on that address alone. Each selected bit is $0$ or $1$, so $\operatorname{ones}(\alpha)$ is also the sum of the selected bits. The paper says that <cite data-source="paper">The diagonal operator SD multiplies the value stored at an address by the phase</cite> determined by those bits. <cite data-source="paper">Here the unselected address bits are unchanged, and the same phase is applied to every coefficient</cite> stored at that address. With two selected bits, the addresses $00,01,10,11$ receive the phases $1,\,i,\,i,\,-1$.

Two facts follow from the definition. First, $\Delta_\upsilon$ is invertible exactly when every $\upsilon_\iota$ is nonzero. If all are nonzero, the scaling $\Delta_{\upsilon^{-1}}$ with $(\upsilon^{-1})_\iota=1/\upsilon_\iota$ is a two-sided inverse, because the $\iota$-th coordinate of $\Delta_{\upsilon^{-1}}\Delta_\upsilon x$ is $\upsilon_\iota^{-1}\upsilon_\iota x_\iota=x_\iota$. If some label $\iota_0\in\mathcal I$ has $\upsilon_{\iota_0}=0$, then $\Delta_\upsilon$ sends both the vector with a $1$ in coordinate $\iota_0$ and $0$ elsewhere, and the zero vector, to $0$, so two different vectors have the same image, and $\Delta_\upsilon$ is not invertible. Second, for a second family $\upsilon'=(\upsilon'_\iota)_{\iota\in\mathcal I}$ of scalars, $\Delta_\upsilon\Delta_{\upsilon'}=\Delta_{\upsilon\upsilon'}$, where $(\upsilon\upsilon')_\iota=\upsilon_\iota\upsilon'_\iota$. So diagonal scalings compose by multiplying their scalars coordinatewise.

Worked example. Take $F=\mathbb{C}$, $\mathcal I=\{1,2,3,4\}$ and $\upsilon=(1,\,i,\,-1,\,-i)$. For $x=(2,\,1+i,\,0,\,3)$,
$$\Delta_\upsilon x=(2,\;i(1+i),\;0,\;-3i)=(2,\;-1+i,\;0,\;-3i).$$
The inverse scalings are $\upsilon^{-1}=(1,\,-i,\,-1,\,i)$, and applying $\Delta_{\upsilon^{-1}}$ to the result gives $(2,\;-i(-1+i),\;0,\;i(-3i))=(2,\;1+i,\;0,\;3)=x$, as the composition rule predicts.
