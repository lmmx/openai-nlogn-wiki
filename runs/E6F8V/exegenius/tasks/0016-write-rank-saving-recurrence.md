## This page

Concept: Recursive rank saving
Gloss: Splitting rows among the W network roles makes each recursive call a 1/W-volume stream, so the cost per volume grows by s/W<m when the parameter is multiplied by m, giving a power saving.

## This page in the argument

The step: The cost per unit volume of interchanging two chunks of width $e=m^k$ satisfies $F_k\le(s/W)F_{k-1}+O(1)$ with $s/W<m^\tau$, hence $F_k=O(e^\tau)$: a power saving.
How: Count the calls, normalize by volume (each child has $1/W$ of the volume), and unroll the recurrence as a geometric sum.
Why: Multiplying the width by $m$ multiplies the work per volume only by $s/W<m$, and this strict inequality is the source of the power saving. (the sources say so: "is the source of the power saving." (paper))
Striking feature: The factor per level is $s/W<m$ although the width grows by the factor $m$: the margin is tiny (exponent $\tau=1-2^{-50}$) yet any strict margin yields a polynomial saving $e^{\tau}$ instead of a factor $e$. (explain why it holds, from the method)

Its sub-steps, in order:

- The number of recursive calls is the sum of the edge ranks, exactly $s$.
- Each call acts on one role stream of volume $V/W$, with all other fields kept as spectators.
- Splitting, merging, gates and triangular operations cost $O(V)$ at a node, so the cost per volume satisfies $F_0=O(1)$ and $F_k\le(s/W)F_{k-1}+O(1)$.
- Since $s/W<m^\tau$, the geometric sum $\sum_{j\le k}(s/W)^j$ is $O(m^{k\tau})$, whether $s/W\le1$ or $s/W>1$.
- Hence the normalized cost is $F_k=O(e^\tau)$ for width $e=m^k$.
- The fixed-tape depth-first schedule (parking the inactive streams, copying) moves $O(V)$ symbols per node, so the additive term is $O(V)$ even though each child has volume $V/W$.

It serves these steps, from the main result down:

- A deterministic multitape Turing machine multiplies two $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.; how: Build two faster tape procedures (address chunk interchange and simultaneous butterfly layers) from rank-saving linear networks, use them in synthetic polynomial transforms and resampled source transforms for a convolution, reduce integer multiplication to that convolution, then prove exactness and add up costs. (on [Integer multiplication below n log n](main-theorem.md))
- Two disjoint contiguous address fields of $u$ bits of an array of volume $V$ can be interchanged in $O(Vu^\tau)$ time for a fixed $\tau<1$.; how: Run the bit exchange network of the previous section on role streams: its endpoint operator is an address shear, each edge shear is implemented by smaller interchanges, and the rank saving yields a power recurrence; then remove width and row restrictions. (on [Address chunk interchange](address-chunk-interchange.md))
- Two disjoint chunks of $e=m^k$ digits can be interchanged in $O(Ve^\tau)$ time provided the row field is divisible by $W^k$, by running the bit network on $W$ role streams with every edge shear done recursively.; how: Split rows among the $W$ roles, apply the address shear on each edge with smaller interchanges, run the gates pointwise so the frame identity gives $H\leftarrow H+D$ on every row, then finish with $D\leftarrow D-H$, $H\leftarrow H+D$, $D\leftarrow H-D$. (on [Power-width chunk interchange](power-width-interchange.md))
