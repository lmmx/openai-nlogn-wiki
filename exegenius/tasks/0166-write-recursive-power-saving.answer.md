Recursive power saving is the mechanism that gives a tape procedure, a procedure that rearranges stored data on the tapes of a Turing machine, a cost that is a fixed power of its parameter, with exponent below one. It is built from a [Linear network with restored auxiliary values](linear-network-exchange.md), a fixed network that exchanges two banks of values and restores every auxiliary value.

A call moves a volume $V$ of data. The network has $W$ input roles, not counting scratch wires, and makes $s$ smaller calls. In this page $m$ is the factor by which the parameter grows. On earlier pages $W$ is a wire count and $s$ a field index, so these letters change meaning here. A call at parameter $mf$ makes $s$ calls at parameter $f$, where $f$ is the parameter of a smaller call. Each smaller call works on a stream of volume $V/W$, and the call also does linear work on its own volume.

Let $L$ be the number of levels, so the top call has parameter $m^L$ and the base calls have parameter $1$. Base calls cost time linear in their volume. Let $i$ be the level index, counted from the top with $i=0$. After $i$ levels there are $s^i$ calls, each on volume $V/W^i$, so level $i$ costs $V(s/W)^i$ up to a constant. Put $\gamma=\log_m(s/W)$, the exponent of the saving, so $s/W=m^\gamma$ and level $i$ costs $Vm^{\gamma i}$. If $s>W$, then $\gamma>0$, and the sum over $i=0,\dots,L$ is a geometric sum with ratio $m^\gamma>1$, dominated by its last term. The total is therefore $O(V(m^L)^\gamma)$.

The exponent is uniform. Each level multiplies the call count by $s$ and divides each volume by $W$, so $s/W$ is the same at every level, and $\gamma$ depends only on $s$, $W$ and $m$, not on $V$. The saving is strict exactly when $s<Wm$, that is $\gamma<1$, since then $m^\gamma<m$. <cite data-source="paper">This strict inequality is the source of the power saving</cite> If $s=Wm$, the cost is linear in the parameter and nothing is saved.

Applied to the [Fast address interchange](address-interchange.md) with field width $u$ as the parameter, this recursion bounds the cost of the interchange by $O(Vu^\tau)$ for a fixed $\tau$ with $\gamma<\tau<1$. <cite data-source="paper">Choose a rational number $\tau\in(0,1)$ with $s/W<m^\tau$.</cite> Any such $\tau$ works because $m^\gamma<m^\tau$, so the level sum is at most a constant times $m^{L\tau}=u^\tau$ for the top parameter $u=m^L$.

The same mechanism is applied to the [Simultaneous butterfly layer](simultaneous-butterfly-layer.md), with chunk count $d$ as the parameter.
