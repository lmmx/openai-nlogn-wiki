Fast interchange of address fields is a fixed-tape procedure that swaps two disjoint contiguous address fields of an array, and the multiplication construction uses it to speed up its address moves. The procedure acts on fields of an array laid out as in [Address fields and array layout on tapes](address-fields.md), so each field is a block of $u$ contiguous bits. Write $H$ and $D$ for the two fields, each viewed as a vector of entries over a common residue ring; for the bit procedure this ring is $\mathbb F_2$, where subtraction and addition coincide. Here $\tau$ is the fixed exponent below 1 in the cost, which is $O(Vu^\tau)$ <cite data-source="paper">for a fixed $\tau<1$</cite>.

Swapping takes three updates, applied componentwise:

$$D\leftarrow D-H,\qquad H\leftarrow H+D,\qquad D\leftarrow H-D.$$

Starting from $(H,D)$ they give $(H,D-H)$, then $(D,D-H)$, then $(D,H)$, since $H+(D-H)=D$ and $D-(D-H)=H$. For example, with $(H,D)=(1,0)$ over $\mathbb F_2$ the states are $(1,1)$, $(0,1)$, $(0,1)$, which is $(D,H)$.

The network performs only the middle update. The procedure is built from the [Address shear and lower-triangular factorization](address-shear-factorization.md): the network's endpoint operator is the shear $(H,D)\mapsto(H+D,D)$ over $\mathbb F_2$, with rank reduced by a lower-triangular factorization. Two further linear-cost address updates complete the interchange. Both change only $D$, each combining $D$ with the earlier field $H$ in linear time, so the shear is the only costly step.

The network's cost bound follows from [Recursive power saving from s<Wm](recursive-power-saving.md). The network makes $s$ smaller calls, each on a stream of volume $V/W$, where $W$ is its number of wires and $s$ is the sum of its edge ranks; for the bit network $s<Wm$, so $s/W<m$. Choose a fixed $\tau<1$ with $s/W<m^\tau$. Unrolling the recursion, the time per unit of volume is a geometric sum with ratio $s/W$, which is $O(u^\tau)$ for field width $u$, since each level multiplies the width by $m$.

The final effect is an exact permutation, although the network uses only pointwise XOR gates, so its intermediate values are XOR combinations of data. Over $\mathbb F_2$ each update is a pointwise XOR, since addition and subtraction are the same operation; after the first update $D$ holds the XOR of $D$ and $H$. The shear is applied to every row, including scratch rows with arbitrary contents. Exactness is secured by the [Restoring auxiliary scratch values](scratch-restoration.md) schedule, which subtracts the initial register value, computes, adds the result back, and reverses; the initial contents cancel, so the final permutation does not depend on them. <cite data-source="paper">The final permutation is exact for arbitrary initial auxiliary values</cite>.
