## This page

Concept: Complex phase network
Gloss: The second network over Gaussian dyadics with binary labels, whose frames are built from the two-point kernel C=HSH=aI+bX, so each edge is a product of translation kernels and the endpoint operator is C^{⊗m} on every role.

## This page in the argument

The step: Applying the complex phase network to a group of $e$ selected axes, with column frames built from $C=HSH=aI+bX$, produces $C^{\otimes e}$ on every role, using $s_{\rm c}$ child calls on $e/m$ axes each.

It serves these steps, from the main result down:

- A deterministic multitape Turing machine multiplies two $n$-bit integers in $O(n(\lg n)^{1-\kappa})$ time with $\kappa=2^{-182}$.; how: Reduce the product to a convolution of radix digits evaluated by approximate Fourier transforms over a polynomial ring, make the transform's address movement and arithmetic cheaper with two new tape procedures, then show the result is exact and add up the cost. (on [Integer multiplication below n log n](main-theorem.md))
- Applying $H_0(u,v)=((u+v)/2,(u-v)/2)$ to the same bit position in each of $D\le d$ address chunks of polynomial records at once costs $O(Vd^{\lambda'})$ for a fixed $\lambda'<1$, with a single truncation at the end.; how: Write the tensor power of $H_0$ through the tensor power of the kernel $C=aI+bX$, evaluate that by the complex phase network recursively with packed changes of selected address bits, and convert back to $H_0$. (on [Simultaneous butterfly layer](simultaneous-butterfly-layer.md))

## Evidence from the sources, with the paragraph around each quote

- "For the numerical procedure, the endpoint operator becomes the simultaneous $H_0$ layer after diagonal phase operations and a dyadic scale." (paper)

  > For the bit procedure, that endpoint operator is an address shear: two fields, written as vectors $H,D$ over a common residue ring, are updated by $(H,D)\mapsto(H+D,D)$. Two further linear-cost address updates complete their interchange. For the numerical procedure, the endpoint operator becomes the simultaneous $H_0$ layer after diagonal phase operations and a dyadic scale. The intermediate frames are chosen so that every edge can be implemented by smaller calls to the same procedure.

- "Each procedure arises from its own fixed linear network that exchanges two banks of values, with prescribed signs, and restores every auxiliary value." (paper)

  > Each procedure arises from its own fixed linear network that exchanges two banks of values, with prescribed signs, and restores every auxiliary value. A wire's fixed place in the network is called its role. To use the network on an array, regard a row as the complete ordered suffix, including all active address fields, at a fixed prefix and row index. Distribute rows cyclically among the $W$ roles, padding the row count for each prefix to a multiple of $W$. Let $V$ now denote the node volume after padding. All role streams have the same local address set and each contains $V/W$ bits. A scalar gate is then applied pointwise to matching addresses on the roles that it touches.
